# 教师端白板：原理分析与修复总结

> 日期：2026-11-13 16:42
> 范围：白板「线条颜色没显示」根因分析 + dpr/橡皮/resize 三项缺陷修复

---

## 一、白板整体架构与数据流原理

白板是一个 **「本地实时绘制 + WebSocket 实时同步 + 重连重放」** 的协作画板。数据从一笔落下到对端看到，走的是同一条链路：

```
用户拖拽鼠标
   │
   ▼
classroom-whiteboard.js #_move()   本地绘制（_drawSeg）＋ 记录到 _ops
   │ seg = {tool,color,size,x0,y0,x1,y1}
   ▼
classroom-ws.js #sendWhiteboard(seg)   封装成 op:'draw' 发给 WS
   │
   ▼
classroom-service  WhiteboardHandler.handlePayload
        registry.broadcastWhiteboard(sid, payload)   ← 原样字符串转发，不做任何改写
   │
   ▼
对端 onMessage(op:'draw')  →  _drawSeg(seg)   远端照画
```

**涉及的关键文件**

| 角色 | 文件 | 职责 |
|------|------|------|
| 工具栏/画布 | `frontend/classroom.html:53-62` | 颜色 picker、粗细 range、画布 canvas |
| 绘制核心 | `frontend/js/classroom/classroom-whiteboard.js` | 全部绘制逻辑（本地+远端） |
| 工具栏样式 | `frontend/css/classroom.css:219-250` | 工具栏/画布样式 |
| 发送 | `frontend/js/public/classroom-ws.js:135` | `sendWhiteboard` 封装 |
| 接线 | `frontend/js/classroom/classroom-main.js:141/161` | init + onWhiteboard 接线 |
| 服务端 | `api/classroom-service/.../ws/WhiteboardHandler.java` | 广播 + `wb:init` 重放 |
| 契约 | `doc-develop/classroom服务与前端交互清单.md:123` | 消息格式约定 |

**坐标约定（关键）**：所有 `seg` 里的 `x0/y0/x1/y1` 都是 **0~1 的归一化坐标**，绘制时再乘以画布尺寸。这样不同分辨率/缩放的客户端能对齐笔迹。

## 二、根因分析：颜色值没丢，是三种缺陷让线"看不见"

### 结论 1：颜色链路一层都没丢

追踪整条颜色链路：

```
#wb-color(input) → self.color → seg.color
   → sendWhiteboard JSON → WhiteboardHandler.broadcastWhiteboard（原样转发）
   → 对端 onMessage → _drawSeg 的 strokeStyle
```

用 **jsdom + mock canvas** 实测：选 `#e0245e` 后，`wb.color=#e0245e`、`strokeStyle=#e0245e`、`lineWidth=8`。所以「颜色值没传过来」**不是根因**。服务端是纯字符串转发，不碰内容。

### 结论 2（★主因）：dpr 双重缩放把线画到画布外

`_resize()` 里做了两件事：

```js
canvas.width  = w * dpr;          // 物理像素尺寸
canvas.height = h * dpr;
ctx2d.setTransform(dpr, 0, 0, dpr, 0, 0);   // 逻辑坐标 → 物理坐标 的变换
```

但 `_drawSeg()` 又用 `var w = this.canvas.width`（**物理像素**）去乘归一化坐标：

```js
c2.moveTo(seg.x0 * w, seg.y0 * h);   // w/h 是物理像素
```

而 `ctx2d` 已带 `setTransform(dpr,...)`，于是实际物理坐标 = 归一化 × 逻辑宽 × **dpr²**。

**jsdom 实测对比**（逻辑 800×400）：

| dpr | canvas 尺寸 | transform | 绘制坐标 | 终点是否出画布 |
|-----|------------|-----------|----------|----------------|
| 1   | 800×400    | [1,0,0,1,0,0] | (80,80)-(720,320) | 正常 |
| 2   | 1600×800   | [2,0,0,2,0,0] | (160,160)-(1440,640) → **再×2 = (320,320)-(2880,1280)** | **远超画布** |

Windows 缩放 125% / 150% / 200% 时 dpr>1 必现「画了线却看不见」，常被误报成「没有显示线条颜色」。

### 结论 3：另外两个同类缺陷（也会表现为线/颜色"消失"）

1. **橡皮擦失效**：`_move()` 里 `color:'#ffffff'` + `size*3`，是在**透明 canvas 上画白线**。画布背景是 CSS `#fff`，视觉上像擦掉了，但 ops 里留下白线 —— `wb:init` 重连回放时白线重新变可见。正确做法是 `destination-out` 真正擦除像素，或下发专门 erase 消息。

2. **resize 清空板书**：`_resize()` 只在尺寸变化时给 `canvas.width` 赋值。但 **给 `canvas.width` 赋值本身就会清空像素与绘图状态**（这是 Canvas 规范行为，注释里"避免清空已有绘制"是误判）。`wb:init` 只在 WS 建连时下发明一次，窗口变化后不会再重放 → 板书全没。

3. **UI 层（次要）**：`#wb-color` / `#wb-size` 在 `classroom.css` **完全没有样式规则**，深色工具栏上既无标签也无选中态，用户容易找不到「线条颜色」控件本身。

## 三、修复方案（一个 JS 文件 + 一个 CSS 文件）

改动文件：
- `frontend/js/classroom/classroom-whiteboard.js`（全部绘制逻辑）
- `frontend/css/classroom.css`

### ① dpr 双乘（主因）

- **对象新增缓存字段**：`granted`/`active` 旁加 `_w/_h/_dpr/_ops`（初始 `_ops:[]`）。
- **`_drawSeg` 改用逻辑尺寸**：不再读 `this.canvas.width`（物理像素），改读 `this._w/_h`（逻辑尺寸）。
- **`_resize` 保存逻辑尺寸**：`this._w = w; this._h = h; this._dpr = dpr;` 并在尺寸变化时重设后重绘。

> ctx2d 带 `setTransform(dpr,...)` 负责物理缩放；`_drawSeg` 只用逻辑坐标 × 逻辑尺寸，二者不再叠加。

### ② 橡皮擦（真擦除）

`_drawSeg` 里按 `seg.tool === 'eraser'` 切换：

```js
if (isEraser) {
  c2.save();
  c2.globalCompositeOperation = 'destination-out';
}
c2.strokeStyle = isEraser ? 'rgba(0,0,0,1)' : (seg.color || '#2f80ed');
c2.lineWidth   = (seg.size || 3) * (isEraser ? 3 : 1);
// ... moveTo / lineTo / stroke ...
if (isEraser) { c2.restore(); }
```

`destination-out` 真正清除画布像素（背景走 CSS `#fff`），且**回放同样生效**。

### ③ resize 清空板书（重放缓存）

- 本地 `_move` 绘制后 `this._ops.push(seg)`（在 sendWhiteboard 之前）；
- 远端 `op:'draw'` 入 `_ops`；`wb:init` 重建 `_ops`（遍历 ops 去重、含 clear 后重放）；`op:'clear'` 调用 `_clearLocal`；
- `clear` 同步 `this._clearLocal(); this._ops = [];`；
- `_resize` 尺寸变化时重设后调 `this._redrawAll()`（遍历 `_ops` 重绘），尺寸不变不重绘；
- 新增 `_redrawAll`：遍历 `_ops` 调 `_drawSeg`。

### ④ 颜色/粗细控件样式

`#wb-color` / `#wb-size` 原本零样式，新增：
- color input：28×28 圆角描边，跨浏览器 swatch 去边框；
- range：96px 宽，`accent-color:#1f6feb`，补 webkit/moz track/thumb 自定义，深色背景下可见可拖动。
