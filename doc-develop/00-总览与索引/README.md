# doc-develop 文档分类索引

2026-11-18 目录重组：`doc-api/` 改名为 `doc-user/`（只留用户操作文档），原两个目录里的开发资料、维护手册与项目生命周期文档按内容归入下列分类。

## 分类目录

| 目录 | 放什么 |
|---|---|
| `00-总览与索引/` | 文档地图、分类约定（本文件） |
| `01-需求与产品/` | 需求分析、功能规格、产品文案、组织架构、行业适配与术语映射、功能差距 |
| `02-架构与设计/` | 系统/软件设计说明、技术方案、架构原理、契约与多租户设计、论文式专题（原 `paper/`） |
| `03-开发与编程/` | 构建工具（Maven/NPM）、编码封装、前后端联调、开发操作指导、代码组织说明 |
| `04-部署与运维/` | 云服务器/云托管部署手册、000 系列核对清单、HTTPS 与证书生成、本地开发启动、故障排查 |
| `05-数据库与SQL/` | DDL 快照、迁移脚本、视图脚本、数据需求（原 `doc-api/v0/*.sql` 等） |
| `06-测试与验收/` | 测试用例与记录、回归/验收报告、itest 集成测试脚本、质量复盘 |
| `07-复盘与总结/` | 实施总结、工作总结、薄弱分析、迁移复盘、改进分析 |
| `08-电子课堂/` | 电子课堂全部资料：对接方案、修复记录、录制/白板/课时方案、页面 mockup（原 `classroom-integration/`） |
| `09-合规与合同/` | 隐私政策、协议、合同、验收单、等保相关 |
| `90-工具与脚本/` | 本地开发代理、启动/停止脚本、集成测试辅助脚本、配置样例（原目录根部的可执行文件） |
| `99-历史归档/` | v0 旧版设计/PDF、内容重复副本、同名旧稿，仅供追溯 |

## 留在根目录的运行时文件（不归类）

- `certs/`：本地 HTTPS 自签证书（被 `.gitignore` 忽略），`dev-proxy.js` 默认读取这里。
- `*.log`、`pids.txt`、`desktop.ini`：本机运行产物，不入文档分类。

## 脚本路径提醒

`90-工具与脚本/` 与 `06-测试与验收/` 下的 JS 脚本比原来深了一层，脚本内 `frontend/` 与 `certs/` 的相对路径已改为 `../../` / `../`；外部调用方式见各脚本头部注释与 `04-部署与运维/000 本地开发启动指南-三服务与前端.md`。
