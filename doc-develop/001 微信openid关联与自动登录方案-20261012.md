# 微信 openid 与用户 ID 关联及自动登录方案

> 日期：2026-10-12
> 范围：`miniprogram/` + `api/`
> 前置：微信登录代码骨架已存在但全线屏蔽（详见第六节"现状"），本方案在独立关联表 `wx_userid` 的基础上重新设计启用路径。

---

## 一、设计思路

### 1.1 与旧方案的区别

| 维度 | 旧方案（user 表加列） | 新方案（独立 wx_userid 表） |
|------|----------------------|---------------------------|
| 存储位置 | `user.wx_openid` 列 | 独立表 `wx_userid` |
| user 表改动 | 需 ALTER TABLE 加列 + 唯一索引 | **不改 user 表** |
| 关联关系 | openid 内嵌在 user 行 | `<openid, userId>` 独立行，可扩展 |
| 解绑/换绑 | UPDATE user SET wx_openid=NULL | DELETE/UPDATE wx_userid 行 |
| 多对多扩展 | 不支持（一列一值） | 天然支持（加行即可） |
| 查询效率 | user 表加索引 | 独立小表，索引更轻 |

### 1.2 三种场景

| 场景 | 触发条件 | 行为 |
|------|----------|------|
| **A. 静默登录** | 用户再次进入小程序，已有关联 | openid → 查 wx_userid → 命中 → 发 token → 免输入进系统 |
| **B. 已有账号绑定** | 用户密码登录成功后勾选"微信登录" | openid → 校验未绑过 → 插入 wx_userid `<openid, userId>` |
| **C. 微信直接注册** | 新用户扫码/分享进入，无账号无关联 | openid → 查 wx_userid 未命中 → 以 openid 为 account 创建 user → 插入 wx_userid → 发 token |

### 1.3 核心原则

- **openid 永不落前端**：`wx.login()` 仅拿临时 code，openid 由后端 `code2Session` 换取
- **不获取用户隐私**：不调 `wx.getUserProfile`/`wx.getUserInfo`，不拿昵称头像，仅用 openid 做身份标识
- **user 表零改动**：所有微信关联信息存在 `wx_userid` 表，user 表保持不变
- **静默降级**：任何环节失败都不影响密码登录主流程

## 二、数据模型设计

### 2.1 新增表：`wx_userid`

```sql
CREATE TABLE `wx_userid` (
  `id`          bigint       NOT NULL AUTO_INCREMENT COMMENT '自增主键',
  `wx_openid`   varchar(64)  NOT NULL COMMENT '微信 openid（全局唯一，不随租户隔离）',
  `user_id`     varchar(36)  NOT NULL COMMENT '关联的系统用户 user.user_id',
  `tenant_id`   bigint       NOT NULL COMMENT '用户所属租户（冗余，便于按租户统计）',
  `bind_source` varchar(20)  NOT NULL DEFAULT 'manual' COMMENT '关联来源：manual=已有账号手动绑定 / auto_register=微信直接注册',
  `create_time` datetime     NOT NULL DEFAULT CURRENT_TIMESTAMP COMMENT '关联建立时间',
  `update_time` datetime     NOT NULL DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP,
  PRIMARY KEY (`id`),
  UNIQUE KEY `uk_wx_openid` (`wx_openid`) COMMENT '一个微信最多关联一个账号',
  KEY `idx_user_id` (`user_id`),
  KEY `idx_tenant_id` (`tenant_id`)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COMMENT='微信 openid 与用户 ID 关联表';
```

**设计说明**：

| 项 | 说明 |
|---|------|
| `uk_wx_openid` 全局唯一 | 一个微信最多绑一个账号，与现有 `user.uk_phone`/`user.uk_email` 全局唯一一致 |
| `tenant_id` 冗余列 | 通过 `user_id` 可 JOIN 查出，冗余存储便于按租户统计微信注册用户，且避免登录时额外 JOIN |
| `bind_source` | 区分"手动绑定"与"微信自动注册"，用于运营分析和注册来源统计 |
| 不加 `@TableLogic` 软删除 | 解绑即物理删除该行（关联关系不存在中间态） |

### 2.2 不修改的表

- `user` 表：**零改动**，不新增 `wx_openid` 列
- `sys_tenant` 表：不改动
- 旧方案中的 `wechat_openid_migration.sql` **废弃**，不再执行

### 2.3 实体与 Mapper

**实体 `WxUserid.java`**（新增）：

```java
@TableName("wx_userid")
public class WxUserid {
    @TableId(type = IdType.AUTO)
    private Long id;
    private String wxOpenid;
    private String userId;
    private Long tenantId;
    private String bindSource;  // manual / auto_register
    private LocalDateTime createTime;
    private LocalDateTime updateTime;
    // getters/setters ...
}
```

**Mapper `WxUseridMapper.java`**（新增）：

```java
@Mapper
public interface WxUseridMapper extends BaseMapper<WxUserid> {

    // 按 openid 查关联（跳过租户隔离，openid 是平台级标识）
    @InterceptorIgnore(tenantLine = "true")
    @Select("SELECT * FROM wx_userid WHERE wx_openid = #{openid} LIMIT 1")
    WxUserid getByOpenid(@Param("openid") String openid);

    // 按 userId 查关联（解绑/查询用）
    @InterceptorIgnore(tenantLine = "true")
    @Select("SELECT * FROM wx_userid WHERE user_id = #{userId} LIMIT 1")
    WxUserid getByUserId(@Param("userId") String userId);

    // 解绑
    @InterceptorIgnore(tenantLine = "true")
    @Delete("DELETE FROM wx_userid WHERE user_id = #{userId}")
    int unbind(@Param("userId") String userId);
}
```

> 所有方法加 `@InterceptorIgnore(tenantLine = "true")`，因为 `wx_userid` 是平台级关联表，不参与租户隔离插件的条件拼接。

## 三、三种场景完整流程

### 3.1 场景 A：静默登录（已绑定用户免输入进系统）

```
┌─ 小程序启动 / 进入登录页 ─────────────────────────────────────┐
│  app.js onLaunch 或 login.js onLoad                          │
│  → 检测无本地会话 → wechatSilentLogin()                       │
└──────────────────────────────────────────────────────────────┘
                              │
                              ▼
┌─ 小程序端 ───────────────────────────────────────────────────┐
│  ① wx.login() → 临时 code（静默，无弹窗，5 分钟有效）           │
│  ② POST /auth/wechat-login { code }                          │
│     不带 Bearer（公开接口），customErrorMsg=false 静默降级      │
└──────────────────────────────────────────────────────────────┘
                              │
                              ▼
┌─ 后端 authController.wechatLogin ────────────────────────────┐
│  ③ WeChatService.code2Session(code)                          │
│     → 调微信 jscode2session API                              │
│     → 返回 { openid, session_key }                            │
│  ④ WxUseridMapper.getByOpenid(openid)                        │
│     → 查 wx_userid 表                                         │
└──────────────────────────────────────────────────────────────┘
                              │
              ┌───────────────┴───────────────┐
              │                               │
              ▼ 命中关联                       ▼ 未命中
┌─ ⑤ 状态校验 ──────────────┐    ┌─ 返回 code=1001 "未绑定微信" ─┐
│  user.status=frozen → 拒绝  │    │  前端 wechatSilentLogin()    │
│  user.status=pending → 拒绝 │    │  返回 null → 降级走密码登录   │
│  user.status=active → 放行  │    └──────────────────────────────┘
└─────────────────────────────┘
              │
              ▼
┌─ ⑥ 生成 JWT ────────────────────────────────────────────────┐
│  token = jwtUtil.generateToken(tenantId, userId, role)       │
│  refreshToken = jwtUtil.generateRefreshToken(...)            │
│  refreshTokenService.saveNewToken(...)                       │
│  userSessionService.onLogin(...)                             │
└──────────────────────────────────────────────────────────────┘
              │
              ▼
┌─ ⑦ 返回与密码登录一致的结构 ──────────────────────────────────┐
│  { code:200, token, refreshToken, userId, role, tenantCode } │
└──────────────────────────────────────────────────────────────┘
              │
              ▼
┌─ 前端 setSession(res) → 直接进角色首页 ──────────────────────┐
│  免输入账号密码，无感登录                                       │
└──────────────────────────────────────────────────────────────┘
```

### 3.2 场景 B：已有账号绑定 openid

```
密码登录成功
  → 用户勾选"允许微信登录"（login.wxml checkbox）
  → bindWechat()
    ① wx.login() → code
    ② POST /auth/bind-wechat { code }  （带 Bearer，需登录态）
       后端：
       ③ code2Session(code) → openid
       ④ WxUseridMapper.getByOpenid(openid) → 校验该 openid 未被其他账号绑定
          ├─ 已被占用且 userId 不同 → 返回 409 "该微信已绑定其他账号"
          └─ 未被占用 → 继续
       ⑤ WxUserid newRecord = { wxOpenid: openid, userId: 当前用户, tenantId, bindSource: "manual" }
          wxUseridMapper.insert(newRecord)
       ⑥ 返回成功
    → 下次启动即可走场景 A 静默登录
```

### 3.3 场景 C：微信直接注册（新用户无账号）

```
┌─ 小程序：用户扫码/点分享链接进入 ────────────────────────────┐
│  URL 带 tenantCode（必需，确定注册到哪个租户）                 │
│  → 无本地会话 → wechatSilentLogin()                           │
│  → 后端返回 code=1001 "未绑定微信"                            │
│  → 前端检测到未绑定 + 有 tenantCode → 走微信注册流程           │
└──────────────────────────────────────────────────────────────┘
                              │
                              ▼
┌─ 小程序端 ───────────────────────────────────────────────────┐
│  ① wx.login() → code                                         │
│  ② POST /auth/wechat-register { code, tenantCode, role? }     │
│     不带 Bearer（公开接口）                                    │
│     role 可选，默认 "student"                                  │
└──────────────────────────────────────────────────────────────┘
                              │
                              ▼
┌─ 后端 authController.wechatRegister ─────────────────────────┐
│  ③ WeChatService.code2Session(code) → openid                 │
│  ④ WxUseridMapper.getByOpenid(openid)                        │
│     → 命中 → 返回 409 "该微信已注册，请直接登录"               │
│     → 未命中 → 继续                                            │
│  ⑤ TenantService.getByCode(tenantCode) → tenant              │
│     → 租户不存在/已停用 → 返回 403                             │
│  ⑥ 事务内：                                                   │
│     ├─ 构造 User 对象：                                        │
│     │   account  = openid          （以 openid 为账号）        │
│     │   password = 随机UUID(BCrypt加密) （不可用于密码登录）   │
│     │   role     = role || "student"                          │
│     │   status   = "pending"      （需租户管理员审批）         │
│     │   tenantId = tenant.id                                   │
│     │   name     = null           （后续可补填）               │
│     │   phone/email = null                                     │
│     ├─ TenantContext.setTenantId(tenant.id)                   │
│     ├─ tenantQuotaService.acquire(tenant.id, USER/STUDENT)    │
│     ├─ userMapper.insert(user)                                │
│     └─ wxUseridMapper.insert({                                │
│         wxOpenid: openid,                                     │
│         userId: user.userId,                                  │
│         tenantId: tenant.id,                                  │
│         bindSource: "auto_register"                           │
│       })                                                      │
│  ⑦ 生成 JWT token + refreshToken                              │
│  ⑧ 返回 { code:200, token, userId, role, tenantCode,          │
│           status:"pending", message:"注册成功，待审批" }       │
└──────────────────────────────────────────────────────────────┘
                              │
                              ▼
┌─ 前端 setSession(res) → 进首页（pending 状态可浏览，功能受限）─┐
│  下次启动 → 场景 A 静默登录（无需再注册）                      │
└──────────────────────────────────────────────────────────────┘
```

**微信直接注册的关键设计**：

| 项 | 值 | 说明 |
|---|---|---|
| `account` | openid | 以 openid 作为账号标识，全局唯一（配合 uk_wx_openid 保证不重复注册） |
| `password` | 随机 UUID（BCrypt 加密） | 不可预测，仅限微信登录；用户不知道密码，无法走密码登录 |
| `role` | 请求传入或默认 `student` | 微信注册通常为学生；教师/管理员需走其他渠道 |
| `status` | `pending` | 需租户管理员审批（与现有密码注册的 student/teacher 一致） |
| `name` | null | 不获取微信昵称（不调 getUserProfile），后续用户可在个人中心补填 |
| `phone`/`email` | null | 微信不提供，后续可补填 |
| `tenantCode` | 请求传入 | **必需**，确定注册到哪个租户（通常来自推广链接/分享参数） |

## 四、后端 API 设计

### 4.1 接口清单

| 端点 | 方法 | 鉴权 | 场景 | 说明 |
|------|------|------|------|------|
| `/api/v1/auth/wechat-login` | POST | permitAll | A | 静默登录：code → openid → 查关联 → 发 token |
| `/api/v1/auth/wechat-register` | POST | permitAll | C | 微信直接注册：code → openid → 建 user + 关联 → 发 token |

### 4.3 Service 层设计

**`WxUseridService.java`**（新增）：

```java
@Service
public class WxUseridService {

    @Autowired private WxUseridMapper wxUseridMapper;

    // 按 openid 查关联
    public WxUserid findByOpenid(String openid) {
        return wxUseridMapper.getByOpenid(openid);
    }

    // 按 userId 查关联
    public WxUserid findByUserId(String userId) {
        return wxUseridMapper.getByUserId(userId);
    }

    // 绑定（已有账号）
    @Transactional(rollbackFor = Exception.class)
    public void bind(String openid, String userId, Long tenantId, String source) {
        WxUserid exist = wxUseridMapper.getByOpenid(openid);
        if (exist != null && !exist.getUserId().equals(userId)) {
            throw new BusinessException(409, "该微信已绑定其他账号，无法重复绑定");
        }
        if (exist != null) {
            return; // 已绑定同一账号，幂等返回
        }
        WxUserid record = new WxUserid();
        record.setWxOpenid(openid);
        record.setUserId(userId);
        record.setTenantId(tenantId);
        record.setBindSource(source);
        wxUseridMapper.insert(record);
    }

    // 解绑
    @Transactional(rollbackFor = Exception.class)
    public void unbind(String userId) {
        wxUseridMapper.unbind(userId);
    }
}
```

**`UserService` 改动**：取消旧块注释，改为调用 `WxUseridService`：

```java
// 静默登录
public Result<HashMap<String, Object>> wechatLogin(String openid) {
    WxUserid binding = wxUseridService.findByOpenid(openid);   // ← 改：查 wx_userid 表

    }

    if (user == null) {
        return Result.fail(1001, "关联账号不存在");
    }
    // 状态校验 + 生成 token（与旧逻辑相同）
    // ...
}

// 微信直接注册（新增）
@Transactional(rollbackFor = Exception.class)
public Result<HashMap<String, Object>> wechatRegister(String openid, String tenantCode, String role) {
    // 1. 查关联，已存在则拒绝
    if (wxUseridService.findByOpenid(openid) != null) {
        return Result.fail(409, "该微信已注册，请直接登录");
    }
    // 2. 解析租户
    Tenant tenant = tenantService.getByCode(tenantCode);
    if (tenant == null || tenant.getStatus() != STATUS_NORMAL) {
        return Result.fail(403, "租户不存在或已停用");
    }
    // 3. 构造 User
    TenantContext.setTenantId(tenant.getId());
    String resolvedRole = (role != null) ? role : RoleConst.STUDENT;
    String userId = UUID.randomUUID().toString();
    User user = new User();
    user.setUserId(userId);
    user.setTenantId(tenant.getId());
    user.setAccount(openid);                          // 以 openid 为账号
    user.setPassword(passwordEncoder.encode(UUID.randomUUID().toString())); // 随机不可登录密码
    user.setRole(resolvedRole);
    user.setStatus("pending");                        // 待审批
    // 4. 配额占用
    tenantQuotaService.acquire(tenant.getId(), TenantQuotaService.USER);
    if (RoleConst.STUDENT.equals(resolvedRole)) {
        tenantQuotaService.acquire(tenant.getId(), TenantQuotaService.STUDENT);
    }
    // 5. 落库
    userMapper.insert(user);
    // 6. 建立关联
    wxUseridService.bind(openid, userId, tenant.getId(), "auto_register");
    // 7. 生成 token
    String token = jwtUtil.generateToken(tenant.getId(), userId, resolvedRole);
    String refreshToken = jwtUtil.generateRefreshToken(tenant.getId(), userId);
    refreshTokenService.saveNewToken(userId, refreshToken, jwtUtil.getRefreshExpireTime());
    // 8. 返回
    HashMap<String, Object> result = new HashMap<>();
    result.put("token", token);
    result.put("refreshToken", refreshToken);
    result.put("userId", userId);
    result.put("role", resolvedRole);
    result.put("tenantCode", tenantCode);
    result.put("status", "pending");
    return Result.success(result, "注册成功，待审批");
}

// 绑定微信（已有账号）
public Result<Boolean> bindWechat(String userId, String openid) {
    User user = userMapper.selectById(userId);
    if (user == null) {
        return Result.fail(404, "用户不存在");
    }
    wxUseridService.bind(openid, userId, user.getTenantId(), "manual");
    return Result.success(true, "微信绑定成功");
}
```

## 五、前端实现设计

### 5.1 `miniprogram/core/auth.js` 改动

```javascript
// 新增：微信直接注册
export async function wechatRegister({ tenantCode, role }) {
  try {
    const { code } = await wxLoginCode();
    const res = await request({
      url: ENDPOINTS.AUTH_WECHAT_REGISTER,   // 新增端点常量
      method: 'POST',
      data: { code, tenantCode, role: role || 'student' },
      tokenOnly: true,
      customErrorMsg: false
    });
    if (!res || !res.token) return null;
    setSession(res);
    try { await loadTermMap(); } catch (e) {}
    return res;
  } catch (e) {
    return null;
  }
}

// 新增：解绑
export async function unbindWechat() {
  try {
    await request({ url: ENDPOINTS.AUTH_UNBIND_WECHAT, method: 'POST' });
    return true;
  } catch (e) {
    return false;
  }
}
```

### 5.2 `miniprogram/pages/login/login.js` 改动

```javascript
// onLoad 中恢复静默登录尝试
onLoad(options) {
  // ... 现有逻辑 ...

  // 恢复微信静默登录
  if (!getSession()) {
    const res = await wechatSilentLogin();
    if (res) {
      // 静默登录成功，直接跳首页
      redirectToUserPage(res);
      return;
    }
    // 静默登录失败（未绑定），检查是否有 tenantCode 可走微信注册
    const tenantCode = options.tcode || options.tCode || storage.get(BOUND_TENANT_KEY);
    if (tenantCode && options.autoRegister !== '0') {
      // 有租户编码 → 尝试微信直接注册
      const regRes = await wechatRegister({ tenantCode });
      if (regRes) {
        redirectToUserPage(regRes);
        return;
      }
    }
    // 都失败 → 显示密码登录表单
  }
}

// onLogin 中恢复微信绑定
async onLogin() {
  // ... 密码登录成功 ...
  if (this.data.bindWechat) {
    await bindWechat();  // 勾选了"允许微信登录"则绑定
  }
}
```

## 七、安全要点

| 项 | 设计 |
|---|------|
| **openid 不落前端** | `wx.login()` 仅拿临时 code，openid 由后端 `code2Session` 换取，客户端永不接触 |
| **不获取用户隐私** | 不调 `wx.getUserProfile`/`wx.getUserInfo`，不拿昵称头像，仅用 openid 做身份标识 |
| **全局唯一绑定** | `wx_userid.uk_wx_openid` 唯一索引，一个微信最多关联一个账号 |
| **跳过租户隔离** | `WxUseridMapper` 所有方法加 `@InterceptorIgnore(tenantLine="true")`，openid 是平台级标识 |
| **公开接口无 Bearer** | `/auth/wechat-login` / `/auth/wechat-register` 在 permitAll 白名单；`/auth/bind-wechat` / `/auth/unbind-wechat` 需登录态 |
| **appsecret 保护** | 通过环境变量 `WECHAT_SECRET` 注入，不进版本库 |
| **未绑定不泄露信息** | 未命中返回 `code=1001`，不透露"该微信是否注册过"的具体信息 |
| **微信注册不可密码登录** | password 设为随机 UUID，用户不知道，只能通过微信登录 |
| **注册需审批** | 微信直接注册 status=pending，需租户管理员审批后才能完整使用（与密码注册一致） |
| **防重复注册** | 注册前先查 `wx_userid`，已存在则返回 409；`uk_wx_openid` 唯一键兜底并发 |

## 八、与推广路径的协同

微信自动登录与推广路径方案协同，形成完整的获客闭环：

```
推广者分享小程序码（带 ref=推广码 & tcode=租户编码）
  → 用户扫码进入
  → captureAttribution() 抓取 inviter/source（首次触达归因）
  → wechatSilentLogin() 尝试静默登录
    │
    ├─ 已绑定 → 直接进系统 + reportAttributionOnce() 上报归因
    │
    └─ 未绑定 → 检测到 tcode → 走微信直接注册
         → wechatRegister({ tenantCode: tcode })
         → 后端：建 user（account=openid, status=pending）+ 建 wx_userid 关联
         → 前端：setSession → 进首页（待审批状态）
         → reportAttributionOnce() 上报归因（推广者业绩 +1 注册人数）
         → 租户管理员审批通过 → status=active → 推广者业绩 +1 审批通过
```

**归因上报时机**：无论密码登录、微信静默登录还是微信直接注册，只要 `setSession` 成功即可触发 `reportAttributionOnce()`，三种登录方式对归因机制透明。

## 九、多租户设计决策

### 9.1 当前方案：一个微信全局绑一个账号

`wx_userid.uk_wx_openid` 全局唯一，一个微信最多关联一个账号。这与现有 `user.uk_phone`/`user.uk_email` 全局唯一一致。

**适用场景**：一个用户主要在一个机构（租户）活动。

**限制**：如果用户想在另一个机构注册，需要先解绑当前关联，或使用密码注册。

### 9.2 可选扩展：一个微信在多个租户各绑一个账号

如需支持"同一微信在不同机构各注册一个账号"，改为联合唯一键：

```sql
-- 改为联合唯一键（openid + tenant_id）
ALTER TABLE wx_userid DROP INDEX uk_wx_openid;
ALTER TABLE wx_userid ADD UNIQUE KEY uk_wx_openid_tenant (wx_openid, tenant_id);
```

此时静默登录需带 `tenantCode` 确定登录到哪个租户：

```javascript
// 前端：静默登录带 tenantCode
const tenantCode = storage.get(BOUND_TENANT_KEY) || options.tcode;
const res = await request({
  url: ENDPOINTS.AUTH_WECHAT_LOGIN,
  method: 'POST',
  data: { code, tenantCode }  // 带上租户编码
});
```

后端按 `(openid, tenantId)` 查关联。若一个 openid 在多个租户有关联且未传 tenantCode，返回租户列表让用户选择。

> 本方案默认采用 9.1（全局唯一），与现有系统一致。如后续需要多租户支持，按 9.2 扩展。
