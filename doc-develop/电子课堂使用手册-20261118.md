# 电子课堂使用手册

- 版本：v1.0
- 日期：2026-11-18
- 适用角色：授课教师、上课学生、租户管理员、平台管理员
- 适用页面：`classroom-prep.html`（课程/课前准备）、`classroom.html`（在线课堂）、`replay.html`（课堂回放）、`classroom-ops.html`（课堂运营台）、`admin.html`（管理后台）

> 本手册只写界面上真实存在的操作。所有按钮文字、提示文案均取自当前代码。

---

## 0. 先看这里：三个前置条件

| 条件 | 说明 | 不满足时的现象 |
|---|---|---|
| **浏览器权限** | 首次进入准备页要允许摄像头、麦克风权限 | 提示「麦克风不可用，请到「课程准备」页检查设备与浏览器权限」，只能仅观看 |
| **HTTPS / localhost** | 浏览器只在安全上下文放行 `getUserMedia`。本机 `https://localhost:8080` 可用；局域网另一台电脑必须用 `https://<本机IP>:8080`，用 `http://` 摄像头会被直接禁用 | 摄像头/麦克风下拉为空，提示需 HTTPS |
| **自签证书信任（可选）** | 本地自签证书首次访问会显示「不安全」，点「高级 → 继续前往」即可；功能不受影响。要消除红锁需把 `doc-develop/certs/ca.crt` 导入「受信任的根证书颁发机构」 | 仅地址栏红锁，不影响音视频 |

## 3. 教师端

### 3.1 课前：课程准备页

页面正常宽度下：左侧「教学资料」+「课堂信息」，右侧「设备检测与选择」；窗口变窄（≤900px）时顺序为 教学资料 → 设备检测 → 课堂信息。

**① 设备检测与选择（右侧宽栏）**

- 打开「摄像头」后下方出现本地预览；灰色电平条会随说话跳动（提示语：「对着麦克风说话，绿色条会跳动」）。
- 「麦克风」「摄像头」两个下拉可切换设备，首项为「系统默认」；选择结果会被记住，进入课堂直接生效。
- 插拔设备会自动重新枚举；也可点「重新检测」。
- 顶部状态汇总为「全部正常 / 部分可用 / 不可用」。

**② 教学资料（左上）**

- 「上传资料」按钮选择本地文件；列表显示 `文件名 / 大小(KB) / 查看 / 删除`。
- 每行「删除」按钮：二次确认「确认删除「X」？文件将一并删除且不可恢复。」，教师和管理员可用，学生不显示。
- 支持 PDF / 图片 / 视频等；不支持内联预览的格式显示「点此下载」，下载文件名自动带原始扩展名。

**③ 课堂信息（左下）**

- 「课次标识」显示为可读的「课程名 · 第N课次」（第 1 课次只显示课程名），不再是一长串 UUID；鼠标悬停也无编码，排障看地址栏参数。
- 「上课时间」「课堂状态」；状态取值见第 8 节。
- 教师可见「成员名单」。

**④ 顶部按钮**

| 按钮 | 作用 |
|---|---|
| 返回 | 有历史则后退，否则回教师/学生首页 |
| 同步课堂 | 把课次推送到课堂服务（课堂缺失时用）；成功后提示「已发起同步，课程服务会为每个课次创建课堂」 |
| 进入课堂 | 进入在线课堂页 |

### 3.2 上课：控制栏

底部控制栏按角色和状态动态显示：

| 按钮 | 角色 | 说明 |
|---|---|---|
| 麦克风 / 摄像头 | 教师、学生 | 开关本地轨道；全员禁言时学生开麦会被拒并提示 |
| 白板 / 讲稿 | 所有角色 | 显示/隐藏对应面板 |
| 举手 / 上传作业 | 学生 | — |
| 点名 | 教师 | 弹窗「发起点名」，可不选学生则随机 |
| 全员静音 | 教师、管理员 | 一键静音全体学生 |
| 录制模式下拉 | 教师、管理员 | 「人像录制」（默认）/「教学区域」 |
| 录制 | 教师、管理员 | 开始/停止录制 |
| 保存板书 / 作业点评 | 教师 | — |
| 巡课 | 管理员 | 浮层含「强制结束」 |
| 进行中 / 暂停 / 下课 | 教师 | 状态控制，见下 |
| 离开 | 学生、管理员 | 确认「确定要离开课堂吗？」 |

### 3.3 课堂状态控制（重要：不会自动下课）

系统默认**显式手工管理**，时间只产生提醒，不会自动开课或自动结束。

| 操作 | 行为 |
|---|---|
| 进行中 | 实时查状态：`PAUSED` → 恢复；`LIVE` → 提示「课堂已在进行中，无需重复开课」；`CLOSED` → 提示「课堂已结束/已取消，无法重新开课」；其余 → 开课 |
| 暂停 | 确认「确定暂停课堂吗？暂停期间教师端和学生端都不能发送音视频、白板与聊天。」；暂停期间**师生全员**都不能发言/书写/翻页 |
| 下课 | 确认「确定要结束本次课堂吗？」。**若尚未到约定上课时间（计划 start_time），不结束，改为暂停**，提示「尚未到上课时间，课堂已暂停（稍后可点「进行中」恢复）」；已到/超过计划时间才真正结束并结算 |

> 下课收尾是不可逆的：闭合出勤区间、归一出勤、全员离线、触发课时回流。所以已结束的课**不能重新开课**，误操作请用「暂停」而不是「下课」。

### 3.4 三大面板：移动、缩放、复位

视频、白板、讲稿三个面板都是独立浮层，布局记在浏览器本地，下次进入自动恢复。

| 想做什么 | 怎么操作 |
|---|---|
| 移动面板 | 按住面板**标题栏**拖动（视频标题栏 / 白板工具栏 / 讲稿标题栏）。提示：「拖动移动；双击恢复默认位置」 |
| 缩放面板 | 拖面板**右下角**的缩放手柄（提示「拖动缩放」） |
| 复位 | 点标题栏的 ⟳ 按钮「恢复默认位置与大小」，或**双击标题栏**；提示「XX面板已恢复默认位置与大小」 |
| 置顶 | 点面板任意位置即置顶 |

### 3.5 视频焦点放大

有 **2 个及以上**画面时：

- **点击某个画面** → 它放大到主区，其余画面缩到右侧一列。
- 退出方式三选一：再点该画面一次 / 点右上角「关闭放大」按钮 / 按 `Esc`。

焦点只是本地观看状态，不广播、不进录制、不影响其他人。

### 3.6 讲稿

- 讲稿栏按钮：「资料选择…」下拉、「上传讲稿」、「上一页」「下一页」；页码显示「第 N 页」。**学生看不到这些按钮**，只能看当前展示的讲稿。
- 多份资料时从下拉中选一份展示，全员同步；「上传讲稿」保留现场上传能力，新上传的资料自动成为当前展示稿。
- 翻页与滚动都会同步给全班；迟到/刷新进房的人会自动定位到教师当前页和滚动位置。
- PDF 由浏览器内 PDF.js 渲染，不走 iframe，避免换页黑闪。

### 3.7 白板

工具栏从上到下：

| 工具 | 说明 |
|---|---|
| 画笔 / 橡皮 | 基础书写 |
| 矩形 / 圆 / 正方形 | 形状 |
| 文字 | 点画布输入，**Ctrl+Enter** 确认，也可用浮层「确定」/「取消」 |
| 颜色 / 粗细 / 字体 / 字号 | 样式 |
| 撤回 | 撤回最近一条操作（`Ctrl+Z`）；无可撤回操作时会提示 |
| 清空 | 清空白板 |
| 只读 | 当前无编辑权限时显示 |
| 复位 ⟳ | 恢复白板视图 |

**学生默认是只读的**（与服务端权限一致），要让学生写字，需在**右侧参与者列表**里点该学生行的「授权白板」；收回点「收回白板」。学生被授权后收到「教师已授权你编辑白板」。

> 授权消息只发给被授权者本人，不会出现"A 被授权、B 也能画"的错觉。

### 3.8 录制

1. 先从「录制模式」下拉选模式：
   - **人像录制**（默认）：录教师本地摄像头+麦克风，画面只有教师一人。
   - **教学区域**：用屏幕共享采集，讲稿、白板、PPT 都进画面，可存档。需要 Chrome/Edge 且为 HTTPS；共享时勾选系统音频，整屏共享常录不到系统声，建议同时开麦克风。
2. 点「录制」，开始提示：「人像录制已开始」或「教学区域录制已开始（共享画面 + 系统声音，若需人声请开麦克风）」（学员端会看到录制提示）。
3. 共享被用户/浏览器停止时会自动收尾上传，不会让记录卡在「录制中」。
4. 停止后提示「录制已保存，可在回放页观看」。

录制文件在收尾时会自动补齐时长与跳转索引，回放可拖动进度条、显示总时长。

## 4. 学生端

### 4.1 课前准备

入口为「课前准备」（URL 带 `?mode=student`）：只显示「设备检测与选择」+「课堂信息」，隐藏教学资料和成员名单。课堂状态显示为「待开始 / 上课中 / 已结束」。

### 4.2 课堂内操作

| 操作 | 说明 |
|---|---|
| 麦克风 / 摄像头 | 自行开关；被全员静音时提示「全员禁言中，无法开启麦克风」 |
| 举手 | 点「举手」，再点「已放下手」；教师端能看到举手状态 |
| 上传作业 | 提交作业文件 |
| 聊天 | 底部输入框输入后按 **Enter** 或点「发送」 |
| 点名应答 | 教师点名时弹窗「老师点名了你！」，点「我已到」或「稍后」；应答后提示「已应答点名」 |
| 白板 | 默认只读；教师授权后可写，被收回时提示「教师已收回白板编辑权」 |
| 讲稿 | 跟随教师翻页与滚动，无翻页按钮 |
| 离开 | 确认「确定要离开课堂吗？」 |

暂停期间全员都不能发送音视频、白板与聊天，界面会提示「课堂已暂停，暂不能发布音视频、白板与聊天」。

## 5. 管理员端

### 5.1 预订审核

`admin.html` →「预订审核」（界面文字是"预订"）。列：序号 / 课程名称 / 排期名称 / 学生姓名 / 教师姓名 / 上课时间 / 状态 / 操作。

操作按钮：`确认`、`拒绝`、`撤回`、`删除`、`查询递补`、`拒绝候补`；当该课次已有课堂且状态为 booked 时，多一个「进入课堂」。

### 5.2 上课通知

`admin.html` →「上课通知」。列：序号 / 课程名称 / 学生姓名 / 教师姓名 / 上课时间 / 状态 / 操作。

- 管理员操作：「发送提醒」、「进入课堂」（需 hasClassroom 且可通知/有排期）。
- 行内按钮按阶段变化：
  - 未开始 → 学生「课前准备」「进入课程」，教师「课程准备」「进入课程」
  - 进行中 →「进入课程」
  - 已结束 →「课程回看」（灰）

### 5.3 课堂监控 / 运营台

「课堂监控」跳转到 `classroom-ops.html`（课堂运营台），顶部有「刷新当前页」，五个标签页：

| 标签页 | 用途 |
|---|---|
| 实时监控（默认） | 列：课程 / 教师 / 开始时间 / 状态 / 在线-成员 / 操作；操作列有「进入课堂」；下方告警如「卡在 LIVE 未下课的课堂 N 节」 |
| 学情报表 | 出勤与学情 |
| 对账差异 | 课时与课堂对账 |
| 内容审核 | 审核消息与板书 |
| 契约联调 | 接口联调 |

> 运营台本身没有「结束课堂」按钮；强制结束在管理员进入课堂后的「巡课」浮层里。

## 6. 回放

### 6.1 进入方式

- 从「我的课堂」已结束课次的「课程回看」进入，URL 带 `?scheduleId=...`，页头直接显示「课程名 · 第N课次」，**不再出现课次 ID**。
- 直接打开 `replay.html` 时显示手工查询入口：输入框「粘贴课次链接或标识（手工查询用）」+「查询」按钮；支持粘贴整条链接自动解析。

### 6.2 列表与播放器

- 每条录制显示：开始时间 + 状态徽标（可回放 / 录制中 / 录制失败）、「时长 … · 状态 · 人像录制/教学区域录制」。
- 播放器保留浏览器原生控件（进度条、拖拽、音量、倍速）。
- 额外便捷功能：

| 功能 | 操作 |
|---|---|
| 倍速 | 右上角 `1x / 1.25x / 1.5x / 2x` 按钮，记忆上次选择 |
| 续播 | 超过 5 秒且未看完时中间出现「从 mm:ss 继续播放」 |
| 快捷键 | `空格` 播放/暂停、`←→` 快退/快进 5 秒、`↑↓` 音量 ±0.1 |
| 连播提示 | 播完自动高亮下一条并提示「本条已播完，已选中下一条（点击即可播放）」 |

> 录制文件保留 90 天，签名地址有效期 2 小时。

## 7. 课堂状态说明

| 状态 | 界面文字 | 含义 |
|---|---|---|
| SCHEDULED | 待开始 / 未开始 | 排期已生成，还没就绪 |
| READY | 待开课 / 待开始 | 已就绪，可进入 |
| LIVE | 上课中 / 进行中 | 正在上课，可收发全部内容 |
| PAUSED | 已暂停 | 全员禁发，可恢复 |
| CLOSED | 已结束 | 终态，已结算，**不可重开** |
| CANCELLED | 已取消 | 终态 |

## 8. 常见问题

| 现象 | 原因与处理 |
|---|---|
| 摄像头/麦克风下拉为空 | 浏览器权限未授，或用的不是 HTTPS/localhost；到「课程准备」页检查并允许权限 |
| 「不安全」红锁 | 自签证书未被信任，点「高级 → 继续前往」即可，不影响摄像头 |
| 局域网另一台电脑打不开 | 用 `https://<教师机IP>:8080`，不能用 `http://`；首次访问需点继续 |
| 学生画了但别人看不到 | 学生默认只读，需要教师在参与者列表点「授权白板」 |
| 学生端提示「课堂已暂停，暂不能发布…」 | 教师暂停了课堂，等教师点「进行中」恢复 |
| 提前点「下课」却没结束 | 这是设计行为：未到计划上课时间会自动转成「暂停」，稍后点「进行中」恢复 |
| 点「下课」后想重新开课 | 做不到。已下课会触发课时结算与出勤归一，属于不可逆终态 |
| 回放有声音没画面 | 请刷新页面（旧版有 video 被 CSS 隐藏的问题，现已修复） |
| 回放进度条拖不动 / 显示 ∞ | 历史录制文件没有时长与索引；新录制已自动补齐，旧文件需离线回填 |
| 教学区域录制没有系统声音 | 整屏共享常不带系统音频；勾选共享标签页音频，并同时开麦克风 |
| 面板找不到了 | 双击面板标题栏或点 ⟳ 恢复默认位置与大小 |
| 视频画面叠在一起 | 点面板任意位置置顶；或复位布局 |

## 9. 附录：快捷键汇总

| 场景 | 快捷键 |
|---|---|
| 白板文字输入确认 | `Ctrl + Enter` |
| 白板撤回 | `Ctrl + Z` |
| 视频焦点放大退出 | `Esc` |
| 聊天发送 | `Enter` |
