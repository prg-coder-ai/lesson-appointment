# 电子课堂系统 · 操作说明

> 适用版本：2026-10-29（包 1~4 全部交付后）
> 面向对象：授课教师、学员、机构管理员、平台管理员
> 配套文档：《电子课堂-系统维护说明.md》（部署、配置、故障处置）

---

## 一、角色与能做什么

系统按角色区分能力，权限由服务端判定，前端只做展示。越权请求会返回 401/403，看不到按钮不代表没权限，反之亦然。

| 角色 | 标识 | 典型身份 | 核心能力 |
|---|---|---|---|
| 学员 | `student` | 报名学员 | 进课堂、听讲、举手、应答点名、聊天、上传作业、看讲稿、查看自己的出勤 |
| 教师 | `teacher` | 本课授课教师 | 开课/下课、全员静音、点名、白板与协作授权、讲稿上传与翻页、录制、作业点评、调整出勤、移出成员 |
| 机构管理员 | `admin` | 机构负责人 | 巡课、远程结束异常课堂、课堂运营台全部功能 |
| 平台管理员 | `platform_admin` | 平台方 | 同上，且可跨机构查看 |
| 系统 | `system` | 服务间调用 | 接收排期事件、回调，不用于人工登录 |

**前置条件（不满足则进不去课堂）**：

1. 机构已开通课堂功能（后台 `sys_tenant_eclassroom` 有启用记录），否则 403「本机构未开通在线课堂」。
2. 你的账号在该课堂的成员名单内（通过报名/排期生成），非成员即使知道链接也进不去。
3. 课堂状态不是 `CANCELLED`；已 `CLOSED` 的课堂只能看回放，不能进入。

## 二、进入课堂

### 2.1 入口

课堂页地址格式：

```
https://<你的域名>/classroom.html?scheduleId=<课次ID>
```

- `scheduleId` 是**课次**标识（不是课程 ID）。从「我的预约 / 排期卡片 / 上课提醒」点进来会自动带上。
- 直接手输地址时必须带这个参数，否则会被退回首页。
- 同一课次再次打开即为重连，会自动恢复到当前进度（禁言态、举手态、白板笔迹、讲稿页码、正在录音提示）。

### 2.2 进房后会自动发生什么

1. 校验身份与课堂归属 → 写成员记录、开始在线计时。
2. 建立三条长连接：**信令**（状态同步）、**白板**、**心跳**（15 秒一次）。
3. 拉取服务端当前状态并回放：谁被禁言、谁举手了、谁被授权画白板、老师讲到讲稿第几页、白板已有笔迹。
4. 顶部状态灯变绿，显示「已连接」；若显示「连接中…」超过 10 秒，见第七节排障。

### 2.3 顶部与页面构成

| 区域 | 位置 | 说明 |
|---|---|---|
| 状态灯 | 顶栏中间 | 灰=连接中，绿=已连接，红=已断开 |
| 回放 | 顶栏右侧 | 打开本节课的录制回放页（新窗口，不影响当前课堂） |
| 禁言横幅 | 状态灯下方（红色） | 全员静音时出现，学员看到即表示自己不能发言 |
| 录制横幅 | 横幅下方（红点闪烁） | 本节课正在录制，教师端还显示已录时长 |
| 成员名单 | 左侧 | 在线人数、每人角色、举手/关摄像头/可画白板等标记 |
| 视频区 | 中间上方 | 参与者画面格子；未开摄像头显示头像占位 |
| 白板区 | 中间（点「白板」切换） | 画布 + 工具条 |
| 聊天区 | 右侧 | 消息列表 + 输入框 |
| 控制栏 | 底部 | 按角色显示不同按钮 |

## 三、学员操作

### 3.1 开关麦克风 / 摄像头

- 点底部「麦克风」「摄像头」按钮切换。
- **首次进入浏览器会询问权限**，必须点「允许」，否则按钮点了没反应。
- **被全员静音时麦克风按钮点不动**：这是服务端的强控，不是浏览器问题。横幅会提示，教师解除静音后自动恢复可用。
- **学员默认不推送视频**（`classroom.rtc.student-publish-video=false`，省上行带宽），此时点「摄像头」只对自己生效，其他同学看不到你的画面。需要全班互相看脸时，由机构把该配置改为 `true` 后重启服务 —— 教师端没有「开启学生视频」这类按钮，不要在现场找。

### 3.2 举手

1. 点底部「举手」。
2. 按钮高亮，教师在名单中看到举手标记。
3. 教师点「批准开麦」后，你会收到提示，麦克风自动可用。
4. 再次点「举手」可取消。

### 3.3 应答点名

教师发起点名时，被点到的学员会弹出**强提示弹窗**「老师点名了你！」：

| 操作 | 结果 |
|---|---|
| 点「我已到」 | 应答成功，教师端显示已应答，出勤记为到课 |
| 点「稍后」 | 弹窗关闭，但 2 分钟内不答会被判超时，计入缺勤 |

- 只有**被点到的那个学员**会看到弹窗，其他人无感。
- 弹窗期间课堂画面仍在，不会打断听讲。

### 3.4 聊天

- 输入内容后回车或点发送。
- **消息由服务端广播后才显示**，不是本地先显示。网络慢时会有一两秒延迟，属正常。
- **被全员静音时无法发言**，发送后会收到「当前处于全员静音状态」提示，消息不会发出。
- 聊天内容会留档供管理员审核查阅（合规要求），请勿发送无关内容。

### 3.5 上传作业

1. 点底部「上传作业」。
2. 选择类型：

| 类型 | 要填什么 | 限制 |
|---|---|---|
| 文字 | 直接在文本框写 | 建议 2000 字以内 |
| 语音 | 选音频文件（mp3/m4a/wav） | ≤100MB |
| 图片 | 选图片文件 | ≤100MB |
| 文件 | 选任意文件 | ≤100MB |

3. 选文件后自动上传，显示进度百分比。**100MB 以内直接上传；更大的文件不支持**。
4. 上传中不要关闭页面；中断后重新点上传会从头开始（课堂作业未做断点续传，讲稿/录制有）。
5. 教师点评后，可在「作业点评」里看到评语与分数（学员端不显示他人的作业）。

### 3.6 查看讲稿

- 教师上传讲稿并翻页时，你的画面会**自动跟着翻到同一页**，不需要自己操作。
- 中途进入或刷新，会自动定位到老师当前正在讲的那一页。
- 点底部「讲稿」可放大查看；学员端只读，没有上传和翻页按钮。

### 3.7 查看自己的出勤

- 点左侧名单下方的「我的出勤」。
- 显示历史到课记录，每行四列：课程名/课次、签到时间、状态、有效时长（分钟）。
- 状态取值：**出勤 / 迟到 / 缺席 / 离开 / 重连**。
  - 「重连」表示中途断开后回来过，该段间隙不计入有效时长；
  - 「离开」表示主动点了「离开」按钮。
- 迟到判定：开课后 `classroom.late-grace-minutes`（默认 5）分钟内签到算准时，超过算迟到。

### 3.8 离开课堂

- 点底部「离开」（红色）。
- 离开后有效时长停止累计；**15~30 秒内回来不算离开**（网络闪断保护），超过则这段间隙不计入课时。

## 四、教师操作

### 4.1 开课与下课

| 操作 | 说明 |
|---|---|
| 自动开课 | 到达排期开始时间，系统自动把课堂置为 `LIVE`（默认开启，机构可在配置中关闭 `classroom.auto-start`） |
| 手动开课 | **当前界面没有「开课」按钮**。需要提前开课时，由管理员调接口 `POST /api/v1/classrooms/{课次ID}/start`，或临时把排期时间改到当前 |
| 下课 | 点底部「下课」（红色），**点击即生效，没有二次确认**。系统随即：结算出勤 → 回流课时给预约系统 → 停止录制 → 标记未完成录制为失败 |
| 自动下课 | 超过计划结束时间 5 分钟仍未手动下课，系统自动下课 |

> ⚠️ **下课后不可恢复，且按钮无二次确认**。教师点「下课」时务必确认旁边没有误触。误点后只能由管理员在运营台用「契约联调 → 重放」人工补推课时，课堂状态本身无法回退到进行中。
>
> 这条与我们常见的「红色按钮都有二次确认」习惯不一致，培训时要专门提醒。

### 4.2 全员静音

- 点底部「全员静音」切换。
- 开启后：所有学员麦克风被服务端强制静音，**学员自己解不开**，页面顶部出现红色横幅。
- 再次点击解除，学员恢复。
- **新进课堂的学员也会立即处于静音态**（状态由服务端下发，不依赖广播时在线）。

### 4.3 点名

1. 点底部「点名」。
2. 弹窗中从下拉框选一个学员；**留空则随机抽一名在线学员**。
3. 点「发起点名」，被点学员弹出强提示。
4. 弹窗下方实时显示应答状态：已应答 / 超时（2 分钟）。
5. 点「×」关闭弹窗不影响已发起的点名。

> 点名有频率限制（每分钟 10 次），连点会提示「点名过于频繁」。

### 4.4 白板

- 点底部「白板」切换显示。
- 工具条：画笔、橡皮、颜色、粗细、清空。
- **默认只有教师和已获授权的学员能画**，其他学员为只读（画布上显示「只读」）。
- 点「保存板书」立即落盘（不等自动保存）；系统每 2 秒也会自动保存一次。
- 学员刷新或中途进入，会看到**已有全部笔迹**（服务端重放）。

**授权学员协作**：

1. 在左侧名单中找到该学员。
2. 点该学员行内的「授权白板」按钮。
3. 该学员画布变为可编辑，右上角提示消失。
4. 再次点击可收回授权。

### 4.5 讲稿

1. 点底部「讲稿」打开面板。
2. 点「上传讲稿」选择文件，支持 PDF、图片（png/jpg/webp）、PPT/PPTX，≤100MB。
3. 上传后显示第一页；点「上一页 / 下一页」翻页。
4. **翻页会实时同步给所有学员**，学员端自动跟随。
5. PDF 翻页是页内跳转，不会重新下载整份文件。

> PPT/PPTX 无法在浏览器内渲染，会显示为「下载查看」；建议课前另存为 PDF 再上传。

### 4.6 录制

1. 点底部「录制」开始，按钮变红并计时。
2. 全体学员端出现「本节课正在录制」横幅（合规要求，不可关闭）。
3. 再次点击停止，系统开始上传录制文件（显示进度）。
4. 下课时若仍在录制，系统会自动停止并上传。

**必须知道的三点**：

| 事项 | 说明 |
|---|---|
| 录制内容 | 录制的是**教师本机麦克风与摄像头**（CLIENT 模式），学员画面不进录制文件 |
| 上传时机 | 停止录制后才上传，一节 90 分钟 720p 课约 400~800MB，走 5MB 分片，需要保持页面开启 |
| 保留期 | 默认 **90 天**，到期自动删除（先删文件再删记录） |

> 若机构配置了云录制（`classroom.recording.mode=cloud`）且厂商侧已接通，则由服务端录制混流画面，此时学员画面也会入镜。

### 4.7 作业点评

1. 点底部「作业点评」。
2. 列表显示本堂课所有学员提交的作业：学员、类型、内容摘要、时间。
3. 点开一条查看：文字直接显示；语音可试听；图片可预览；文件可下载。
4. 填写评语与分数（0~100），提交后学员可见，状态变为「已批阅」。
5. 已批阅的作业可再次修改评语。

### 4.8 名单操作

左侧名单每行学员右侧有三个按钮（仅教师/管理员可见）：

| 按钮 | 作用 | 注意 |
|---|---|---|
| 批准开麦 | 学员举手后批准，其麦克风解锁 | 与「全员静音」冲突时，需先解除全员静音 |
| 授权白板 | 允许该学员在白板上书写 | 可随时收回 |
| 调出勤 | 手动修正该学员的出勤状态 | 用于学员设备故障无法签到等场景，操作会留痕 |

> **移出成员目前没有界面入口**。后端有 `kick` 能力，但控制栏与名单里都没有按钮；需要移人时由管理员走后台接口或运营台处理。

### 4.9 巡课与远程下课（管理员）

管理员的课堂页与控制栏和教师不同，需要分清：

| 能力 | 教师 | 管理员 |
|---|---|---|
| 麦克风 / 摄像头 | 有 | **无**（只观察） |
| 全员静音 / 录制 | 有 | 有 |
| 点名 / 保存板书 / 作业点评 | 有 | **无** |
| 巡课 | 无 | 有 |
| 底部红色按钮 | 「下课」 | **「离开」**（管理员在课堂页内不能下课） |

**远程结束异常课堂**（卡在 `LIVE` 下不来的课）：

```bash
# 方式一：运营台「契约联调」按课次处理
# 方式二：调管理员接口
curl -X POST -H "Authorization: Bearer <管理员token>" \
  http://<域名>/api/v1/admin/classrooms/<课次ID>/end
```

行为等同教师下课：结算出勤 → 回流课时 → 停录制。**不可恢复**，操作前确认课次 ID。

## 五、运营台（管理员 / 平台管理员）

### 5.1 入口

```
https://<你的域名>/classroom-ops.html
```

> **当前没有菜单入口，需直接访问该地址**（建议后续在后台侧边栏加入口）。未登录会被拦，非管理员调用接口返回 403。

### 5.2 五个 Tab

| Tab | 回答什么问题 | 关键操作 |
|---|---|---|
| **实时监控** | 现在几节课在跑、多少人真在线、有没有异常堆着 | 看活跃课堂表（在线/名单人数）、告警列表、部署健康（RTC/录制/存储实际选型） |
| **学情报表** | 这段时间出勤率、迟到率、互动次数如何 | 选日期区间 → 查询；分「按课堂」「按学生」两张表；可导出 CSV |
| **对账差异** | 有没有课堂结束了但课时没回流等异常 | 按状态（待处理/已解决/已忽略）筛选；点「处理」填说明后关闭；「立即对账」手动跑一次 |
| **内容审核** | 学员作品与聊天内容是否需要处置 | 作品列表 → 标记违规 / 通过；输入课次 ID 调阅聊天记录（调阅动作留痕） |
| **契约联调** | 事件有没有投递成功、能不能补推 | 查事件流水 → 选中后「重放」；「重新同步」按课次补推 |

### 5.3 几个容易误解的地方

- **「已解决」vs「已忽略」**：已解决=问题真实存在且已处理；已忽略=误报或无需处理。两者都会从待处理列表移除，但统计口径不同，请如实选择。
- **重放不会重复扣课时**：系统有幂等保护，重复重放同一事件只会生效一次。
- **部署健康里的「configured ≠ active」**：配置了某服务商但关键参数缺失时会自动降级，此处显示的就是**实际生效的**那个。看到降级说明配置没生效，需查配置而不是查代码。
- **导出是流式 CSV**：时间跨度大时下载会慢一些，浏览器会先收到响应再慢慢落盘，属正常。

## 六、回放

### 6.1 入口

两个入口：

1. 课堂页顶栏「回放」按钮（新窗口打开）。
2. 直接访问：`https://<你的域名>/replay.html?scheduleId=<课次ID>`

### 6.2 使用

- 列表显示该课次所有录制：开始时间、时长、状态（录制中/已完成/失败）、大小。
- 点「播放」在页内播放，支持**拖动进度条与倍速**（0.5x~2x）。
- 只有本课次成员与管理员能看；非成员打开会提示无权限。

### 6.3 常见状态

| 状态 | 含义 | 处理 |
|---|---|---|
| 录制中 | 正在录制或正在上传 | 等下课后刷新 |
| 已完成 | 可正常播放 | — |
| 失败 | 录制中断或上传未完成 | 联系教师确认是否停止录制后关闭了页面 |

> 点击播放却提示「地址已过期」：签名地址有效期 2 小时，刷新页面重新获取即可。

## 七、学员与教师常见问题

| 现象 | 最可能原因 | 处置 |
|---|---|---|
| 页面一直「连接中…」 | 网络拦截 WebSocket，或后端 8092 不可达 | 换网络试；确认 nginx 已代理 `/ws/classrooms/`；查服务是否存活 |
| 提示「无权进入该课堂」 | 不在成员名单 / 课堂已取消 / 机构未开通课堂 | 找教务确认名单与开通状态 |
| 看不到别人的画面 | 对方未开摄像头；或 mesh 模式人数超上限（默认 6） | 超过上限的成员只收不发，需机构切 SFU（LiveKit/TRTC） |
| 听不到声音 | 被全员静音；或浏览器未授权麦克风 | 看顶部红色横幅；点地址栏图标恢复麦克风权限 |
| 麦克风按钮点不动 | 同上，服务端强控 | 请教师解除全员静音 |
| 白板画不上 | 学员默认只读 | 请教师「授权白板」 |
| 点名没弹窗 | 未点到你；或弹窗被误关 | 教师可重新发起；「稍后」关闭后 2 分钟内仍可被再次点名 |
| 上传到 99% 卡住 | 网络抖动或文件超 100MB | 换文件重试；确认大小 |
| 录制结束后没有文件 | 停止录制后立即关闭了页面，上传被中断 | 保持页面开启直到进度走完；失败记录会标记为「失败」 |
| 回放拖动卡顿 | 服务端 Range 未生效（nginx 未代理 `/api/v1/files/`） | 联系运维核查 nginx 配置 |
| 讲稿不跟随翻页 | 网络断开导致 `page:state` 未收到 | 刷新页面，会自动定位到当前页 |

## 八、给培训讲师的 3 分钟速览版

**教师课前 5 分钟**：

1. 提前进入课堂，确认状态灯为绿。
2. 上传讲稿（PDF 最稳），翻到第一页。
3. 点「录制」。
4. 学员陆续进入，左侧名单可见在线人数。

**教师课上**：

- 讲重点前点「全员静音」，提问时解除。
- 需要互动时「点名」（留空=随机）。
- 需要学员上台写，名单里点「授权白板」。
- 讲稿翻页学员会自动跟随，不用口头报页码。

**教师下课**：

1. 先停「录制」，等上传进度走完再关页面。
2. 点「下课」。
3. 到「作业点评」处理当堂作业。

**学员课前 2 分钟**：

1. 浏览器允许麦克风权限。
2. 确认状态灯为绿。
3. 需要发言先「举手」，不要直接开麦。
