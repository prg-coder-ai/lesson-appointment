## 第一部分：系统总览与选型框架

### 1.1 三类产品的定位差异

音视频课堂系统不是单一产品，而是由三类能力叠加构成的完整体系：

| 类别 | 核心价值 | 解决什么问题 | 代表产品 |
|---|---|---|---|
| **在线互动教室** | 把课上好 | 直播授课、连麦互动、板书演示、云录播 | ClassIn |
| **教务管理系统** | 把课管好 | 约课、排课、课消、收费、家校沟通 | 校管家、校宝在线、小麦助教 |
| **知识付费/内容交付 SaaS** | 把课卖好 | 线上卖课、私域运营、招生裂变、内容变现 | 小鹅通、创客匠人、短书 |

**关键结论**：没有任何一款产品能同时把三件事都做到顶尖。实际选型通常是「组合采购」——用一款上课工具 + 一款教务系统 + 一款营销工具，或者选一款相对全能的一站式 SaaS。

### 1.2 一对多授课系统的技术架构分层

从技术视角看，一套完整的一对多音视频授课系统包含以下层次：

```
┌─────────────────────────────────────────────────┐
│  客户端层（学生/教师端）                          │
│  App / 小程序 / H5 / PC / Pad                   │
├─────────────────────────────────────────────────┤
│  接入层                                          │
│  WebRTC（低延迟互动）/ RTMP-HLS（大并发直播）    │
│  CDN 分发 · 全球节点加速                        │
├─────────────────────────────────────────────────┤
│  媒体处理层                                      │
│  编解码（H.264/H.265/AAC）· 转码 · 混流         │
│  SFU/MCU · 录制 · 截图 · 水印                   │
├─────────────────────────────────────────────────┤
│  业务服务层                                      │
│  约课 · 排课 · 课消 · 教务 · 招生 · 收款        │
│  用户中心 · CRM · 订单 · 财务                    │
├─────────────────────────────────────────────────┤
│  基础设施层                                      │
│  云存储（云盘/录播回放）· 消息推送 · 短信        │
│  大数据分析 · AI 能力（语音评测/作业批改）       │
└─────────────────────────────────────────────────┘
```

**选型时需要回答的核心问题**：
1. **上课端**：需要多少人同时在线？几个人连麦互动？要不要分组讨论？——决定选 ClassIn 还是小鹅通自带直播。
2. **教务端**：学员能不能自助约课/改约？要不要撞课检测？要不要按级别排课？——决定选校管家/校宝还是轻量工具。
3. **营销端**：需不需要从公域引流？要不要分销裂变？要不要交易闭环？——决定选小鹅通/创客匠人还是纯教务系统。

## 第二部分：在线互动直播教室类

### 2.1 ClassIn（翼鸥教育 EEO）

#### 核心功能清单

| 功能项 | 是否支持 | 说明 |
|---|---|---|
| 课程预约/约课 | ⚠️ 弱 | 核心是"在线教室"，班级课表由机构后台统一建班排课，**未见面向学员的自由时段自助约课/取消/调课 C 端流程**【已查证】 |
| 智能排课 | ⚠️ 基础 | 支持建班、课表、多教师；无教务级"一人一课表/冲突自动检测"式智能排课【已查证】 |
| 课时与课消管理 | ❌ 未见 | 公开定价页/产品文档未列课消、剩余课时扣减模块【未能核实】 |
| 教务管理 | ⚠️ 偏轻 | 有班级管理、作业/测验、云盘资源、Admin Dashboard；不是完整教务 ERP【已查证】 |
| 招生营销 | ❌ 弱 | 官方"ClassIn 小店"支持开店卖课，但只是交易渠道，非 SCRM 招生裂变【已查证】 |
| 收款支付 | ✅（小店） | ClassIn 小店"0 元入驻，每笔订单仅收 2% 手续费"【已查证】 |
| 师生互动 | ✅ **强** | 13 路音视频、分组讨论、举手、答题卡、聊天、云录播回放、作业批改——互动教学是其最大强项【已查证】 |
| 小程序/App/公众号端 | ✅ | 学生/教师端 App、Windows/Mac/Pad 多端；微信生态通过小店/公众号触达【已查证】 |

**在线教室硬核参数（官方定价页）**：
- 标准版：单课最多 6 名学生上台、单课最长 4 小时、单班最多 50 人
- 加强版：12 人上台、12 小时、1000 人
- 企业版：24 小时、2000 人、支持 Web 推拉流与 API 集成

#### 适用机构规模与类型
- **类型**：少儿英语、STEAM、留学语培、职业培训、K12 学科辅导、高等院校与国际化学校【已查证】
- **规模**：从个人老师（基础版免费）到大型连锁/集团校/学区均覆盖
- **典型画像**：需要强互动在线直播课的语言培训、双师课堂、OMO 机构

#### 部署方式
- 主体为 **SaaS 云订阅**（按教师席位/月付费，云端教室+云盘）
- **私有化部署**：公开渠道未见明确私有化版本；企业版提供 API 集成、Web 推拉流，属于"开放接口"而非"私有化交付"【未能核实】

#### 收费模式与价格

**国际版公开报价（美元，按教师/月）**：

| 版本 | 价格 | 关键权益 |
|---|---|---|
| Basic | 免费 | 单课 40 分钟、每月 10 节课、5GB 云盘、20 种工具 |
| Standard | **$99 / 月 / 教师** | 6 人上台、4 小时/课、50 人、50GB、37 种工具 |
| Plus | **$199 / 月 / 教师** | 12 人上台、12 小时/课、1000 人、500GB、LTI |
| Enterprise | **$299 / 月 / 教师** | 24 小时、2000 人、Web 直播、API、1TB |

- 国内教培机构版人民币定价：**官网未公开标价，需联系销售咨询**【未能核实】
- ClassIn 小店：0 元入驻，每笔成交抽 **2% 手续费**【已查证】

#### 产品口碑与典型客户
- 厂商自称：全球 150 多个国家、60000+ 所学校和机构使用；5000 万+ 师生
- 官网客户墙：华尔街英语（Wall Street English）、Crestar Education Group 等【已查证】
- 行业口碑：在"在线互动教室"细分赛道属第一梯队，尤其双师/语言培训场景认可度高；但作为教务/招生系统常被评价"只是上课工具，不管排课消课招生"

#### 主要优点 / 不足

**优点：**
1. 互动教学能力业内顶尖（上台人数、分组、板书、37 种互动工具、云录播）
2. 大班承载强（企业版 2000 人）、全球服务器覆盖、多端体验成熟
3. 价格透明度高（国际版公开 $99–$299/教师/月），有免费入门版
4. 生态延展好（LTI、API、云盘资源库、小店卖课）

**不足：**
1. **不是教务/约课系统**——缺学员自助约课、课消、课时余额、智能排课闭环
2. 国内人民币版价格不透明，需走销售；按教师席位计费，大机构长期成本不低
3. 私有化部署选项未公开
4. 招生营销能力弱，仅靠小店 2% 抽佣交易

#### 语言教学预约场景适配度
- **约课/取消/调课**：低。ClassIn 是"建班上课"模式，不是"学员挑时段约课"模式
- **一对一 vs 小班**：✅ 都支持（1v3/1v6/1v12 上台，1v1 自然支持）
- **自由时段约课 vs 固定课表**：偏固定课表，无学员端自由时段选择
- **按学员个性化排课**：❌ 不具备该教务能力

> **小结**：ClassIn 解决"课上得好"，不解决"课怎么约、怎么排、怎么消"。语言机构若选它，需另配教务/约课系统。

#### 推荐指数：★★★☆☆（3/5）
> 一句话：在线互动直播教室的优等生，但约课/排课/课消/招生几乎空白，适合"已有教务系统、只需强上课工具"的机构。

| 小程序/App/公众号端 | ✅ | 家长端走「师生信」公众号/H5/小程序；机构端有 PC + App（含脸到 App 人脸打卡） |

#### 适用机构规模与类型
- **类型**：K12 学科类、素质教育（美术/书法/机器人/创客/舞蹈/体育）、托管、少儿编程、语言培训等
- **规模**：主打中大型连锁培训机构；厂商自称「合作 1 万+ 中大型培训学校，中大型市场份额 65%–70%」【厂商自称】
- **典型客户**：香港现代教育（45+ 校区、2 万+ 学员）、望子成龙教育集团、重庆壹心壹、艾克瑞特机器人（3 万+ 学员）、两个黄鹂等

#### 部署方式
- **SaaS 云订阅**为主（华为云/阿里云双活、信息安全等级保护三级、ISO27001 认证）【已查证】
- 私有化/本地部署：未见公开方案，**需联系销售确认**

#### 收费模式与价格
- **SaaS 年订阅**，按模块/校区/版本分档，另售 VIP 服务包
- **无公开标准报价，需联系销售咨询**；厂商称"单价从几百元到几千元不等"【厂商自称】

#### 主要优点 / 不足

**优点：**
1. 排课/课消/财务闭环成熟，图形化排课冲突检测、一对一/班课/预约课三类排课都覆盖
2. 中大型连锁校区管理经验丰富，多校区、跨校业务、总部管控能力强
3. 招生营销工具链完整（小竹通裂变、电子推荐卡、师生信转介绍）
4. 家校端「师生信」为自有微信生态，签到/点评/作业/通知一体化
5. 安全合规资质齐全（等保三级、ISO27001、双云异地备份）

**不足：**
1. 界面/交互偏传统，新用户上手需约一周学习期，功能模块多、学习曲线陡
2. 微型/1–2 个班的小机构全模块投入性价比偏低
3. 人工客服响应速度被部分用户吐槽；微信端课时/课堂评价自动化程度不足
4. 无公开价格，需销售介入，预算不透明
5. 私有化/本地部署方案未公开，技术栈封闭

#### 语言教学预约场景适配度
- **约课/取消/调课**：✅ 支持家长师生信自助约课/取消、在线排队候补、老师/教务后台排预约课、临时调课、家长发起调班调课申请在线审批，流程成熟
- **一对一与小班课**：✅ 均支持，一对一学员单独排课模块
- **自由时段约课 vs 固定课表**：两者都支持——「排预约课」支持学员按老师/校区自由预约开放时段；「班级排课」支持固定周期课表
- **按学员个性化排课**：支持按学员维度排课、按老师筛选约课入口；但「按学员级别自动推荐课表/老师」的强 AI 个性化能力需销售 Demo 验证

> **适配结论**：语言培训（尤其是一对一外教/中教、小班课、自由约课）场景适配度较高，约课—取消—候补—课消链路完整。

#### 推荐指数：⭐⭐⭐⭐（4/5）
> 一句话：排课/课消/连锁管控能力扎实，语言机构约课闭环完整，但界面老、无公开报价，更适合中大型机构。

### 6.2 POC 必测清单（针对语言培训场景）

以下五项在所有产品的公开材料中都没有完整答案，**必须在 Demo/POC 阶段实测**：

1. **学员端自助约课/改约/取消**：流程是否流畅？有没有取消时间窗？取消后排队学员是否自动递补？
2. **老师档期撞课检测**：老师已被约满时，新约课是否自动拦截？
3. **按学员级别/偏好老师排课**：系统能不能根据学员级别、学习进度自动推荐合适的老师和课表？
4. **课消规则**：请假、补课、转班、退费的课消规则怎么算？是否自动推送续费提醒？
5. **多校区财务对账**：跨校区约课的课时怎么结算？总部和校区的分成怎么算？

### 6.3 价格谈判提示

- 除小鹅通与短书标准版有公开价外，其他产品均无公开报价；
- 务必同时拉 2 家以上进入比价；
- 重点要：**按学员数/校区数/模块数**的明细报价 + 第一年实施费 + 续费涨幅 + 退费条款；
- 创客匠人完全不公开价格，必须拿到 2-3 家同类机构的实际成交价做参照；
- 小鹅通超课时/超流量/超交易额度均另收费，TCO 容易超过标称价，POC 阶段务必让销售出书面报价。

### 6.4 私有化/数据合规提示

- 本次调研的 10 款产品**均未在公开渠道给出成熟的本地/私有化部署方案**；

  - 是否支持私有化部署？
  - 数据落地区域在哪里？
  - API 开放范围有哪些？
  - 是否支持数据导出与迁移？
