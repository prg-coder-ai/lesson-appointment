### 分页机制核心说明（偏移量分页方案）

针对你的语言教学预约系统，后台列表（用户、课程、预约等）最适合用**偏移量分页（页码式分页）**，也是最通用、易维护的方案。下面从核心原理、后端实现、前端实现三个维度详细说明，完全适配你现有的 Spring Boot \+ 原生 JS 技术栈，可直接修改复用。

## 一、分页核心原理

### 核心逻辑

前端传递「当前页码 `pageNum`」和「每页条数 `pageSize`」，后端根据参数计算数据偏移量，从数据库中只查询当前页的数据，同时返回总记录数；前端据此渲染数据列表和分页控件。

### 关键公式

```Plain Text
数据偏移量 = (当前页码 - 1) × 每页条数
总页数 = 向上取整(总记录数 / 每页条数)
```

### 统一返回字段（前后端约定）

所有分页接口返回结构保持一致，前端只需一套解析逻辑：

|字段名|类型|说明|
|---|---|---|
|rows|Array|当前页的数据列表|
|total|Number|总记录数|
|pageNum|Number|当前页码|
|pageSize|Number|每页条数|
|totalPages|Number|总页数（也可前端自行计算）|

## 二、后端实现（Spring Boot \+ MyBatis\-Plus）

MyBatis\-Plus 自带分页插件，无需手动写 `limit/count` SQL，配置后直接使用，修改成本极低。

### 1\. 第一步：配置分页插件（必做）

在项目中新增 MyBatis\-Plus 分页配置类，开启自动分页能力：

```java
// config/MyBatisPlusConfig.java
@Configuration
public class MyBatisPlusConfig {
    @Bean
    public MybatisPlusInterceptor mybatisPlusInterceptor() {
        MybatisPlusInterceptor interceptor = new MybatisPlusInterceptor();
        // 添加分页拦截器，数据库类型根据实际选择（MySQL）
        interceptor.addInnerInterceptor(new PaginationInnerInterceptor(DbType.MYSQL));
        return interceptor;
    }
}
```

#### 分页返回结果

```java
// common/PageResult.java
@Data
@AllArgsConstructor
public class PageResult<T> {
    private List<T> rows;      // 当前页数据
    private Long total;        // 总记录数
    private Integer pageNum;   // 当前页码
    private Integer pageSize;  // 每页条数
    private Integer totalPages;// 总页数

    // 快速构造方法
    public static <T> PageResult<T> of(IPage<T> page) {
        return new PageResult<>(
            page.getRecords(),
            page.getTotal(),
            (int) page.getCurrent(),
            (int) page.getSize(),
            (int) page.getPages()
        );
    }
}
```

#### Service 层

```java
// service/impl/ReservationServiceImpl.java
@Override
public PageResult<ReservationVO> getPage(ReservationQuery query) {
    // 1. 构建分页对象
    Page<Reservation> page = new Page<>(query.getPageNum(), query.getPageSize());
    
    // 2. 构建查询条件（筛选逻辑）
    LambdaQueryWrapper<Reservation> wrapper = Wrappers.lambdaQuery();
    // 按状态筛选（示例）
    if (StrUtil.isNotBlank(query.getStatus())) {
        wrapper.eq(Reservation::getStatus, query.getStatus());
    }
    // 按课程名称模糊搜索（示例）
    if (StrUtil.isNotBlank(query.getCourseName())) {
        wrapper.like(Reservation::getCourseName, query.getCourseName());
    }
    // 按时间倒序，最新的在前
    wrapper.orderByDesc(Reservation::getCreateTime);
    
    // 3. 执行分页查询（MP自动执行 count + 分页数据两条SQL）
    Page<Reservation> resultPage = this.page(page, wrapper);
    
    // 4. 转换为VO返回
    List<ReservationVO> voList = BeanUtil.copyToList(resultPage.getRecords(), ReservationVO.class);
    return PageResult.of(resultPage).setRows(voList);
}
```

> 若不使用 MyBatis\-Plus，手写 SQL 逻辑完全一致：
> 
> 1. 数据 SQL：`SELECT * FROM reservation LIMIT #{pageSize} OFFSET #{offset}`
> 
> 2. 总数 SQL：`SELECT COUNT(*) FROM reservation`

### 4\. 核心分页逻辑（可复用）

封装两个通用函数：请求数据、渲染分页栏，修改列表时只需改接口地址和数据渲染逻辑。

#### ① 数据请求函数

```javascript
// 示例：加载预约列表数据（修改接口地址即可适配其他列表）
async function loadReservationList() {
  // 1. 拼接请求参数（分页参数 + 筛选参数）
  const params = new URLSearchParams({
    pageNum: pagination.pageNum,
    pageSize: pagination.pageSize,
    status: document.getElementById('status-select').value || '', // 筛选条件示例
    courseName: document.getElementById('course-name-input').value.trim() || ''
  });

  try {
    const res = await fetch(`/api/reservation/page?${params.toString()}`, {
      headers: { Authorization: localStorage.getItem('token') }
    });
    const result = await res.json();
    
    if (result.code === 200) {
      const pageData = result.data;
      // 2. 更新分页状态
      pagination.total = pageData.total;
      pagination.totalPages = pageData.totalPages;
      
      // 3. 渲染表格数据（替换为你现有表格渲染逻辑）
      renderReservationTable(pageData.rows);
      // 4. 渲染分页栏
      renderPagination();
    }
  } catch (error) {
    console.error('加载列表失败：', error);
  }
}
```

#### ② 分页栏渲染与交互函数

```javascript
function renderPagination() {
  const btnContainer = document.getElementById('pagination-btns');
  const totalCountEl = document.getElementById('total-count');
  
  // 更新总条数
  totalCountEl.textContent = pagination.total;
  
  // 无数据时不渲染页码
  if (pagination.total === 0) {
    btnContainer.innerHTML = '<span style="color:#999;">暂无数据</span>';
    return;
  }

  let html = '';
  // 上一页按钮
  html += `<button class="pagination-btn" 
            onclick="changePage(${pagination.pageNum - 1})"
            ${pagination.pageNum === 1 ? 'disabled' : ''}>
            上一页
          </button>`;

  // 页码按钮（最多显示7个页码，超出显示省略号）
  const startPage = Math.max(1, pagination.pageNum - 3);
  const endPage = Math.min(pagination.totalPages, pagination.pageNum + 3);
  
  if (startPage > 1) {
    html += `<button class="pagination-btn" onclick="changePage(1)">1</button>`;
    if (startPage > 2) html += '<span style="padding:0 4px;">...</span>';
  }

  for (let i = startPage; i <= endPage; i++) {
    html += `<button class="pagination-btn ${i === pagination.pageNum ? 'active' : ''}" 
              onclick="changePage(${i})">${i}</button>`;
  }

  if (endPage < pagination.totalPages) {
    if (endPage < pagination.totalPages - 1) html += '<span style="padding:0 4px;">...</span>';
    html += `<button class="pagination-btn" onclick="changePage(${pagination.totalPages})">${pagination.totalPages}</button>`;
  }

  // 下一页按钮
  html += `<button class="pagination-btn" 
            onclick="changePage(${pagination.pageNum + 1})"
            ${pagination.pageNum === pagination.totalPages ? 'disabled' : ''}>
            下一页
          </button>`;

  btnContainer.innerHTML = html;
}

// 切换页码
function changePage(targetPage) {
  // 边界校验
  if (targetPage < 1 || targetPage > pagination.totalPages) return;
  pagination.pageNum = targetPage;
  // 重新加载数据
  loadReservationList();
  // 滚动到表格顶部，优化体验
  document.querySelector('.card').scrollIntoView({ behavior: 'smooth' });
}

// 切换每页条数
document.getElementById('page-size-select').addEventListener('change', function() {
  pagination.pageSize = Number(this.value);
  pagination.pageNum = 1; // 切换条数后重置为第1页
  loadReservationList();
});
```

## 四、常见问题与优化点

### 1\. 删除数据后当前页为空

比如在最后一页删除最后一条数据，当前页会变成空页。优化方式：删除成功后判断当前页是否还有数据，无数据则自动跳转到上一页。

```javascript
// 删除成功后补充逻辑
if (pagination.pageNum > 1 && currentPageDataLength === 0) {
  pagination.pageNum--;
  loadReservationList();
}
```

### 2\. 防止重复请求

加载数据时禁用分页按钮，避免用户快速点击多次触发请求：

```javascript
let isLoading = false;
async function loadReservationList() {
  if (isLoading) return;
  isLoading = true;
  // ... 请求逻辑
  isLoading = false;
}
```

### 3\. 大表深分页优化

当数据量超过 10 万条时，`offset` 深分页性能会下降。可改用「ID 游标分页」：基于上一页最后一条数据的 ID 查询下一页，适合无限滚动场景；后台管理系统一般数据量不大，常规偏移量分页足够。

### 4\. 前后端参数名统一

建议前后端约定统一的分页参数名（`pageNum/pageSize` 或 `page/limit`），避免每个接口命名不一致，增加修改成本。
