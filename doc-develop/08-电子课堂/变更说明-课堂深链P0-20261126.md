## 4. 行为面影响（评审重点）

### A. 用户可见变化 —— 仅限运营台 `classroom-ops.html`

| 变化 | 原来 | 现在 |
|---|---|---|
| 临时建课结果区 | 「学生链接」与「管理员代开课」**两个**只读输入框，各带复制按钮 | **合并为一个**「课堂链接」 |
| 巡课表操作列 | 按钮文案「复制学生链接」 | 「复制课堂链接」，复制成功的 toast 同步 |
| 无有效公开基址时 | 仍产出相对路径 / 畸形链接 | 临时建课显示红字提示；巡课表不复制空值并提示 |
| 通知发送（勾选附带链接） | http / 内网环境也照发 | **被拒**并给出中文原因 |

> 合并按钮的依据：`role` 参数早已废弃（课堂页只认登录态），继续显示两个链接会让运营误以为链接分角色。

### B. 行为等价重构 —— 对用户不可见

| 位置 | 等价性依据 |
|---|---|
| 管理端 / 教师端 / 学生端「进入课堂」 | `ClassroomLink.href()` 委托同一个 `pageUrl`，产物与改动前**逐字相同**：`./classroom.html?scheduleId=…&tCode=…` |
| 「我的课堂」进课堂 / 课前准备 / 回放 | 同上；课前准备的 5 个展示元数据（start/end/state/idx/total）继续透传，参数名未变 |
| 加入课堂的粘贴解析 | 规则合并，旧格式（裸号 / `xxx~2` / 旧相对 / 旧绝对）继续可用，另新增支持 `intent=prep` |

### C. 新增约束

| 约束 | 判据 | 对既有数据的影响 |
|---|---|---|
| `scheduleId` 格式校验收紧 | `^[A-Za-z0-9_-]{4,64}(~\d{1,2})?$`（原为"非空"） | **实测无影响**：`course_schedule.schedule_id` 全为 32 位无连字符 hex，全表校验不合规 **0 条** |
| 落库 payload 的 `url` 必须为 https 绝对地址且非内网 | 无基址返回 `''`；`insecure`（非 https / localhost·回环·私网 / 来源页非 https）时拒绝 | 存量缺陷修复：此前 "http 内网打开运营台 → 生成私网链接发进通知" 的口子被堵 |

## 5. 新增能力（供后续调用）

```js
window.ClassroomLink = {
  href(spec)          // 站内相对地址，恒不出壳
  shareUrl(spec)      // 绝对地址字符串；无有效基址返回 ''
  shareUrlSafe(spec)  // { url, insecure } —— 落库/外发专用
  open(spec)          // 站内跳转
  openReplay(key)     // 回放；App 内出壳到系统浏览器（唯一合法出壳例外）
  parse(raw)          // 兼容 6 种输入形态
  isInApp()           // 仅控按钮显隐，不参与地址构造
  enabled()           // 课堂功能开关透出
  publicWebOrigin()   // 排障用
}
window.enterClassroom(key)   // 唯一全局入口，替代原 4 份重复定义
```

`spec` 形状：`{ target: 'classroom'|'prep'|'replay'|'entry', key, mode?, intent?, src?, meta?{start,end,state,idx,total} }`。**签名无 `role`**，参数白名单化（role/token/tenantId/userId 一律丢弃）。
