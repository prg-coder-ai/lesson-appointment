## 1. 微信登录闭环（一期）

### 1.1 静默登录（已绑定微信的用户）— 小程序真机/模拟器

| 步骤 | 操作 | 预期 |
|---|---|---|
| 1 | 小程序登录页点「微信登录」 | 调 `wx.login()` 拿 code → POST `/api/v1/auth/wechat-login` |
| 2 | 观察结果 | 占位 secret：`{"code":1001,"message":"微信登录失败：..."}`，页面**静默回落密码登录**（不白屏、不 401、不 500） |
| 3 | （配真实 secret 后）已绑定账号 | 200 + token/refreshToken + 用户信息，直接进入首页 |

**失败排查**：若返回 401 → 检查 `WebMvcConfig.EXCLUDE_PATTERNS` 是否含 `/api/v1/auth/wechat-login`（第四处同步点，本期刚修过 wechat-register 的同类漏配）。

### 1.2 绑定微信（Web，已登录用户）

| 步骤 | 操作 | 预期 |
|---|---|---|
| 1 | 登录后进「微信绑定」 | 展示绑定状态（未绑定） |
| 2 | 扫码授权 | POST `/api/v1/auth/bind-wechat` → 200「微信绑定成功」 |
| 3 | 刷新/查状态 | GET `/api/v1/auth/wechat-status` → 已绑定，显示绑定时间 |
| 4 | 重复绑定同一微信 | 友好提示，不产生第二条绑定记录（uk_wx_openid 全局唯一） |

### 1.3 微信直接注册（场景 C，免登录）

| 步骤 | 操作 | 预期 |
|---|---|---|
| 1 | 未登录状态 POST `/api/v1/auth/wechat-register`，body `{"code":"<真机code>","tenantCode":"TENANT_B","role":"student"}` | 200 + token + `status=pending`；账号 = openid |
| 2 | 用该账号尝试密码登录 | **登不上**（密码是随机密文，设计如此）——只能走微信登录 |
| 3 | 带**过期 token** 再调一次 | 不再被拦截器 401（一期漏配点，二期已补 WebMvcConfig 排除） |
| 4 | 同一微信重复注册 | 409「该微信已注册，请直接登录」 |
| 5 | role 传 admin | 被降级为 student（防止拿推广码扫码造租户管理员） |

### 1.4 解绑微信

| 场景 | 预期 |
|---|---|
| 未绑定账号解绑 | 404「未绑定微信」 |
| `auto_register` 来源（1.3 注册的）解绑 | 400「微信注册的账号需先设置登录密码，方可解绑」 |
| `manual` 来源（1.2 绑定的）解绑 | 200「已解绑」，之后 wechat-status 显示未绑定 |

### 1.5 小程序归因埋点（二期契约，配套推广）

| 步骤 | 操作 | 预期 |
|---|---|---|
| 1 | 小程序扫码带 `ref` 的推广码（或 URL scene 带 ref）进入 | `core/acquisition.js` 暂存归因到 storage |
| 2 | 完成登录 | `reportAttributionOnce` 只上报一次 → POST `/api/v1/user/attribution` |
| 3 | 杀进程重进 | 不重复上报（once 语义） |

## 2. 推广体系（二期）

### 2.1 生成推广码（推广者 = 任一已登录用户）

| 步骤 | 操作 | 预期 |
|---|---|---|
| 1 | 登录 → 侧栏「我的推广」→ `promo.html` | 页面加载，统计卡全 0（新推广者） |
| 2 | 点「生成推广码」 | 得到 8 位码（字符集去 0/O/1/I/l），`pathType=1`（自助建租户） |
| 3 | 再点一次 | **返回同一个码**（幂等，uk_promoter_path 兜底） |
| 4 | 点「复制链接」 | 剪贴板内容形如 `http://localhost:8080/login.html?ref=XXXXXXXX` |

### 2.2 点击计数（免登录，touch=1）

| 步骤 | 操作 | 预期 |
|---|---|---|
| 1 | **无痕窗口**打开复制出的链接 | 登录页正常渲染，URL 带 ref |
| 2 | 回业绩页看「总点击」 | +1 |
| 3 | 同窗口刷新/再进 | 不再 +1（前端 `promoClicked:<ref>` storage 去重，只上报一次） |
| 4 | 直接 GET `/api/v1/promo/referral/validate?code=XXXXXXXX&touch=0` | `{"valid":true,"pathType":1,"trialDays":14}`，不计数 |

### 2.3 路径 1：自助建租户（免登录）

| 步骤 | 操作 | 预期 |
|---|---|---|
| 1 | 无痕窗口打开带 ref 的链接 | 登录页弹出「机构注册」窗（机构名/管理员账号/姓名/电话/双密码） |
| 2 | 填写并提交 | 200；自动登录为新租户**管理员**；`tenantCode` 为 8 位新码；试用 14 天 |
| 3 | 用新管理员账号密码登录 | 成功，进入 admin.html，左侧能看到本租户数据 |
| 4 | 回推广者业绩页 | `totalRegistered +1`、`totalTenantsCreated +1`；转化明细出现一条 `registered / pathType=1 / tenantCode=新码` |

### 2.4 路径 2：加入指定租户（免登录 + 待审批）

| 步骤 | 操作 | 预期 |
|---|---|---|
| 1 | 推广者在业绩页生成路径 2 码（指定租户，如 TENANT_B） | 得到 `pathType=2, targetTenantId=<id>` 的码 |
| 2 | 无痕窗口打开对应链接 | 登录页弹出「加入租户」窗，**租户编码已锁定**（不可改） |
| 3 | 填写账号/姓名/电话/密码提交 | 200 + `status=pending`「待审批」；**不发 token**（或发了也不能用，以审批为准） |
| 4 | 该租户管理员 → 用户管理 → 审批通过 | 推广者业绩 `totalApproved +1`；转化明细该条 `stage → approved` |
| 5 | **防篡改**：路径 2 码绑租户 A，注册请求传租户 B | 拒绝：「推广码与租户不匹配，请通过官方邀请链接注册」 |

### 2.5 归因上报（已登录）

| 步骤 | 操作 | 预期 |
|---|---|---|
| 1 | 登录用户 POST `/api/v1/user/attribution`，body `{"ref":"<路径2码>"}` | 200；优先级 ref > inviter > source |
| 2 | 重复上报同一被邀请者 | 200 且**不重复计数**（`uk_conversion_invitee` 去重） |

### 2.6 缴费转化（平台管理员）

| 步骤 | 操作 | 预期 |
|---|---|---|
| 1 | 平台管理员 → 租户管理 → 找到 2.3 新建的租户 | 列表可见 `trialStatus=trial`、`referredBy=推广者userId` |
| 2 | 给该租户变更套餐（配套付钱模板） | 200「套餐变更成功」 |
| 3 | 回推广者业绩页 | 该转化 `stage → paid`（带 paidAt）；`totalPaid +1` |
| 4 | 回租户列表看该租户 | `trialStatus → converted` |

### 2.7 防刷限频

| 步骤 | 操作 | 预期 |
|---|---|---|
| 1 | 同一 IP 一小时内第 4 次调 `/api/v1/promo/register-tenant` | 拒绝：「注册过于频繁，请稍后再试」（IP 每时上限 3） |
| 2 | 换手机号再试（同 IP） | 仍被 IP 闸拦 |
| 3 | 查库 `promo_conversion.register_phone_hmac` | 手机号只存 HMAC，**无明文** |

### 2.8 code-by-account（账号 → 所属租户）

| 场景 | 预期 |
|---|---|
| 已登录用户查**自己**的账号 | 200 `{found:true, tenantCode, orgName, trialStatus}` |
| 已登录用户查**他人**账号 | 403「无权查询该账号所属租户」 |
| 平台管理员查他人 | 200（支持场景：客服排查「这个账号属于哪个公司」） |
| 未登录 | 401 |

> 语义说明：查的是「账号**所属**租户」，不是「账号创建的租户」——二期测试抓出并纠正过。

### 2.9 推广排行（平台管理员，纯 API）

```bash
curl -H "Authorization: <平台管理员token>" \
  "http://127.0.0.1:8083/api/v1/promo/achievement/overview?pageNum=1&pageSize=20"
```

| 场景 | 预期 |
|---|---|
| 平台管理员 | 200，`rows` 含各推广者业绩（按 registered/approved/paid 排序） |
| 租户管理员调同一接口 | 403 |

### 2.10 微信链路回归（占位 secret 下的正确姿态）

| 接口 | 预期 |
|---|---|
| POST `/api/v1/auth/wechat-login` `{"code":"x"}` | `code=1001`「微信登录失败：invalid appsecret...」，**不 500、不 401** |
| POST `/api/v1/auth/wechat-register` `{"code":"x","tenantCode":"TENANT_B","role":"student"}` | `code=1001`「微信授权失败...」，前端静默降级回密码注册 |
