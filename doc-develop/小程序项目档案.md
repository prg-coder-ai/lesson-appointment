## 技术栈

- 微信原生开发（WXML/WXSS/JS ES Module），style v2
- 主包：login / mine / demo / **promo（我的推广）** / **promo-landing（邀请落地）**
- 分包：package-student、package-teacher、package-admin（含 **promo-stats（推广统计）**）、package-message
- 共享层：根 `shared/` 为唯一权威源，`miniprogram/shared/` 为镜像（`npm run check:shared-sync` 看守，改动需走 sync → check → gen-bridge → build 四步）
- 网络层 `core/request.js`（Bearer 注入、401 静默刷新队列、响应解包）；登录态 `core/auth.js`；获客归因 `core/acquisition.js`（ref/inviter/source/scene）

## 已用组件与接口

**微信 API（均做存在性检测 + 失败降级；基础库版本以官方文档为准）**

| API | 用途 | 落点 |
|---|---|---|
| wx.createCanvasQRCode | 离屏 canvas 绘制小程序码 → canvasToTempFilePath 导出 | promo 页「小程序码」按钮 |
| wx.generateShortLink | 生成 URL Link（小程序链接） | promo 页「小程序链接」按钮 |
| wx.saveImageToPhotosAlbum | 小程序码保存相册（失败引导 openSetting） | promo 页二维码弹窗 |
| wx.setClipboardData | 复制推广码/链接 | promo 页 |
| onShareAppMessage | 转发分享卡片（path 带 ref/inviter） | promo / promo-landing 页 |

**后端接口（均已在 shared/apiPaths.js 登记，走 apiBase）**

| 端点 | 用途 | 调用页 |
|---|---|---|
| GET /api/v1/promo/achievement | 我的码 + 业绩汇总 + 名额 | promo |
| GET /api/v1/promo/conversions | 转化明细分页（**PageResult.rows**，非 records） | promo |
| POST /api/v1/promo/referral/code | 生成/获取推广码（只传 pathType，目标租户服务端派生） | promo |
| GET /api/v1/promo/achievement/platform | 平台统计（PLATFORM_ONLY） | promo-stats |
| GET /api/v1/promo/achievement/tenant | 租户统计（TENANT_ADMIN_ONLY） | promo-stats |
| GET /api/v1/promo/referral/validate | 校验码 + touch 点击计数（permitAll，tokenOnly 调用防 401 清场） | promo-landing |

**归因链路**：promo-landing onLoad → `captureAttribution(options)` 落盘 → 登录成功后 `reportAttributionOnce()` 上报（后端 uk_conversion_invitee 去重）。点击计数按 `promoTouched:<ref>` 去重，对齐 Web 端 `promoClicked:<ref>` 口径。

## 平台管理员登录修复（2026-10-14）

- **问题**：小程序登录页 `ROLE_OPTIONS` 只有 学生/教师/管理员 三档，**无"平台管理员"入口**；用户只能手填 `platform` + 选"管理端"(role=admin)，后端 `authController.toLogin` 落到 else 分支查 `tenantService.getByCode('platform')`→null→`403 租户编码无效或已停用`，登录失败。平台管理员登录契约要求 `tenantCode='platform'` 且 `role='platform_admin'` 同时成立。
- **修复**（`miniprogram/pages/login/` 的 js/wxml/wxss）：
  1. `ROLE_OPTIONS` 增补第 4 项 `{ role:'platform_admin', fallback:'平台' }` → 角色段出现"平台端"；选中后 `onPickRole` 自动把 `tenantCode` 锁为 `platform` 并禁用输入框。
  2. `onTenant` 输入识别：trim 后等于 `platform` 自动切到平台管理员入口（直接命中用户现有操作路径）；改回普通编码自动退回默认角色。
  3. 平台管理员选中时显示蓝色提示"平台管理员使用固定标识 platform，已自动填入，无需修改"；按钮文案 `role==='platform_admin' ? '平台管理员登录'` 早已预留，现已可触发。
- **下游已验证**：`role-tabbar` 经 `tabGroupForRole` 把 platform_admin 归入 admin 分组，复用管理端底部导航，不崩；`homePageForRole` / `constants.js` 均已覆盖 platform_admin。
- **未改后端**：后端契约正确，无需改动。注意平台管理员账号须真实存在于库（role=platform_admin, tenant_id=0），属数据侧前提。
