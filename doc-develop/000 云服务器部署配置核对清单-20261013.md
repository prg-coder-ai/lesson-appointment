# 云服务器部署配置核对清单（2026-10-13）

> 背景：本地 8080 开发代理伺服 `frontend/` 源码，从未暴露问题；一旦部署到云服务器
> （尤其国内），所有走境外 CDN 的前端依赖全部加载失败，表现为「auth.js 依赖
> utility_request.js，请先引入 utility_request.js」（axios 未定义 → utility_request.js
> 崩溃 → window.request 没挂上）以及 `index.global.min.css` 失败等。
>
> **根因**：前端 4 类库此前全部走 CDN（jsdelivivr / cdnjs / bootcdn），云服务器
> 访问境外 CDN 不稳定/被墙。本次已将全部依赖本地化（vendor 自托管），并修正构建脚本。

---

## 一、本次已完成的修复（源码侧，已提交）

| 项 | 改动 | 说明 |
|---|---|---|
| 前端依赖本地化 | 新增 `frontend/js/public/vendor/` | axios / fullcalendar / html2canvas / font-awesome(含 webfonts) 全部本地自托管，不再依赖任何 CDN |
| 12+ 个 HTML | `https://cdn...` → `js/public/vendor/...` | 全部外链改为相对路径；fullcalendar 独立 CSS 链接已删除（v6 样式由 JS 注入，独立 CSS 多余） |
| `frontend/build.js` | `copyAssets` 增加 vendor CSS 原样复制 | 原 `buildCss` 只扫 `frontend/css/`，vendor 下的 font-awesome CSS 两头都不处理 → 漏进 dist。已修 |
| `frontend/tools/check-origin.js` | `SKIP_REL` 跳过规则修正 | 原正则 `^js/vendor/` 漏掉实际路径 `js/public/vendor/`，导致 axios 内部 `http://localhost` 被误报。已改为匹配任意层级 `/vendor/` |

**部署前必须重新构建**：`cd frontend && node build.js`（已跑通，dist 内含完整 vendor 资源，含 8 个字体文件）。

## 二、部署同步清单（按类别，逐项勾选）

### A. 反向代理 / 网关（`deploy/nginx/*.conf`）
- [ ] **主服务新增接口基本无需改路由**：新增的 `/industry/options`、`/promo/*`、`/tenant/validate-code` 走兜底的 `location ^~ /api/v1/` → 8081，自动命中。
- [ ] ⚠️ **但"整片通配"只对主服务成立**：本项目是 **三服务**（8081 主 / 8090 消息 / 8092 课堂）。课堂相关接口**必须**逐个精确前缀（14 个），漏一个就 404；`/ws/classrooms/` 更必须显式配 Upgrade 头。清单见 `deploy/nginx/booking.conf` 与《000 腾讯云部署与维护手册》3.5.5。
- [ ] 三个易错前缀（**别凭名字猜**）：`/api/v1/messages*`（复数，消息）≠ `/api/v1/user`（单数，主服务）；`/api/v1/schedules/`（复数，课堂）≠ `/api/v1/schedule`（单数，主服务）；`/api/v1/eclassroom`（课堂**开关**）与 `/api/v1/classroom-callback/`（课堂**回调落点**）都属主服务 8081。
- [ ] `root /var/www/frontend` 指向的必须是 **dist 产物**（不是 `frontend/` 源码）。
- [ ] 无域名内测用 `booking-ip.conf`（`listen 80 default_server`），有域名用 `booking.conf`（HTTPS + certbot）。
- [ ] 前端静态页（promo.html 等）由 `try_files … /login.html` 兜底，无需单独配。
- [ ] `client_max_body_size` 至少 105m（课堂单文件上限 100MB）。

## 三、建议部署顺序

1. **数据库**：先导入 schema + 行业基础数据（否则后端行业端点/下拉报错）；三个库 `lesson_appointment` / `message_center` / `classroom`，并补课堂种子 `20261029-1300-eclassroom-default-instance.sql`。
2. **后端**：`mvn package` → 上传 jar → 重启 8081 / 8090 / 8092（**课堂未起不影响其他功能**）。
3. **前端**：`node build.js` → rsync dist → `/var/www/frontend`（**重点确认 vendor/ 一并上传**）。
4. **nginx**：**不是"基本无需改"**——确认三个服务的前缀都在（见 A 段）与 `/ws/classrooms/`；确认 root 指向 dist；`nginx -t && systemctl reload nginx`。
5. **环境变量**：注入 `JWT_SECRET` / `AES_KEY` / `HMAC_KEY` / `WECHAT_SECRET` / `DB_*` / `REDIS_*`。
6. **冒烟**（见下）。
