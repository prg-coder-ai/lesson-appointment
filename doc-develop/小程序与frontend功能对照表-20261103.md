# 小程序与 frontend 功能项目对照表

> 生成时间：2026-11-03 17:12
> 范围：`miniprogram/`（微信小程序原生）与 `frontend/`（Web 前端，构建产物 `dist/`）
> 对照口径：以"用户可见功能"为单位；frontend 多采用"单页多 Tab"承载，小程序采用"一页一功能"，故 frontend 一个 html 常对应小程序多个 page。

## 八、架构差异小结

| 维度 | 小程序 | frontend |
|------|--------|----------|
| 页面组织 | 一页一功能，分包加载（主包 7 页 + 4 分包 30 页 = 37 页） | 单页多 Tab，HTML 入口 16 个 |
| 角色入口 | 登录后按角色 `switchTab` 到对应分包 home | 登录后按角色 `location.href` 到 `student/teacher/admin/platform_admin.html` |
| 权限层级 | 学生 / 教师 / 管理员 三角色 | 学生 / 教师 / 管理员 / **平台管理员** 四角色 |
| 消息中心 | 独立分包（3 页） | 内嵌组件 + 管理员发送页 |
| 平台管理 | ❌ 无 | ✅ 完整平台层（11 个模块） |
| 自助建租户 | ✅ `register-tenant` | ❌ 仅平台后台创建 |
| 教师资料维护 | `profile` 单页 | `teacherInfo.html` + 编辑/发布双 JS |
| 术语系统 | `shared/` 镜像同步 | `shared/apiPaths.js` 权威源 → `shared-domain-bridge.js` 浏览器镜像 |
| 构建产物 | 微信开发者工具直接上传 | `node frontend/build.js` → `dist/`（terser 压缩） |
| 部署形态 | 微信平台托管 | Nginx 静态伺服 `dist/` |

## 十、同步关系

两端共享以下源（位于 `shared/`，经 `tools/sync-miniprogram-shared.js` 同步）：

- `shared/apiPaths.js` —— 端点常量（150 个）
- `shared/domain/*.js` —— 领域映射（message / promo / tenant 等）
- `shared/terms.js` —— 术语字典

**同步链**（改 shared 后必须走）：
```
sync-miniprogram-shared → check:shared-sync → gen-shared-bridge → frontend/build.js
```

小程序侧通过 `miniprogram/shared/` 镜像读取；frontend 侧通过 `frontend/js/shared-domain-bridge.js`（生成产物）+ `window.ApiPaths` 暴露。

> ⚠️ 改 `shared/apiPaths.js` 后若只重跑前端 build 而不重生成 bridge，会出现"源码绿、运行时 `undefined`"的静默故障（2026-10-31 端点收口时踩过）。
