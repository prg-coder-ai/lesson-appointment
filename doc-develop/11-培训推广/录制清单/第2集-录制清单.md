# 第 2 集 录制清单｜平台管理员：管租户、管套餐、管全局

| 项目 | 内容 |
|---|---|
| 片长 | 03:00（10 个镜头） |
| 连播偏移 | +02:30 |
| 录制账号 | 平台管理员 1 个（无需租户端账号） |
| 演示数据 | 2 个租户（1 个正常、1 个待停用演示）；2 个套餐模板；1 个租户未分配套餐；用户列表含正常/待审核/停用三种状态 |
| 纯素材 | 平台端各页面截图、确认框截图 |

| 镜号 | 时间段 | 录制画面 | 操作步骤 | 前置/注意 |
|---|---|---|---|---|
| 2-1 | 00:00–00:15 | 登录页角色联动 | ① 录登录卡片第 1–4 行；② 「登录身份」下拉展开并选「平台管理员」；③ 第 4 行「租户编码」自动填充并变灰只读，特写 2s；④ 点「登录系统」 | 录制前清空浏览器自动填充，避免密码框有提示 |
| 2-2 | 00:15–00:31 | 平台总览 | ① 左侧点「平台总览」；② 镜头自上而下扫过统计卡、租户趋势图、各租户在线；③ 点卡片右上「刷新」，等数据重载完成 | 刷新后数字变化要可辨，必要时先改一条测试数据 |
| 2-3 | 00:31–00:48 | 新增租户弹窗 | ① 左侧「租户管理」→ 点「新增租户」；② 依次填机构名称、租户编码、所属行业、联系人、联系电话、状态、到期时间、备注；③ 光标停在「租户编码」2s，旁挂气泡"机构登录时填写的码"；④ 点「保存」 | 机构名称用演示名，电话用 13800000000 并后期打码 |
| 2-4 | 00:48–01:05 | 租户列表行操作 | ① 点第 1 行「编辑」→ 弹窗回填 → 改联系人 → 点「保存」；② 点同租户「停用」→ 确认框「确认停用该租户？」→ 先悬停"取消"2s 再点"确定"；③ 点另一行最右红色「删除」→ 确认框同样先悬停再确认 | 删除操作在演示环境执行，保留一条可删数据 |
| 2-5 | 01:05–01:26 | 套餐分配三步卡 | ① 左侧「套餐管理」→ 顶部页签切「租户套餐」；② 点表格下方「从模板为租户创建套餐」；③ ①选租户 ②选套餐模板，右下「指定套餐」由置灰变为可点；④ 点「指定套餐」→ 额度绑定成功提示 | 先演示未选完时按钮置灰，停 2s |
| 2-6 | 01:26–01:47 | 套餐模板与额度 | ① 切回「套餐模板」页签 → 点「新增模板」；② 弹窗依次展示模板名称、模板编码、五项额度（课程/排期/用户/教师/学生上限）、状态、备注；③ 重点停留「0 表示不限」的输入框；④ 关弹窗后切「租户套餐」页签看各租户余量 | 五项额度需完整入画，可缓慢下滑表单 |
| 2-7 | 01:47–02:04 | 用户管理筛选与行操作 | ① 左侧「用户管理」；② 依次操作筛选栏：账号、姓名、全部角色、全部状态；③ 点「搜索」再点「重置」；④ 表格「公司名称」列圈注；⑤ 打开行操作列，依次悬停「编辑」「重置密码」「发消息」「启用/冻结」 | 不实际执行重置密码，悬停即可 |
| 2-8 | 02:04–02:25 | 运营统计 | ① 左侧「运营统计」→ 点卡片右上「刷新」；② 镜头扫过平台汇总统计卡；③ 「租户用量」按机构名/编码搜索一次；④ 下拉到「到期预警」表，停在临近到期行 2s | 到期预警行需真实存在，提前把某租户到期日设为 7 天内 |
| 2-9 | 02:25–02:44 | 系统设置与行业词汇 | ① 左侧「系统设置」→ 页签「行业管理/行业词汇/系统参数/协议与政策」依次点开；② 在「行业词汇」点行「编辑」，改一个显示词并保存；③ 右侧同屏切租户端刷新，界面称呼同步变化；④ 左侧分别点开「消息分类管理」「敏感词管理」 | 行业词汇改动后要能看到租户端对应词变化，提前选一个常见词 |
| 2-10 | 02:44–03:00 | 系统维护 + 收尾卡 | ① 左侧「系统维护」组依次悬停「系统日志」「审计日志」「后台信息」「数据维护」；② 进「后台信息」，切服务页签，展示运行状态与已运行时长；③ 收尾卡「平台端不管具体课程和预约」 | 运行时长数字后期打码或模糊 |

> 2-5 必须先演示「指定套餐」置灰状态；2-9 的行业词改动要提前确认能在租户端看到，否则改用已存在的词条做对比。
