二、我们与普通机构的真正区别
普通机构：靠老师个人水平，换老师就换质量。
我们：靠全流程 SOP 体系，任何老师、任何班级，质量高度统一。
普通机构：重语法、重课本、轻开口。
我们：每节课开口率≥60%，A1 就能自我介绍、问路、点餐。
普通机构：发音靠自学，纠错不系统。
我们：小语种发音标准化工程，联诵、语调、重音、小舌音统一规范。
普通机构：课后没人管，作业没人批。
我们：课前 - 课中 - 课后 24 小时闭环，作业必批、录音必听、问题必回。
普通机构：进步靠感觉，效果说不清。
我们：入学测 - 单元测 - 月度测 - 结业测，全程数据化，进步看得见。
三、核心独特能力（别人抄不走的壁垒）
1. 全链路标准化教学 SOP 体系
课前：统一预习、统一通知、统一备课
课中：统一时间轴、统一互动、统一开口训练
课后：统一作业、统一批改、统一反馈、统一复盘
实现：教学可复制、质量可控制、团队可扩张。
2. 小语种发音标准工程（法语核心优势）
统一音标、重音、联诵、省文、语调
统一动词变位、阴阳性、配合讲解逻辑
每课强制发音训练 + 录音纠音
承诺：从第一节课就地道，越学越标准。
3. 高开口率实战课堂体系
每节课开口训练≥25 分钟
对话、角色扮演、场景模拟、实景表达
课后口语录音作业 + 老师逐句点评
目标：敢说、能说、会说、说得地道。
4. 效果可视化学习追踪体系
入学水平测评 → 分级分班
单元知识点测评 → 查漏补缺
月度综合测评 → 强弱项报告
结业能力测评 → 进阶建议
家长清晰看见进步，学生明确感知成长。
5. 多小组标准化教学管理体系
教学总监 → 教研负责人 → 教学小组 → 授课教师
每组按级别 / 时段 / 人群精细化运营
听课、磨课、评课、培训、考核全闭环
保证：规模越大，质量越稳，口碑越强。
四、教学理念
小语种不是知识，是技能。
技能靠训练，不靠听讲。
标准比名师更重要，体系比个人更可靠。
发音决定第一印象，开口决定学习成果。
效果可量化，才是真教学。
五、给学生 / 家长的承诺
发音标准：不走音、不中式、不尴尬。
敢开口：不怕错、不怕笑、能交流。
效果稳：不依赖老师，不看运气，看体系。
进步看得见：每次测评有报告，每个阶段有成果。
学完就能用：日常、留学、旅行、职场均能实战。

我们不做低价竞争，
