# 课程预约系统 API 功能规格说明

## 1. 系统概述

### 1.1 项目简介
本系统是一个面向多语言教学场景的在线课程预约管理平台，支持学生、教师、管理员三种角色。系统提供完整的用户注册认证、课程模板管理、教师课程发布、排期管理、在线预约、课时管理、教师职业信息维护、数据统计等功能，同时支持多时区时间换算，满足跨地域教学需求。

- **项目名称**: lesson-appointment-api
- **版本号**: 1.0.0
- **技术栈**: Spring Boot 3.3.5 + Java 17 + MyBatis-Plus 3.5.7 + MySQL 8.0 + Spring Security + JWT
- **默认端口**: 8081
- **数据库名**: lesson_appointment

### 1.2 系统角色

| 角色 | 标识 | 说明 |
|------|------|------|
| 学生 | student | 浏览课程、预约课时、查看个人课表、评价课程 |
| 教师 | teacher | 注册资质审核、创建课程、设置排期、管理预约、维护个人职业信息 |
| 管理员 | admin | 用户审核管理、课程模板管理、全局数据统计、强制踢出用户、发布教师信息 |

## 3. 统一数据格式规范

### 3.1 统一响应格式 `Result<T>`

所有接口采用统一的JSON响应格式：

```json
{
  "code": 200,
  "message": "操作成功",
  "data": {}
}
```

| 字段 | 类型 | 说明 |
|------|------|------|
| code | Integer | 状态码：200成功，400参数错误，401未认证，403无权限，404资源不存在，500服务器错误 |
| message | String | 提示信息 |
| data | T (泛型) | 业务数据，具体类型由接口决定 |

### 3.2 分页响应格式 `PageResult<T>`

分页接口在 `Result.data` 中返回以下结构：

```json
{
  "rows": [],
  "total": 100,
  "pageNum": 1,
  "pageSize": 10,
  "totalPages": 10
}
```

| 字段 | 类型 | 说明 |
|------|------|------|
| rows | List\<T\> | 当前页数据列表 |
| total | Long | 总记录数 |
| pageNum | Integer | 当前页码 |
| pageSize | Integer | 每页条数 |
| totalPages | Integer | 总页数 |

### 3.3 认证方式

除白名单接口外，所有请求需在Header中携带Token：

```
Authorization: Bearer <accessToken>
```

**Token白名单接口**（无需认证）：
- `/auth/login` - 登录
- `/auth/refreshToken` - 刷新Token
- `/auth/logout` - 登出
- `/user/student/register` - 学生注册
- `/user/teacher/register` - 教师注册
- `/user/account/exist` - 账号查重
- `/teacher/published/latest-public` - 公开查询教师最新发布信息
- `/teacher/published/public-get` - 公开查询教师指定发布版本
- 静态资源页面 `/index.html`、`/admin.html`、`/student.html`、`/teacher.html` 等

## 4. 功能模块详细说明

### 4.1 认证与授权模块 (`/auth`)

对应代码文件: [authController.java](file:///h:/2026/lesson-appointment/api/src/main/java/com/reservation/controller/authController.java)、[SecurityConfig.java](file:///h:/2026/lesson-appointment/api/src/main/java/com/reservation/config/SecurityConfig.java)

#### 4.1.1 用户登录

- **接口**: `POST /auth/login`
- **权限**: 公开
- **请求体**:
  ```json
  {
    "account": "string (邮箱/手机号)",
    "password": "string (密码)"
  }
  ```
- **返回数据**:
  ```json
  {
    "userId": "string (用户ID-UUID)",
    "account": "string",
    "name": "string (教师姓名)",
    "role": "student/teacher/admin",
    "token": "string (JWT Access Token)",
    "refreshToken": "string (刷新Token)"
  }
  ```
- **业务逻辑**:
  1. 验证账号密码（BCrypt加密比对）
  2. 校验账号状态：冻结/待审核状态禁止登录
  3. 生成双Token（Access有效期默认10小时，Refresh持久化到数据库）
  4. 写入Spring Security安全上下文

#### 4.1.2 刷新AccessToken

- **接口**: `POST /auth/refreshToken`
- **权限**: 公开（需有效RefreshToken）
- **请求体**:
  ```json
  {
    "refreshToken": "string (旧刷新Token)",
    "account": "string (用户账号)",
    "role": "string (用户角色)"
  }
  ```
- **返回数据**:
  ```json
  {
    "token": "string (新AccessToken)",
    "refreshToken": "string (新RefreshToken)"
  }
  ```
- **业务逻辑**: 校验RefreshToken有效性→删除旧Token→生成新双Token并持久化

#### 4.1.3 用户登出

- **接口**: `POST /auth/logout`
- **请求体**: `{ "refreshToken": "string" }`
- **业务逻辑**: 清除安全上下文 + 删除数据库中的RefreshToken

#### 4.1.4 强制踢出用户（管理员）

- **接口**: `DELETE /auth/kick/{userId}`
- **权限**: 管理员
- **业务逻辑**: 删除指定用户所有RefreshToken，使其所有设备下线

#### 4.1.5 密码重置

- **接口**: `POST /auth/password/reset`
- **参数**: `account` (账号)
- **业务逻辑**: 由管理员重置用户密码（后续用户自行修改）

### 4.5 排期管理模块 (`/schedule`)

对应代码文件: [ScheduleController.java](file:///h:/2026/lesson-appointment/api/src/main/java/com/reservation/controller/ScheduleController.java)、[CourseSchedule.java](file:///h:/2026/lesson-appointment/api/src/main/java/com/reservation/entity/CourseSchedule.java)

#### 4.5.1 创建排期

- **接口**: `POST /schedule/create`
- **权限**: 教师/管理员
- **请求体 (ScheduleCreateDTO)**:
  ```json
  {
    "courseId": "string (关联课程ID)",
    "name": "string (排期名称)",
    "timeZone": "string (时区，如Asia/Shanghai)",
    "startTime": "YYYY-MM-DD HH:mm:ss",
    "endTime": "YYYY-MM-DD HH:mm:ss",
    "startDate": "YYYY-MM-DD (重复起始日期)",
    "repeatType": 0,
    "repeatInterval": 1,
    "repeatDays": "1,3,5",
    "availableSites": 1,
    "status": "active"
  }
  ```
- **repeatType说明**:
  - `0` - 不重复（单次课）
  - `1` - 每天重复
  - `2` - 每周重复（repeatDays指定周几：1=周一..7=周日）
  - `3` - 每月重复（repeatDays指定1-31号哪几天）

| `/schedule/delete/{id}` | DELETE | 删除单个排期 | 教师/管理员 |
| `/schedule/deleteByCourseId/{id}` | DELETE | 删除课程下所有排期 | 教师/管理员 |
| `/schedule/detail/{id}` | GET | 查询排期详情 | 已登录 |
| `/schedule/list` | GET | 查询排期列表 | 已登录 |

| `/schedule/selectByCourseId/{courseId}` | GET | 按课程ID查排期 | 已登录 |

#### 4.5.3 生成排期预览（本地时区）

- **接口**: `POST /schedule/generate`

- **返回**: `List<ScheduleVO>` - 用户时区下的日期+时间集合
- **说明**: 根据表单参数与时区配置，生成排期预览列表（不入库）

#### 4.5.4 排期冲突检查

#### 4.7.2 课时操作

#### 4.7.3 时间段查询（课表浏览）

- **接口**: `GET /course/appointment/statistical/listByDays`
- **参数**:
  - `days` - 近N天（如3表示未来3天）
  - `userId` - 可选，按用户过滤
  - `role` - 可选，student/teacher
  - `sortField` - 排序字段（默认appointmentDatetime）
  - `sortOrder` - asc/desc
- **说明**: 用于师生查看个人近期课表

- **接口**: `POST /course/appointment/statistical/listByDaysByPage`
- **说明**: 时间段分页查询版，支持`days<=0`查询全部历史

- **接口**: `GET /course/appointment/statistical/byMonth?year=2024&month=6`
- **返回**: `{ "appMonth": 50, "appMonthLast": 45 }`
- **说明**: 当月与上月的（active+completed）课时数统计

#### 4.7.5 N日内课时计数

- **接口**: `GET /course/appointment/statistical/onDays?ondays=7`
- **说明**: 统计当日起N日内的课时总数

## 5. 数据库ER关系概览

数据库初始化脚本: [database.sql](file:///h:/2026/lesson-appointment/api/database.sql)

```
user (用户表)
  ├─ 1:N → course (教师课程，teacher_id)
  ├─ 1:N → booking_teacher (预约，teacher_id)
  ├─ 1:N → booking_student (预约，student_id)
  ├─ 1:1 → teacher_professional (教师职业信息)
  ├─ 1:N → teacher_certificate (教师证书)
  ├─ 1:N → teacher_available_time (可预约时段)
  └─ 1:N → user_refresh_token (刷新Token)

course_template (课程模板)
  └─ 1:N → course (教师课程基于模板创建)

course (教师课程)
  └─ 1:N → course_schedule (课程排期)

course_schedule (课程排期)
  └─ 1:N → booking (学生预约)

booking (预约)
  ├─ 1:N → appointment (每个课时时间记录)
  ├─ 1:1 → course_check_in (签到记录)
  └─ 1:1 → course_evaluation (课程评价)

course (课程)
  ├─ 1:N → course_evaluation (评价)
  └─ 1:N → course_feedback (反馈，管理员处理)
```

## 6. 安全设计

### 6.1 认证机制
- **双Token机制**: Access Token（短时，放Header）+ Refresh Token（长时，持久化DB）
- **JWT算法**: 密钥存储于配置`jwt.secret`（Base64编码）
- **过期时间**: Access默认10小时（`jwt.expiration=36000000`毫秒）

### 6.2 权限控制
- 基于角色的访问控制（RBAC）：`ROLE_student` / `ROLE_teacher` / `ROLE_admin`
- 工具类 [PermissionCheck.java](file:///h:/2026/lesson-appointment/api/src/main/java/com/reservation/utils/PermissionCheck.java) 提供：
  - `checkAdmin(token)` - 仅管理员
  - `checkTeacherOrAdmin(token)` - 教师或管理员
  - `getUserIdFromToken(token)` - 从Token提取userId
  - `getRoleFromToken(token)` - 从Token提取role

### 6.3 异常处理
- 全局异常处理器 [GlobalExceptionHandler.java](file:///h:/2026/lesson-appointment/api/src/main/java/com/reservation/exception/GlobalExceptionHandler.java)
- 未认证 → 401 "未登录或登录已过期"
- 权限不足 → 403 "无权限访问该资源"
- 参数校验异常 → 400 + 具体错误信息

### 6.4 其他安全配置
- CORS跨域支持
- CSRF禁用（前后端分离+JWT场景）
- 无状态Session（`SessionCreationPolicy.STATELESS`）
- 密码BCrypt加密存储
