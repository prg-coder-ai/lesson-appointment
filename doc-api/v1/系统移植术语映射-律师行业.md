# 系统移植术语映射表：课程预约 → 律师咨询服务

> 本文档记录将「课程预约系统」移植到「律师咨询服务行业」所需的术语变更及对应关系。

---

## 一、角色映射

| 当前术语 | 英文/代码 | 律师行业术语 | 英文 |
|----------|-----------|-------------|------|
| 学生 | student | 当事人/委托人 | client |
| 教师 | teacher | 律师 | lawyer |
| 管理员 | admin | 律所管理员/运营 | admin |
| 教师ID | teacherId | 律师ID | lawyerId |
| 学生ID | studentId | 当事人ID | clientId |

## 四、状态与流程映射

| 当前术语 | 律师行业术语 | 说明 |

| 预约 confirmed | 已确认 | 律师确认预约 |

## 八、需要额外新增的字段（律师行业特有）

| 新增字段 | 说明 |
|----------|------|
| `barNumber` | 律师执业证号（不同于通用 certificate） |
| `lawFirmName` | 所在律所名称 |
| `practiceAreas` | 擅长领域（诉讼/非诉/公司法/刑事/民事等，可多选） |
| `consultFee` | 咨询费用/计费方式（按时/按次/免费） |
| `retainerAgreement` | 委托协议附件 |
| `confidentialityLevel` | 保密级别（律师有保密义务） |

---

## 九、无需修改的部分

以下模块可**直接复用**，无需术语调整：

- JWT 双 Token 认证机制
- RBAC 权限控制（三种角色结构不变）
- 排期重复规则（none/day/week/month + interval + repeatDays）
- 冲突检测算法
- 时区换算
- 分页查询框架
- 统一响应格式 `Result<T>` / `PageResult<T>`
- 静态页面生成与版本管理
