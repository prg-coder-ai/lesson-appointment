# 日志存储分析与日志浏览功能实现方案

## 一、当前日志存储现状

### 1.1 日志框架

项目使用 **Spring Boot 内置 Logback**（`ch.qos.logback`），无需额外依赖。

- 日志门面：SLF4J（通过 Lombok `@Slf4j` 注解注入）
- 日志实现：Logback Classic
- 配置文件：[logback-spring.xml](file:///h:/2026/lesson-appointment/api/src/main/resources/logback-spring.xml)

### 1.2 日志输出目标（两个 Appender）

| Appender | 类型 | 输出目标 | 编码 |
|----------|------|----------|------|
| `CONSOLE` | ConsoleAppender | 控制台（终端） | UTF-8 |
| `FILE` | RollingFileAppender | 文件 `./logs/spring-boot-app.log` | UTF-8 |

### 1.3 日志文件存储结构

```
./logs/
  ├── spring-boot-app.log              ← 当前活跃日志文件（实时追加）
  └── archived/
      ├── spring-boot-app.2026-08-13.0.log.gz   ← 按日期归档+压缩
      ├── spring-boot-app.2026-08-14.0.log.gz
      ├── spring-boot-app.2026-08-15.0.log.gz
      ├── spring-boot-app.2026-08-16.0.log.gz
      ├── spring-boot-app.2026-08-17.0.log.gz
      ├── spring-boot-app.2026-08-18.0.log.gz
      ├── spring-boot-app.2026-08-19.0.log.gz
      └── spring-boot-app.2026-08-20.0.log.gz
```

### 1.4 滚动策略

| 参数 | 值 | 说明 |
|------|-----|------|
| `maxFileSize` | 50MB | 单文件超过 50MB 时按 `%i` 索引切分 |
| `maxHistory` | 30 天 | 保留最近 30 天的归档日志 |
| `totalSizeCap` | 5GB | 所有日志文件总大小上限，超限自动清理最旧文件 |
| `cleanHistoryOnStart` | true | 应用启动时清理过期归档文件 |
| 归档文件名 | `spring-boot-app.%d{yyyy-MM-dd}.%i.log.gz` | 日期+索引，gzip 压缩 |

### 1.5 日志格式

```
%d{yyyy-MM-dd'T'HH:mm:ss.SSSXXX} %-5level %logger{36} : %msg%n
```

**实际输出示例**：
```
2026-08-21T13:58:48.930+08:00 INFO  c.r.service.CourseScheduleService : schedule 74d91b4283694d52a6dc785fd83c2713 bookingCount=1
2026-08-21T13:56:35.262+08:00 WARN  o.s.w.s.m.m.a.ExceptionHandlerExceptionResolver : Resolved [org.springframework.http.converter.HttpMessageNotReadableException: JSON parse error...]
```

### 1.8 当前存在的不足

| 问题 | 影响 |
|------|------|
| 无日志浏览界面 | 管理员只能 SSH/FTP 下载日志文件查看，无法在线浏览 |
| `e.printStackTrace()` 输出到 stderr | 不走 Logback 管道，不落盘到 FILE appender，归档日志中丢失异常堆栈 |
| 无日志级别动态调整 | 修改级别需改配置文件+重启 |
| 无日志搜索/过滤 | 无法按关键词、时间范围、级别筛选 |
| 归档日志为 .gz 压缩 | 浏览前需手动解压 |

## 二、日志浏览功能实现方案

### 2.1 功能目标

为管理员提供 Web 界面浏览系统日志，支持：

1. 实时查看当前日志文件尾部（类似 `tail -f`）
2. 按日期浏览归档日志
3. 按级别（INFO/WARN/ERROR）过滤
4. 按关键词搜索
5. 按时间范围筛选
6. 自动解压 .gz 归档文件

### 2.2 技术原理

```
┌──────────────────────────────────────────────────┐
│                    前端 (admin)                    │
│   logBrowser.html + logBrowser.js                 │
│   - 日期选择 / 级别过滤 / 关键词搜索               │
│   - WebSocket 实时推送 / AJAX 分页加载              │
└──────────────┬───────────────────────────────────┘
               │ HTTP / WebSocket
┌──────────────▼───────────────────────────────────┐
│                后端 API 层                         │
│   LogController.java                              │
│   GET  /api/logs/tail?lines=200                   │
│   GET  /api/logs/date?date=2026-08-21             │
│   GET  /api/logs/search?keyword=&level=&from=&to=│
│   WS   /ws/logs (SSE 或 WebSocket)                │
└──────────────┬───────────────────────────────────┘
               │ 文件 IO
┌──────────────▼───────────────────────────────────┐
│              文件系统层                            │
│   ./logs/spring-boot-app.log      (当前)         │
│   ./logs/archived/*.log.gz        (归档)         │
└──────────────────────────────────────────────────┘
```

### 2.3 后端实现

#### 2.3.1 LogController（新增）

```java
package com.reservation.controller;

import com.reservation.common.Result;
import org.springframework.web.bind.annotation.*;

import java.io.*;
import java.nio.file.*;
import java.time.LocalDate;
import java.util.*;
import java.util.stream.*;
import java.util.zip.GZIPInputStream;

@RestController
@RequestMapping("/api/logs")
public class LogController {

    private static final String LOG_DIR = "./logs";
    private static final String CURRENT_LOG = LOG_DIR + "/spring-boot-app.log";
    private static final String ARCHIVED_DIR = LOG_DIR + "/archived";

    // 1. 读取当前日志尾部（tail）
    @GetMapping("/tail")
    public Result<List<String>> tail(@RequestParam(defaultValue = "200") int lines) {
        try {
            List<String> all = Files.readAllLines(Path.of(CURRENT_LOG));
            int start = Math.max(0, all.size() - lines);
            return Result.ok(all.subList(start, all.size()));
        } catch (IOException e) {
            return Result.fail(500, "读取日志失败: " + e.getMessage());
        }
    }

    // 2. 按日期读取归档日志（自动解压 .gz）
    @GetMapping("/date")
    public Result<List<String>> byDate(
            @RequestParam String date,           // yyyy-MM-dd
            @RequestParam(defaultValue = "500") int maxLines) {
        // 查找匹配的归档文件（可能有多个 %i 分片）
        File dir = new File(ARCHIVED_DIR);
        File[] matched = dir.listFiles((d, name) ->
            name.startsWith("spring-boot-app." + date) && name.endsWith(".log.gz"));
        if (matched == null || matched.length == 0) {
            return Result.ok(Collections.emptyList());
        }
        // 按索引排序
        Arrays.sort(matched, Comparator.comparing(File::getName));
        List<String> result = new ArrayList<>();
        for (File f : matched) {
            try (GZIPInputStream gz = new GZIPInputStream(new FileInputStream(f));
                 InputStreamReader isr = new InputStreamReader(gz, "UTF-8");
                 BufferedReader br = new BufferedReader(isr)) {
                String line;
                while ((line = br.readLine()) != null && result.size() < maxLines) {
                    result.add(line);
                }
            } catch (IOException e) {
                return Result.fail(500, "解压归档日志失败: " + e.getMessage());
            }
        }
        return Result.ok(result);
    }

    // 3. 搜索日志（关键词 + 级别 + 时间范围）
    @GetMapping("/search")
    public Result<List<String>> search(
            @RequestParam(required = false) String keyword,
            @RequestParam(required = false) String level,   // INFO/WARN/ERROR
            @RequestParam(required = false) String date,    // 可选：限定某天
            @RequestParam(defaultValue = "500") int maxResults) {

        List<String> sourceLines = new ArrayList<>();
        // 读取当前日志或归档日志
        if (date != null && !date.isEmpty()) {
            Result<List<String>> r = byDate(date, Integer.MAX_VALUE);
            sourceLines.addAll(r.getData() != null ? r.getData() : Collections.emptyList());
        } else {
            try {
                sourceLines = Files.readAllLines(Path.of(CURRENT_LOG));
            } catch (IOException e) {
                return Result.fail(500, "读取日志失败: " + e.getMessage());
            }
        }
        // 过滤
        Stream<String> stream = sourceLines.stream();
        if (level != null && !level.isEmpty()) {
            stream = stream.filter(l -> l.contains(" " + level.toUpperCase() + " "));
        }
        if (keyword != null && !keyword.isEmpty()) {
            stream = stream.filter(l -> l.contains(keyword));
        }
        List<String> filtered = stream.limit(maxResults).collect(Collectors.toList());
        return Result.ok(filtered);
    }

    // 4. 列出可用的归档日期
    @GetMapping("/dates")
    public Result<List<String>> availableDates() {
        File dir = new File(ARCHIVED_DIR);
        File[] files = dir.listFiles((d, name) -> name.endsWith(".log.gz"));
        if (files == null) return Result.ok(Collections.emptyList());
        Set<String> dates = new TreeSet<>(Comparator.reverseOrder());
        for (File f : files) {
            // spring-boot-app.2026-08-20.0.log.gz → 2026-08-20
            String name = f.getName();
            int start = name.indexOf('.') + 1;
            int end = name.lastIndexOf('.');
            if (start > 0 && end > start) {
                dates.add(name.substring(start, name.lastIndexOf('.', end - 1)));
            }
        }
        return Result.ok(new ArrayList<>(dates));
    }
}
```

#### 2.4.2 脚本 logBrowser.js（新增）

```javascript
let autoRefreshTimer = null;

// 加载归档日期列表
async function loadDates() {
    const res = await request('/api/logs/dates');
    const select = document.getElementById('log-date');
    (res || []).forEach(d => {
        const opt = document.createElement('option');
        opt.value = d; opt.textContent = d;
        select.appendChild(opt);
    });
}

// 查询日志
async function loadLogs() {
    const date = document.getElementById('log-date').value;
    const level = document.getElementById('log-level').value;
    const keyword = document.getElementById('log-keyword').value.trim();
    let url = date ? `/api/logs/date?date=${date}&maxLines=1000`
                   : `/api/logs/tail?lines=200`;
    if (keyword || level) {
        url = `/api/logs/search?keyword=${encodeURIComponent(keyword)}&level=${level}&date=${date}&maxResults=500`;
    }
    const lines = await request(url) || [];
    const content = document.getElementById('log-content');
    content.innerHTML = lines.map(line => {
        const cls = line.includes(' ERROR ') ? 'log-line-ERROR'
                   : line.includes(' WARN ') ? 'log-line-WARN'
                   : 'log-line-INFO';
        return `<div class="${cls}">${escapeHtml(line)}</div>`;
    }).join('');
    content.scrollTop = content.scrollHeight;
}

// 自动刷新
document.getElementById('log-autorefresh').addEventListener('change', e => {
    if (e.target.checked) {
        autoRefreshTimer = setInterval(loadLogs, 3000);
    } else if (autoRefreshTimer) {
        clearInterval(autoRefreshTimer);
        autoRefreshTimer = null;
    }
});

// 初始化
loadDates();
loadLogs();
```

### 2.6 实时推送方案（可选进阶）

如需 `tail -f` 式实时推送，可用 **Server-Sent Events (SSE)**：

```java
@GetMapping(value = "/stream", produces = MediaType.TEXT_EVENT_STREAM_VALUE)
public SseEmitter stream() {
    SseEmitter emitter = new SseEmitter(0L); // 永不超时
    // 用 Tailer 监听文件变化
    TailerListener listener = new TailerListenerAdapter() {
        @Override
        public void handle(String line) {
            try {
                emitter.send(SseEmitter.event().data(line));
            } catch (IOException e) {
                emitter.complete();
            }
        }
    };
    Tailer tailer = new Tailer(new File(CURRENT_LOG), listener, 1000, true);
    new Thread(tailer).start();
    return emitter;
}
```

前端使用 `EventSource` 接收：
```javascript
const evt = new EventSource('/api/logs/stream');
evt.onmessage = e => {
    const content = document.getElementById('log-content');
    content.innerHTML += `<div>${escapeHtml(e.data)}</div>`;
    content.scrollTop = content.scrollHeight;
};
```

## 三、安全性考虑

| 风险 | 防护措施 |
|------|----------|
| 非管理员访问 | Controller 内校验 role=admin，日志接口不在白名单中 |
| 日志中含敏感信息（手机号/Token） | 日志输出前脱敏，或浏览时前端正则过滤 |
| 大文件 OOM | 使用 `BufferedReader` 流式读取 + `maxLines` 限制 |
| 路径穿越攻击 | 不接受用户传入的文件路径，只接受日期字符串拼接 |
| .gz 解压炸弹 | 限制解压后最大行数（maxLines/maxResults） |

## 四、当前日志改进建议

| 优先级 | 改进项 | 说明 |
|--------|--------|------|
| 高 | 替换 `e.printStackTrace()` | 改为 `log.error("未捕获异常", e)`，确保异常堆栈落盘到 FILE appender |
| 中 | 添加操作审计日志 | 用户登录/数据增删改操作记录到单独的 `audit.log` |
| 中 | 日志浏览功能 | 按本文方案实现 Web 日志浏览器 |
| 低 | 日志级别动态调整 | 暴露 `/api/logs/level` 接口，运行时调整 Logback logger level |
| 低 | 日志告警 | ERROR 级别日志触发邮件/飞书通知 |
