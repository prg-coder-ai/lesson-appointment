
#1【语言教学预约系统-管理端功能】

1. 课程管理
   - 查看课程列表：在“课程管理”菜单下可浏览所有课程信息。
   - 新增课程：点击页面上的“新增课程”按钮，填写相关信息后保存。
   - 编辑课程：点击某课程右侧的“编辑”按钮，在弹出的窗口中进行课程信息修改并保存。
   - 删除课程：点击“删除”按钮并确认后，可移除对应课程。

2. 教师管理
   - 查看教师列表：可浏览教师基本资料及状态。
   - 新增教师：通过“新增教师”按钮创建新教师账号，并设置初始密码。
   - 编辑教师信息：点击“编辑”按钮修改教师资料。
   - 重置教师密码：点击“重置密码”为教师账号重置为默认密码（123456）。

3. 学生管理
   - 查看学生列表：支持查阅所有学生信息。
   - 新增/编辑/删除学生与操作教师类似。
   - 重置学生密码：同教师，通过“重置密码”功能恢复默认密码。

4. 课程排期管理
   - 管理员可在“课程排期”菜单下添加、修改和删除排课计划。
   - 选择课程和教师，设置上课时间等安排。
   - 支持批量操作与高级排期筛选。
   - 支持为学生预定一个排期，自动完成预订。

5. 预约管理
   - 浏览所有学生的课程预约情况，查看排课明细。
   - 审批或拒绝学生预约申请，支持快速查找与状态筛选。

6. 教师授课统计
   - 按月份、课程或教师统计各类授课数据。
   - 点击“刷新”可获取最新授课统计。
   - 结果可导出或打印，便于教务部门管理。 

7. 其它说明
   - 屏幕右上角“退出登录”用于安全退出后台系统。
   - 如有操作权限不足或页面异常，请联系系统管理员。
   - 页面大部分操作均通过弹窗进行交互，请注意弹窗中提示信息。

   
#2 【语言教学预约系统-教师端功能】

1. 今日课程
   - 在“今日课程”栏可查看自己近1天内即将开课的课程和排课列表。
   - 展示内容包括课程名称、学生姓名、上课时段、预约状态等。
   - 支持直接确认学生预约、拒绝预约或查看课程排课详情。
   - 点击“确认”可接受预约，点击“拒绝”将拒绝学生预约申请。

2. 我的课程
   - 展示自己所教授的全部课程列表和已排课情况。
   - 支持按课程名称搜索，快速定位并管理课程。
   - 可浏览课程简介、上课次数等课程信息。
   - 点击进入可查看具体课程下的所有排课和预约详情。

3. 预订管理
   - 集中管理所属课程的所有收到的学生课程预订申请。
   - 显示预约人、预约时间、课程、当前状态等信息。
   - 对待确认的预约可进行【确认】或【拒绝】操作，已确认状态下可以发起“取消预约”。
   - 支持查看每个预约的详细信息和历史处理记录。

4. 课程评价（暂未提供）
   - 可查看学生对自己课程的全部历史评价及评分。
   - 支持筛选课程和评价时间，便于教学反馈改进。
   - 点击“查看详情”可获得完整评价内容。

5. 个人中心（暂未提供）
   - 查看与维护个人教师信息（如头像、姓名、联系方式）。
   - 仅部分字段可修改，如需更改不可编辑或重要信息请联系管理员。
   - 支持修改个人登录密码，增强账户安全。

6. 通用操作说明
   - 左侧菜单切换不同功能板块，当前活跃项高亮。
   - 教师端多数操作使用弹窗进行确认或编辑，务必关注弹窗提示。
   - 每个课时请提前10分钟进教室，按时授课，因故无法授课请及时处理。
   - 如遇系统问题、预约纠纷等可联系课程管理员协助处理。

 
#3【语言教学预约系统-学生端功能】

1. 今日课程
   - 在“今日课程”栏目下，学生可以随时查看最近7天内即将上课的所有课程列表。
   - 包含课程名称、教师、上课时间、预约状态等信息。
   - 可直接进行上课通知确认、查看详情等操作（待完成）。
   
2. 课程预订
   - 浏览可预约的课程，并进行预订操作。
   - 选择心仪的课程和排期时间后，点击预约即可发送预订请求。
   - 支持按课程、老师等条件筛选与搜索课程（待完成）。
   
3. 我的预订
   - 展示本人已预约课程的详细信息列表（预约已完成/待确认/已取消/已完成等状态）。
   - 支持撤销预约、申请取消等操作。
   - 点击“查看详情”可查看每一条预约的课堂信息及排期明细。
   
4. 课程评价（待完成）
   - 完成课程后，可对所上的课程进行评价和打分。
   - 点击“编辑评价”可修改已提交的评价内容。
   - 评价内容包含评分星级、评价文字等，便于教师持续改进教学。
   
5. 个人中心（待完成）
   - 查看并管理个人基本信息与头像。
   - 部分信息仅作为展示，如需修改请联系管理员或教师。

6. 通用操作说明
   - 左侧菜单栏切换功能板块，当前功能高亮显示。
   - 所有重要操作会有确认提示弹窗，请仔细阅读提示信息。
   - 为保证顺利上课，请提前10分钟进入教室，并保持联系方式畅通。
   - 若遇到课程、排期、预约等疑问，可联系课程导师或管理员寻求帮助。
