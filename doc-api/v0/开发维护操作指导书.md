## 1. 环境要求与准备

### 1.1 JDK 安装

| 项目 | 要求 |
|------|------|
| JDK 版本 | **JDK 17**（pom.xml `<java.version>17</java.version>`） |
| 实际验证版本 | Eclipse Adoptium JDK 21（Hotspot）也兼容，已验证可运行 |
| 推荐发行版 | Eclipse Adoptium (Temurin) |
| 下载地址 | https://adoptium.net/ |

**安装后验证**：

```powershell
java -version
# 输出示例：openjdk version "17.0.x" 或 "21.0.x"
```

**环境变量配置**（Windows）：
1. 设置系统变量 `JAVA_HOME` = `C:\Program Files\Eclipse Adoptium\jdk-21.0.8.9-hotspot`（按实际安装路径）
2. `Path` 追加 `%JAVA_HOME%\bin`

> ⚠️ [start-debug.bat](file:///h:/2026/lesson-appointment/api/start-debug.bat) 中硬编码了 `JAVA_EXE` 路径为 `C:\Program Files\Eclipse Adoptium\jdk-21.0.8.9-hotspot\bin\java.exe`。如果安装路径不同，需修改此文件。

### 1.2 Maven 安装

| 项目 | 要求 |
|------|------|
| Maven 版本 | **3.8+**（推荐 3.9.x） |
| 用途 | 依赖管理、编译打包 |
| 下载地址 | https://maven.apache.org/download.cgi |

**安装后验证**：

```powershell
mvn -version
# 输出示例：Apache Maven 3.9.x
```

**环境变量配置**（Windows）：
1. 设置系统变量 `M2_HOME` = Maven解压目录（如 `C:\apache-maven-3.9.6`）
2. `Path` 追加 `%M2_HOME%\bin`

**Maven 仓库配置**（可选，国内加速）：

编辑 `%M2_HOME%\conf\settings.xml`，在 `<mirrors>` 中添加阿里云镜像：

```xml
<mirror>
    <id>aliyunmaven</id>
    <mirrorOf>*</mirrorOf>
    <name>阿里云公共仓库</name>
    <url>https://maven.aliyun.com/repository/public</url>
</mirror>
```

### 6.4 数据查询与维护

```sql
-- 查看用户数据
SELECT user_id, account, role, status, name, create_time
FROM user
ORDER BY create_time DESC
LIMIT 20;

-- 查看待审核用户
SELECT user_id, account, role, name, status
FROM user
WHERE status = 'pending';

-- 查看教师课程
SELECT c.course_id, c.course_name, u.name AS teacher_name,
       ct.language_type, ct.difficulty_level, c.status
FROM course c
JOIN user u ON c.teacher_id = u.user_id
JOIN course_template ct ON c.template_id = ct.template_id;

-- 查看排期及预约数
SELECT s.schedule_id, s.name, s.start_time, s.end_time,
       s.available_sites, COUNT(b.booking_id) AS booking_count
FROM course_schedule s
LEFT JOIN booking b ON s.schedule_id = b.schedule_id
GROUP BY s.schedule_id;

-- 查看近7天课时
SELECT a.id, a.appointment_datetime, a.status,
       c.course_name, u.name AS teacher_name
FROM appointment a
JOIN booking b ON a.booking_id = b.booking_id
JOIN course c ON b.course_id = c.course_id  -- 需通过schedule关联course
WHERE a.appointment_datetime BETWEEN NOW() AND DATE_ADD(NOW(), INTERVAL 7 DAY)
ORDER BY a.appointment_datetime ASC;
```

## 7. 日志管理

### 7.1 日志配置

日志配置文件：[logback-spring.xml](file:///h:/2026/lesson-appointment/api/src/main/resources/logback-spring.xml)

| 配置项 | 值 | 说明 |
|--------|-----|------|
| 日志目录 | `./logs/` | 项目根目录下 logs 文件夹 |
| 当前日志文件 | `logs/spring-boot-app.log` | 实时写入 |
| 历史日志 | `logs/archived/spring-boot-app.YYYY-MM-DD.N.log.gz` | 按日期轮转+gz压缩 |
| 单文件上限 | 50MB | 超过后按 %i 索引切分 |
| 保留天数 | 30天 | 超过自动清理 |
| 总容量上限 | 5GB | 超过后清理最旧 |
| 日志格式 | `yyyy-MM-dd'T'HH:mm:ss.SSSXXX LEVEL logger : msg` | ISO时间+级别+logger+消息 |

## 9. 编码规范与开发指南

### 9.1 新增API接口步骤

以新增一个"查询课程反馈列表"接口为例：

```
1. Entity层（如已有则跳过）
   src/main/java/com/reservation/entity/CourseFeedback.java
   → @Data + @TableName + @TableId(type=ASSIGN_UUID)

2. Mapper层
   src/main/java/com/reservation/mapper/CourseFeedbackMapper.java
   → extends BaseMapper<CourseFeedback>

3. Mapper XML（如需自定义SQL）
   src/main/resources/mybatis/mapper/CourseFeedbackMapper.xml
   → 注意：同时在 src/main/java/com/reservation/mapper/ 下放一份（pom.xml资源配置会打包）

4. QueryPage（如需分页）
   src/main/java/com/reservation/query/CourseFeedbackQueryPage.java
   → extends PageQuery

5. Service层
   src/main/java/com/reservation/service/CourseFeedbackService.java
   → @Service + @Autowired Mapper

6. Controller层
   src/main/java/com/reservation/controller/CourseFeedbackController.java
   → @RestController + @RequestMapping + @Autowired Service

7. 权限白名单（如需公开访问）
   → 修改 SecurityConfig.java 添加 .requestMatchers("/feedback/**").permitAll()
```

### 9.2 统一返回格式

所有接口必须返回 `Result<T>`：

```java
// 成功
return Result.success(data, "操作成功");

// 失败
return Result.fail(400, "参数错误");

// 未登录
return Result.unauthorized("未登录或登录已过期");
```

### 9.3 权限校验

在Controller方法中调用 [PermissionCheck](file:///h:/2026/lesson-appointment/api/src/main/java/com/reservation/utils/PermissionCheck.java)：

```java
@PostMapping("/course/insert")
public Result<String> insertCourse(@RequestBody Course course, HttpServletRequest request) {
    String token = getTokenFromHeader(request);
    PermissionCheck.checkTeacherOrAdmin(token);  // 教师或管理员
    // PermissionCheck.checkAdmin(token);         // 仅管理员
    // PermissionCheck.checkTeacherOwner(token, course.getTeacherId()); // 教师+归属校验
    return courseService.insert(course);
}
```

### 9.4 分页查询规范

```java
// Controller
@PostMapping("/page")
public Result<PageResult<Course>> page(@RequestBody CourseQueryPage query) {
    return courseService.selectByPage(query);
}

// Service
public Result<PageResult<Course>> selectByPage(CourseQueryPage query) {
    List<Course> list = mapper.selectListPage(query);
    Integer total = mapper.selectCountByCondition(query);
    Page<Course> page = new Page<>(query.getPageNum(), query.getPageSize());
    page.setRecords(list);
    page.setTotal(total);
    return Result.success(PageResult.of(page));
}
```

### 9.5 事务管理

写操作必须添加事务注解：

```java
@Transactional(propagation = Propagation.REQUIRED, rollbackFor = Exception.class)
public Result<String> assignStudent(String scheduleId, String studentId, String teacherId) {
    // 1. 创建Booking
    // 2. 扣减席位
    // 3. 生成Appointment
    // 任一步失败→全部回滚
}
```

### 9.6 Mapper XML开发

XML文件需放在两个位置（[pom.xml](file:///h:/2026/lesson-appointment/api/pom.xml#L157-L171) 资源配置要求）：

```
位置1: src/main/java/com/reservation/mapper/XXXMapper.xml  （与接口同目录）
位置2: src/main/resources/mybatis/mapper/XXXMapper.xml    （标准位置）
```

> 项目中实际两个位置都有XML文件，pom.xml 的 `<resources>` 配置确保 `src/main/java` 下的XML也会被打包进JAR。

## 10. 常见问题排查

### 10.1 启动失败

| 错误现象 | 原因 | 解决方法 |
|----------|------|----------|
| `Port 8081 was already in use` | 端口被占用 | 修改 application.properties 的 `server.port` 或停掉占用进程 |
| `Communications link failure` | MySQL未启动 | 启动MySQL服务，检查 `localhost:3306` 是否可达 |
| `Access denied for user 'root'` | 密码不匹配 | 修改 application.properties 第46行 `spring.datasource.password` |
| `Unknown database 'lesson_appointment'` | 数据库未创建 | 执行 database.sql 初始化 |
| `Cannot resolve com.reservation.mapper.XxxMapper` | Mapper未被扫描 | 确认 @MapperScan 包路径包含 `com.reservation.mapper` |
| `Invalid bound statement (not found)` | XML找不到 | 检查 mybatis-plus.mapper-locations 路径，XML需在两个位置都放 |

### 10.2 中文乱码

| 场景 | 原因 | 解决方法 |
|----------|------|----------|
| 控制台日志乱码 | Windows控制台代码页非UTF-8 | `chcp 65001` 切换，或用 start-debug.bat 启动 |
| HTTP响应中文乱码 | 编码配置缺失 | application.properties 已配置6层UTF-8，检查是否被覆盖 |
| 数据库中文乱码 | 数据库字符集非utf8mb4 | `ALTER DATABASE lesson_appointment CHARACTER SET utf8mb4` |
| log文件中文乱码 | logback charset | logback-spring.xml 已配置 `charset=UTF-8` |

### 10.3 JWT认证问题

| 错误现象 | 原因 | 解决方法 |
|----------|------|----------|
| 401 未登录或登录已过期 | Token未传/过期/无效 | 重新登录获取新Token |
| 403 无权限访问该资源 | 角色不匹配 | 检查接口所需角色，使用对应角色账号登录 |
| Token过期太快 | jwt.expiration 值过小 | 修改 application.properties 第91行（当前10小时） |
| RefreshToken失效 | 旧Token已被删除 | 使用最新返回的RefreshToken，不使用旧的 |

### 10.4 热部署不生效

| 检查项 | 操作 |
|--------|------|
| DevTools是否启用 | application.properties `spring.devtools.restart.enabled=true` |
| 监控路径 | `spring.devtools.restart.additional-paths=src/main/java` |
| 排除路径 | `spring.devtools.restart.exclude` 未排除你修改的目录 |
| IDEA设置 | Settings → Build → Compiler → Build project automatically 勾选 |
| IDEA注册表 | Ctrl+Shift+A → Registry → `compiler.automake.allow.when.app.running` 勾选 |

### 10.5 数据库外键删除失败

```sql
-- 错误：Cannot delete or update a parent row: a foreign key constraint fails
-- 原因：有子表引用该记录
-- 解决：先删子表数据，或临时禁用外键检查
SET FOREIGN_KEY_CHECKS = 0;
DELETE FROM user WHERE user_id = 'xxx';
SET FOREIGN_KEY_CHECKS = 1;
```
