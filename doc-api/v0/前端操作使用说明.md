# 课程预约系统 前端操作使用说明

---

## 1. 系统访问与快速开始

### 1.1 访问地址

启动后端服务（Spring Boot默认端口 8081）后，使用浏览器访问以下入口：

| 角色 | 访问地址 | 说明 |
|------|----------|------|
| **统一登录入口** | `http://localhost:8081/index.html` | 登录后按角色自动跳转 |
| 管理员（直接） | `http://localhost:8081/admin.html` | 未登录会自动跳回index |
| 教师（直接） | `http://localhost:8081/teacher.html` | 未登录会自动跳回index |
| 学生（直接） | `http://localhost:8081/student.html` | 未登录会自动跳回index |

> 推荐直接使用 `index.html` 统一入口，系统会根据登录角色自动跳转到对应主页。

### 1.2 浏览器要求

- 推荐使用：Chrome 100+、Edge 100+、Firefox 100+
- 最低要求：需支持 ES6+、本地存储（localStorage）、Cookie
- 分辨率建议：桌面端 1366×768 及以上（响应式布局）

## 2. 统一登录与注册

**页面文件**: [index.html](file:///h:/2026/lesson-appointment/api/src/main/resources/static/index.html)

### 2.1 用户登录

登录页面向所有角色共用，操作步骤如下：

1. **打开登录页**：访问 `http://localhost:8081/index.html`
2. **输入账号**：在「账号」输入框填入注册时的邮箱或手机号
3. **输入密码**：在「密码」输入框填入登录密码
4. **点击「登录系统」**：系统验证身份
5. **自动跳转**：登录成功后 0.8 秒内根据角色自动跳转：
   - 管理员（role=admin）→ `admin.html`
   - 教师（role=teacher）→ `teacher.html`
   - 学生（role=student）→ `student.html`

**登录失败提示**：
- 账号或密码错误 → 红色文字提示「账号或密码错误，请重试」
- 账号处于待审核（pending）→ 提示账号等待审核
- 账号已冻结（frozen）/停用（inactive）→ 提示账号状态异常

### 2.2 用户注册

新用户可以自行注册学生或教师账号（管理员需由现有管理员在后台添加）。

1. **打开注册弹窗**：点击登录页底部「还没有账号？点击注册」
2. **选择注册身份**：
   - 下拉框选择「教师」或「学生」
3. **填写账号信息**：
   | 字段 | 要求 |
   |------|------|
   | 账号 | 邮箱（包含@符）或 电话号码（数字+短横线，最多30位） |
   | 真实姓名 | 必填 |
   | 密码 | 必填 |
   | 确认密码 | 必须与密码一致 |
4. **账号自动查重**：输入账号后系统会实时调用 `/user/account/exist` 接口查重，若已注册会提示「账号已存在」
5. **点击「提交注册」**：
   - 注册成功 → 弹窗提示「注册成功，请等待管理员审核」，2秒后自动跳转
   - 注册失败 → 根据错误码显示具体原因（400参数错误/500服务器错误/网络错误）

**注册后注意事项**：
- 注册后账号状态默认为 `pending`（待审核）
- 需等待管理员在后台审核通过（status→active）后才能正常登录使用
- 教师注册需额外上传资质图片（Base64格式，存储于 `qualification` 字段）

### 3.3 数据总览

点击左侧「数据总览」进入统计面板（实现：`js/admin-overall.js`）。

展示内容：
- 本月月初/月末教师数量对比
- 本月月初/月末学生数量对比
- 本月月初/月末课程数量对比
- 本月与上月预约数量对比
- 本月与上月课时数量对比

操作：
- 点击右上角「刷新」按钮 → 重新拉取最新统计数据

### 3.4 教师管理

点击左侧「教师管理」进入教师列表页（实现：`js/admin-user.js` → `renderTeacherCards("teacher")`）。

**列表展示字段**：
- 姓名、账号、邮箱、电话、教授语言、资质（缩略图）
- 状态标签（待审核/正常/停用/冻结，不同颜色区分）

**操作按钮**（每行）：
| 按钮 | 功能 |
|------|------|
| 审核通过 | 将 pending 状态改为 active（仅对 pending 用户显示） |
| 冻结 | 改为 frozen 状态，用户无法登录 |
| 停用 | 改为 inactive 状态 |
| 重置密码 | 密码重置为默认值 `12345678` |

### 3.5 学生管理

点击左侧「学生管理」进入学生列表页（实现：`js/admin-user.js` → `renderTeacherCards("student")`，复用教师组件）。

**列表展示字段**：
- 姓名、账号、邮箱、电话、学习目标、语言水平
- 状态标签（待审核/正常/停用/冻结）

**操作按钮**：与教师管理一致（审核通过/冻结/停用/重置密码）

### 3.6 课程模板管理

点击左侧「课程模板」进入模板列表页（实现：`js/admin-template.js` → `renderTemplateCards()`）。

**新增模板步骤**：
1. 点击页面顶部「新增模板」按钮 → 弹出编辑弹窗
2. 填写表单字段：
   | 字段 | 说明 |
   |------|------|
   | 语言类型 | 英语/日语/韩语/法语/德语/西班牙语（下拉选择） |
   | 难度等级 | 入门/进阶/中级/高级（下拉选择） |
   | 课时费 | 金额（≥0） |
   | 时长 | 分钟数（≥15，15的倍数） |
   | 授课形式 | 一对一/小班课/大班课 |
   | 课程描述 | 10-500字 |
   | 状态 | active/inactive |
3. 「保存」→ 系统会校验唯一性（同语言+同难度不可重复），成功后刷新列表

**编辑/删除模板**：
- 点击某行「编辑」→ 打开预填表单的弹窗，修改后保存
- 点击某行「删除」→ 二次确认后删除（同时删除关联的课程级联）

**修改模板状态**：
- 状态切换按钮 → active / inactive / frozen

### 3.7 课程列表管理

点击左侧「课程列表」进入课程列表页（实现：`js/admin-course.js` → `renderCourseCards()`）。

**列表展示**：
- 课程名称、关联模板、授课教师、课程状态、创建时间

**操作**：
- 按课程名/教师筛选
- 修改课程状态（发布/回收）
- 按模板ID批量修改状态（当多个课程共享同一模板时）
- 删除单个课程 / 按模板ID批量删除关联课程

### 3.8 课程排期管理

点击左侧「课程排期」进入排期列表页（实现：`js/admin-schedule.js` → `renderScheduleCards()`）。

**新增排期步骤**：
1. 点击「新增排期」→ 打开排期表单弹窗
2. 填写表单：
   | 字段 | 说明 |
   |------|------|
   | 所属课程 | 下拉选择已有课程 |
   | 排期名称 | 自定义名称 |
   | 时区 | 如 Asia/Shanghai、America/Toronto |
   | 开始/结束时间 | 单次课时间范围 |
   | 起始日期 | 重复排期的开始日期 |
   | 重复类型 | 不重复/每天/每周/每月 |
   | 重复间隔 | 如：每2周一次=2 |
   | 重复日 | 周重复选1-7（周几）；月重复选日期号 |
   | 可用席位 | 同时可预约学生数（默认1） |
3. **冲突检测**：点击「预览/检测冲突」→ 系统生成预览列表并检测与同教师其他排期是否时间重叠
4. 「保存」→ 入库，同时按规则展开生成实例

**其他排期操作**：
- 修改排期信息
- 增减可用席位（incSite）
- 启停排期（修改状态）
- 查看排期详情（展开后的具体时间列表）
- 删除单个排期 / 删除课程下所有排期

### 3.9 预订审核

点击左侧「预订审核」进入预约（Booking）列表页（实现：`js/admin-booking.js` → `renderBookingCards()`）。

**列表展示**：
- 预约ID、课程名称、学生姓名、教师姓名、创建时间
- 状态标签：booked（已预约，蓝）/ cancelled（已取消，灰）/ completed（已完成，绿）/ overtime（已过时，橙）

**操作**：
- 按学生/教师/状态筛选
- 修改预约状态
- 查看预约详情（包含展开后的每个课时Appointment列表）
- 删除预约

### 3.10 上课通知

点击左侧「上课通知」进入近7日课时列表页（实现：`js/admin-AppointmentNotes.js` → `refreshAppointmentNotes()`）。

**用途**：检查近期将上课的课时，给学生发送上课提醒通知。

**列表展示**：
- 课程名称、学生姓名、教师姓名、上课时间（精确到分钟）
- 课时状态：active / noted1 / noted2 / completed

**操作**：
- 「发送通知1」→ 状态改为 noted1（第一次提醒）
- 「发送通知2」→ 状态改为 noted2（第二次提醒）
- 「标记完成」→ 状态改为 completed

### 3.11 数据维护

点击左侧「数据维护」进入模块数据管理入口（实现：`js/admin-dataMaintainPage.js` → `renderDatamaintainCards()`）。

- 批量创建课程模板、课程、排期

### 5.4 课程预订

点击「课程预订」进入可预约课程浏览页（实现：`StudentBookingCards.js` → `renderStudentBookingCards()`）。

**预约流程步骤**：

```
步骤1：浏览课程卡片列表
  ↓
步骤2：筛选条件（可选）
  ├── 按语言类型筛选（英语/日语/...）
  ├── 按难度筛选（入门/进阶/...）
  └── 按关键词搜索课程名或教师名
  ↓
步骤3：点击「查看排期」按钮
  → 展开该课程下所有教师的排期列表
  → 显示每个排期的：上课时间、重复规则、剩余席位、时区
  ↓
步骤4：选定排期，点击「立即预约」
  → 弹出二次确认框：确认预约该排期？
  ↓
步骤5：确认后提交预约请求
  → 系统扣减排期可用席位（-1）
  → 创建Booking（状态=booked）
  → 按排期规则生成所有课时Appointment（状态=active）
  → 提示：预约成功！
  ↓
步骤6：在「我的预订」中查看已预约课程
```

**预约限制提示**：
- 排期「可用席位」为0时，「立即预约」按钮变灰禁用
- 同一学生重复预约同一排期会被后端拒绝返回400
- 预约成功后席位数自动递减

### 5.5 我的预订

点击「我的预订」查看自己所有的预约历史（实现：`StudentBookingBrowserCards.js` → `renderStudentBookingBrowserCards()`）。

**列表展示**：
- 预约ID、课程名称、教师姓名、预约时间、预约状态
- 每个预约下展开对应的课时详情表（含每节课日期+时间）

**预约状态说明**：
| 状态 | 颜色 | 说明 |
|------|------|------|
| booked 已预约 | 蓝色 | 已成功预约，等待上课 |
| completed 已完成 | 绿色 | 所有课时已上完 |
| cancelled 已取消 | 灰色 | 已取消的预约 |
| cancelling 申请取消中 | 橙色 | 取消申请待处理 |
| overtime 已过时 | 红色 | 预约已过期 |

**操作**：
| 操作 | 条件 | 说明 |
|------|------|------|
| 「取消预约」 | 状态=booked且未到上课时间 | 弹出确认框→改为cancelled→席位自动归还 |
| 「查看详情」 | 所有状态 | 展开完整课时列表（含每节课状态） |
| 「评价课程」 | 状态=completed（预留功能） | 弹出星级评价表单 |

### 5.6 评价课程（预留功能）

已完成的课程可进行评价：
1. 点击某已完成课程的「评价」按钮
2. 弹出评价弹窗：
   - 星级评分（点击星星选择1-5星，默认5星）
   - 评价内容文本框（不少于10字）
3. 点击「提交评价」→ 评价成功提示

## 6. 通用功能与操作规范

### 6.1 修改密码（所有角色通用）

所有页面（admin/teacher/student）加载时，`addChangePasswordButton()` 函数会自动在头部操作区注入「修改密码」按钮。

**修改密码步骤**：
1. 点击头部「修改密码」按钮 → 弹出表单
2. 输入：
   - 旧密码（Current Password）
   - 新密码（New Password）
   - 确认新密码（Confirm Password）
3. 点击「确认修改」
   - 旧密码错误 → 提示：当前密码不正确
   - 两次新密码不一致 → 提示：两次输入不一致
   - 成功 → 提示：密码修改成功，请重新登录 → 自动登出并跳回登录页

### 6.2 退出登录（所有角色通用）

**方式1**：点击头部右侧「退出」/「退出登录」按钮
**方式2**：清除浏览器 localStorage（不推荐，会导致服务端RefreshToken残留）

退出后行为：
- 清除 localStorage 中的 currentUser、token、refreshToken
- 清除 Cookie 中的 currentUser
- 跳回 `index.html` 登录页

### 6.3 页面自动登录（免二次登录）

打开页面时执行以下自动登录检查（`autoLoginCheck()` 函数）：

1. 从 localStorage 读取 `currentUser` 对象（含 userId/role/token/name）
2. 若无则从 Cookie 中读取并写回 localStorage
3. 若仍无或信息不完整 → 保存当前URL到 `saveLoginRedirect()` 后跳转 index
4. 有则正常渲染页面（头像首字母+用户名+动态内容）

**登录过期处理**：Token过期后，任何接口请求会返回 401 → 前端自动清除本地登录态 → 跳回登录页（并提示重新登录）。

### 6.4 操作弹窗规范

| 弹窗类型 | 样式 | 关闭方式 |
|----------|------|----------|
| 表单编辑弹窗（新增/编辑） | 居中白色圆角卡片+遮罩 | 点击×、点击取消、点击遮罩空白区 |
| 确认弹窗（删除/取消预约等） | `confirm()` 系统对话框（后续替换为自定义） | 点击确定/取消 |
| 错误提示 | 底部红色横幅 `showApiError()` | 2.5秒自动消失 |
| 成功提示 | `alert()` 或页面内绿色文字 | 手动关闭/自动消失 |

### 6.5 数据筛选与刷新

- 所有列表页均支持顶部筛选（按关键词、状态、时间区间）
- 「搜索」按钮提交筛选条件 → 刷新列表
- 「重置」按钮清空筛选条件
- 右上角「刷新」按钮 = 按当前筛选条件重新请求

### 6.6 时区支持说明

系统支持跨多时区教学排期：

1. **教师创建排期时**：选择自己所在地的时区（如 America/Toronto），填入当地时间
2. **学生预约/查看时**：时间自动转换为学生本地时区显示
3. **排期时间换算工具**：可通过时区转换接口手动核对（POST `/tz/switch`）

> 时差计算由后端 `ScheduleGenerator.timeSwitchWithZone()` 精确处理，确保跨时区上课时间一致。

## 7. 常见问题排查（FAQ）

| 问题现象 | 可能原因 | 解决方法 |
|----------|----------|----------|
| 打开页面显示空白/404 | 后端服务未启动 | 启动Spring Boot应用（8081端口）后刷新 |
| 注册后无法登录 | 账号待审核（pending） | 联系管理员在「教师/学生管理」中审核通过 |
| 登录后立即跳回登录页 | Token无效/localStorage清空 | 重新登录，不要在DevTools手动清除localStorage |
| 新建课程看不到 | 课程处于pending | 通知管理员审核或自行将状态改为active |
| 预约失败提示"已无席位" | 排期可用席位=0 | 选择其他排期或联系教师增加席位 |
| 取消预约按钮灰色 | 已完成/已取消/过时的预约不可取消 | 联系管理员后台处理 |
| 页面显示的时间与本地不符 | 时区配置问题 | 检查排期创建时选择的时区是否正确 |
| API请求返回401无权限 | Token过期或缺失 | 重新登录即可 |
| 头部用户头像没显示 | 用户名包含特殊字符或为空 | 不影响功能，刷新即可 |
