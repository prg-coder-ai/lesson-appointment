## 2 总体功能描述

### 2.1 产品定位

提供基于AI的口语发音自动化测评服务，支持录音/上传音频、实时评测、多维度评分、错误标注、报告生成、数据管理，可独立使用或通过API嵌入第三方系统。

### 2.2 用户角色

- **普通用户**：录音、测评、查看报告、个人历史记录

- **游客用户**：体验基础测评，功能与次数受限

- **管理员**：试题管理、用户管理、数据统计、系统配置

- **超级管理员**：权限分配、AI密钥配置、日志审计

### 2.3 核心流程

用户登录/游客 → 选择试题 → 播放标准音 → 录音/上传 → 提交评测 → AI处理 → 生成评分与错误标注 → 展示报告 → 保存记录

## 3 功能需求详细说明（按模块）

### 3.1 音频采集与预处理模块

#### 3.1.1 实时录音功能

1. 支持录音开始、暂停、继续、取消、重录、试听。

2. 支持录音波形可视化展示。

3. 支持录音时长限制：短句≤60s，段落≤180s。

4. 支持前端本地检测静音、过短音频（<1s）并提示重录。

5. 录音异常中断时支持缓存或提示重新录制。

#### 3.1.2 音频上传功能

1. 支持本地音频上传，格式限定：MP3、WAV。

2. 支持文件大小限制：单文件≤20MB。

3. 支持分片上传与基础断点续传。

4. 上传前校验格式、时长、文件有效性。

#### 3.1.3 音频预处理功能

1. 自动转码为统一格式：16kHz、单声道、16bit。

2. 支持静音裁剪、音量归一化、基础降噪。

3. 过滤无效音频：空文件、损坏文件、无法解码文件。

### 3.3 核心发音评测模块（核心）

#### 3.3.1 多维度评分功能

系统必须输出以下评分：

1. **总分**：0–100分。

2. **准确度**：音素、单词发音标准性。

3. **流利度**：停顿、重复、卡顿、语速。

4. **完整度**：漏读、增读、替换、篡改。

5. **等级评定**：A(90–100)、B(80–89)、C(60–79)、D(<60)。

#### 3.3.2 错误识别功能

支持以下错误类型检测与标记：

1. 单词级：错读、漏读、增读、重读、替换。

2. 音素级：元音错误、辅音错误、重音位置错误、长短音混淆。

3. 流利类：过长停顿、频繁重复、拖音、卡顿。

4. 句子级：整句漏读、语序混乱。

#### 3.3.3 评测反馈功能

1. 文本内对错误单词进行颜色区分：

    - 错读：红色

    - 漏读：灰色删除线

    - 重读：黄色下划线

2. 提供错误单词、标准音标、纠正建议。

3. 输出诊断结论，如“/θ/发音偏/s/，注意咬舌”。

#### 3.3.4 评测控制功能

1. 支持单用户短时防重复提交。

2. 支持游客每日评测次数限制。

3. 支持并发控制与接口限流。

## 4 异常处理需求（标准章节）

### 4.1 音频采集异常

1. 麦克风无权限/不可用：引导授权，给出系统设置路径。

2. 无声/纯噪音/爆音：自动检测并提示重新录制。

3. 录音中断/页面崩溃：提示异常，支持重新开始。

### 4.2 音频上传异常

1. 格式非法/文件损坏：直接拦截，提示“格式不支持或文件损坏”。

2. 时长超限：前端拦截+后端校验，拒绝处理。

3. 上传超时/网络失败：提示重试，不产生脏数据。

### 4.3 评测执行异常

1. AI服务超时、宕机、限流：返回友好提示，记录异常日志。

2. 返回结果为空/分值异常（0或100不合理值）：标记评测异常，不入库。

3. 音频无法解码/内容为空：提示“音频无效，请重新录制”。

### 4.4 业务规则异常

1. 游客次数超限：提示升级或登录。

2. 重复提交：幂等控制，直接返回上次结果或拒绝。

3. 越权访问他人记录：返回403，记录安全日志。

### 4.5 系统运行异常

1. 存储服务不可用：禁止上传，提示系统异常。

2. 数据库异常：统一捕获，返回安全提示，不暴露堆栈。

3. 接口被恶意攻击：触发限流，拉黑异常IP。

## 5 业务规则与约束

1. 音频数据存储有效期：普通用户30天，可后台配置。

2. 同一音频短期内重复提交只算一次有效评测。

3. 评测必须依赖参考文本，无文本不允许评测。

4. 管理操作必须留痕，不可匿名修改系统配置。

---

## 6 接口需求（统一规范）

1. 协议：HTTPS

2. 风格：RESTful

3. 请求头统一携带：Authorization: Bearer {token}

4. 统一返回结构：code、msg、data

5. 状态码：200成功、400参数错误、401未登录、403无权限、500服务异常

1. 所有功能点均需实现并可正常运行。

3. 评测流程完整闭环：录音→上传→评测→报告→记录。

4. 管理后台可正常配置、统计、审计。
