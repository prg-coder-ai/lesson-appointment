# 尚未实现的功能点清单

### 尚未实现的功能点清单

对照需求分析文档与已完成功能点，按「**全端公共体系**」「管理端」「教师端」「学生端」四个维度整理如下：

---

## 一、全端公共体系（核心流程缺失）

### 1\. 用户注册与认证体系

- 学生自主注册：手机号 / 邮箱 / 第三方账号注册、个人学习信息（学习目标、语言基础）填写

- 教师入驻申请：提交个人信息与资质证明（教师资格证、语言等级证书），等待管理员审核

- 密码找回：通过手机验证码 / 邮箱验证重置密码

- 教师账号审核激活流程：管理员核验资质，审核通过后账号正式启用

### 2\. 全链路消息通知体系

- 预约结果通知（成功 / 拒绝 / 取消）、课程开始前 1 小时提醒

- 通知渠道：站内信、短信 / 邮件提醒

- 统一消息中心：三端均支持查看历史通知

### 3\. 课程状态流转体系

- 完整的订单 / 预约状态流转：待支付 → 待确认 → 已预约 → 上课中 → 已完成 → 已评价 / 已取消

- 状态变更自动触发对应通知与数据更新

---

## 二、管理端未实现功能

### 1\. 用户管理类

- 教师入驻申请审核：查看教师提交的资质材料，执行「通过 / 驳回」操作

- 账号状态管控：学生 / 教师账号的冻结、解封（违规处理）

- 学生课时余额管理：余额查询、手动调整、充值 / 扣款记录

### 2\. 课程与排期类

- 课程模板体系：管理员配置课程基础模板（语言类型、难度等级、课时费、课程时长），教师基于模板创建具体课程

- 课程分类维护：课程分类的新增、编辑、删除

- 排期规则增强：支持按周重复排期、批量设置不可用时段

- 线上课堂 / 线下教室配置：统一维护线上课堂链接、线下教室地址

### 3\. 订单与退款类

- 全量订单管理：查看所有订单（待支付 / 已预约 / 已完成 / 已取消 / 退款中）

- 退款申请处理：审核学生 / 教师的取消退款申请，按规则处理余额退还

- 订单数据筛选与导出

### 4\. 评价与运营类

- 评价审核：审核学生提交的课程评价，删除 / 隐藏违规评价

- 预约运营：向指定学生 / 教师批量发送课程通知

- 近 7 日预约专项视图

### 5\. 数据统计类

仅实现「教师授课统计」，以下维度缺失：

- 课程预约量趋势统计

- 学生留存率统计

- 多维度运营报表（预约转化、课程热门度、用户增长等）

## 三、教师端未实现功能

### 1\. 课程与排期管理

- 自主创建课程：基于管理员发布的课程模板，创建个人授课课程并填写教学详情

- 自主设置排期：在日历中设置可授课时间段，支持按周重复、标记不可用时段

- 排期调整：手动修改 / 删除个人排期，实时同步学生端可预约状态

### 2\. 课程执行流程

- 课程提醒接收：接收课程开始前的系统提醒

- 线下课程扫码确认上课，更新课程状态

- 提交课程记录：填写本节课学习内容、学生表现等教学记录

- 主动取消课程：因特殊原因取消课程，填写取消理由并提交审核

### 3\. 课程评价模块（已标注「暂未提供」）

- 查看学生全部历史评价与评分

- 按课程、时间筛选评价

- 查看单条评价的完整内容

### 4\. 个人中心（已标注「暂未提供」）

- 个人信息编辑：头像、姓名、联系方式、个人简介

- 资质信息维护：上传 / 更新教师资格、语言等级证明

- 登录密码修改

### 5\. 其他

- 消息通知中心：查看预约、取消、提醒等系统通知

- 个人授课数据统计

---

## 四、学生端未实现功能

### 1\. 课程浏览与筛选

- 多条件课程筛选：按语言类型、难度等级、课程形式（一对一 / 小班课）、教师类型（中教 / 外教）筛选

- 教师详情页：查看教师资质、历史评分、可预约时间段

- 课程详情完整展示：教学内容、课程特色、课时费用说明

### 2\. 预约体验优化

- 日历视图选时段：通过日历选择预约日期，已预约时段自动标灰不可选

- 预约订单确认：提交预约后生成待支付订单，展示费用明细

- 余额支付：使用课时余额完成预约支付

### 3\. 课程执行相关

- 课程提醒接收：上课前 1 小时提醒

- 线上课堂入口 / 线下教室地址查看

- 上课确认功能

### 4\. 课程评价模块（已标注「待完成」）

- 课程结束后进行星级评分（1\-5 星）\+ 文字评价

- 编辑已提交的评价内容

### 5\. 预约变更与退款

- 取消规则提示：明确展示「24 小时前取消可延期、超时取消不退款」的规则

- 取消预约后自动处理课时余额 / 延期次数

- 查看取消记录与退款明细

### 6\. 个人中心（已标注「待完成」）

- 个人信息编辑：头像、学习目标、语言基础、联系方式

- 课时余额查看与充值记录

- 登录密码修改

### 7\. 其他

- 消息通知中心：查看预约结果、课程提醒、取消通知等

- 我的评价列表：查看自己提交过的所有课程评价
