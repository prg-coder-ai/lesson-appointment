《法语在线教学・教学体制 + 多小组管理方案》
完全落地、可直接当制度发下去。
一、整体教学体制（顶层设计）
1. 组织架构（极简、高效）
教学总监 → 教研组长 → 教学小组 → 法语老师
教学总监：定标准、定 SOP、定质量、定考核
教研组长（每语种 1 名）：法语专属教研、磨课、质检
教学小组（3～5 人 / 组）：
每组 = 1 组长 + 3～4 名法语老师
负责：固定班级、固定学生、固定服务
优势：
小组制 = 质量可控、新人好带、扩科不混乱
二、多教学小组怎么管？（核心）
1. 小组划分规则（法语专用）
按这 3 种方式分，不乱：
按级别分
A1 小组、A2 小组、B1 + 小组
优点：内容统一、教研轻松
按班级类型分
成人班小组、少儿班小组、留学考试小组
按区域 / 时段分
早班组、晚班组、周末组
推荐：按级别分最稳。
2. 小组管理铁律（必须执行）
每组固定负责人：小组组长
安排课表
监督本组 SOP 执行
每周磨课、评课
新人带教
统一教材 + 统一教案 + 统一课件
所有小组不能自己乱做内容
统一课堂流程
你前面那套法语 SOP，全小组强制执行
统一作业、统一测评、统一反馈模板
一句话：
内容不同，流程完全相同。
三、教学管理的 5 条硬制度（能管住人）
1. 备课管理制度
老师必须用统一法语教案模板
组长课前审核教案
无教案不许上课
2. 课堂质检制度
组长每两周听每老师 1 节课
按统一评分表打分：
发音标准
流程完整
开口率
互动效果
评分低于 80 分必须重修 + 重磨课
3. 作业批改制度
24 小时内批改
必须用统一点评模板
组长抽查作业批改质量
4. 学情反馈制度
每单元必须给家长 / 学生发学情报告
每月一次阶段测试 + 成绩报表
小组组长审核所有报告
5. 教研磨课制度
每组每周固定 1 次教研
内容：
动词变位怎么讲更简单
发音、联诵怎么教
易错点总结
优秀课堂分享
四、多小组如何做到 “质量一样强”？
1. 全部标准化
法语发音标准
阴阳性、配合、联诵讲解标准
动词变位教法标准
课堂话术标准
组长负责把标准压到每一个人。
2. 新人快速上岗机制（小组制最强优势）
老教师带新教师
统一磨课
统一模仿优秀课堂
1 周可上岗，3 周达标准水平
3. 数据化管理，不靠感觉
每组每周必须上报：
出勤率
作业完成率
24h 批改率
开口率
学生好评率
数据低 = 小组组长负责整改。
五、考核机制（让老师愿意执行 SOP）
小组考核
课堂质量
SOP 执行率
学生续报 / 口碑
测评成绩
个人考核
备课完整度
课堂评分
作业批改及时率
学生好评
考核结果直接和：
课时费、奖金、晋升组长挂钩
六、最核心一句话（你做体制一定要记住）
普通机构：靠优秀老师。
顶级机构：靠优秀体制。
你这套法语 SOP + 小组制 = 可复制、可扩张、可做品牌。
