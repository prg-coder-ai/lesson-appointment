# 小程序上线与域名白名单说明

> 配套：`miniprogram/` 工程。appid 与域名当前均为**占位符**，正式上线前需替换。

## 1. 占位符清单（待实际确定）

| 项 | 占位值 | 说明 |
| --- | --- | --- |
| 小程序 appid | `touristappid` | 微信公众平台分配的正式 appid，写在 `project.config.json` 与 `app.json` 无关 |
| 业务端域名 `apiBase` | `https://api.example.com` | `app.js` 的 `globalData.apiBase`（预约/课程/排期/用户） |
| 消息服务域名 `msgBase` | `https://msg.example.com` | `app.js` 的 `globalData.msgBase`（消息中心 / 敏感词） |

> 注意：小程序**不校验 CORS**，而是校验「服务器域名白名单」。请将下面两个域名（含 `https://` 前缀）加入白名单，且必须为 **HTTPS** 备案域名。

## 2. 服务器域名白名单（微信公众平台 → 开发管理 → 开发设置 → 服务器域名）

| 类型 | 需配置域名 | 本工程用途 |
| --- | --- | --- |
| request 合法域名 | `https://api.example.com`<br>`https://msg.example.com` | 所有 `wx.request`（鉴权/业务/消息） |
| uploadFile 合法域名 | （暂不需要） | 当前无文件上传 |
| downloadFile 合法域名 | 如有静态资源/CDN 域名再加 | 头像/图片等 `wx.downloadFile` |
| socket 合法域名 | （暂不需要） | 小程序**无 SSE**，消息中心采用轮询，无需 socket |
| UDP 合法域名 | （暂不需要） | — |
| 业务域名 | （暂不需要） | 当前无 `web-view` 嵌入 |

## 3. 开发阶段联调

- `project.config.json` 已设 `"urlCheck": false`，开发者工具中**不校验合法域名**，可直接用本地/内网地址联调。
- 真机预览/体验版：**仍会校验白名单**，需先在第 2 节配好真实 HTTPS 域名。
- 勾选「不校验合法域名」仅对开发者工具有效，不能用于生产。

## 4. 分包与体积优化

- 主包保留高频入口：`login / 三个首页 / mine / demo`。
- 深页打入分包：`pages/student`、`pages/teacher`、`pages/admin`、`pages/message`（`app.json` 的 `subpackages`）。
- `preloadRule`：进入首页/个人中心时预下载对应分包，降低首次跳转延迟。
- 共享核心 `shared/`、`core/` 置于主包，分包页面通过相对路径引用（已验证可跨包引用主包模块）。
- 如主包仍过大，可把 `demo` 页移出或进一步拆分教师/管理分包。

## 5. 上传与 CI

- 上传工具：`miniprogram-ci`（见 `scripts/upload.js`）。
- 私钥：`微信公众平台 → 开发管理 → 开发设置 → 小程序代码上传` 下载 **上传密钥**，存于本地，**切勿入库**。
- 命令：
  ```bash
  MINI_PRIVATE_KEY=/path/to/private.key npm run upload 1.0.0 "本次提交说明"
  ```
- 上传前请先执行 `npm run sync` 同步最新的 `shared/` 到 `miniprogram/shared/`。
- 建议 CI：在流水线中 `npm run sync` → `npm run upload`，密钥通过 CI 变量注入。
