## 1. 系统组成与角色总览

### 1.1 系统定位

本系统是一套面向语言教学（可适配法律、咨询等其他行业）场景的在线课程预约管理 SaaS 平台，覆盖：用户注册与审核、课程模板与课程管理、排期与候补、在线预约、课时（课次）跟踪、上课通知、消息中心、教师资料发布、退改与通知规则、推广统计、多租户与套餐额度管理等完整业务闭环。

### 1.2 技术与部署组成



| 组成部分        | 位置 / 端口                                                                           | 说明                                                                               |
| ----------- | --------------------------------------------------------------------------------- | -------------------------------------------------------------------------------- |
| 前端静态站点（Web） | `frontend/`，产物 `frontend/dist/`，Nginx 托管（本地开发默认 `:8080`）                          | 原生 HTML + CSS + 原生 JS，多页面单页 Tab 结构；线上发布的是 `dist/` 构建产物                           |
| 主业务 API     | `api/` 模块，默认 `:8081`，接口前缀 `/api/v1/*`                                             | Spring Boot 3 + Java 17 + MyBatis-Plus + MySQL 8 + Spring Security + JWT，纯后台不含页面 |
| 消息中心服务      | `message-service/`，默认 `:8090`，前缀 `/api/v1/message`、`/api/v1/sse`、`/api/v1/users/` | 收件箱、消息模板、SSE 实时推送、投递追踪                                                           |
| 微信小程序       | `miniprogram/`                                                                    | 与 Web 端功能等价，共享 `shared/` 领域定义；本手册以 Web 端为准，小程序操作可对照同名功能                          |
| 数据库         | MySQL 8.0，库名 `lesson_appointment`；消息库 `message_center`                            | 多租户隔离，按租户编码（tCode）区分数据                                                           |

> 浏览器建议：Chrome / Edge 100+、Firefox 100+，桌面分辨率 1366×768 及以上；页面为响应式布局，可在手机浏览器使用。

### 1.3 角色与权限层级

系统共四类登录角色，权限自上而下逐级隔离：



| 角色    | 角色标识             | 入口页面                                 | 职责范围                                                            |
| ----- | ---------------- | ------------------------------------ | --------------------------------------------------------------- |
| 平台管理员 | `platform_admin` | `platform_admin.html?tCode=platform` | 平台级：租户、套餐、跨租户用户、全局配置、行业 / 术语、日志与后台诊断、推广统计                       |
| 租户管理员 | `admin`          | `admin.html?tCode=<租户编码>`            | 本机构内：教师 / 学生 / 管理员账号审核、课程模板、课程、排期、预约审核、通知与退改规则、消息、敏感词、审计日志、额度查看 |
| 教师    | `teacher`        | `teacher.html`                       | 本人课程与排期、预订管理、今日课程、个人资料与职业信息、消息、推广                               |
| 学生    | `student`        | `student.html`                       | 浏览课程与师资、预约 / 候补、我的预订、今日课程、个人中心、消息、推广                            |

**数据隔离原则**：租户管理员只能管理本租户内数据；教师只能管理自己的课程与排期；学生只能查看和操作本人预订。跨租户操作仅平台管理员可执行。

## 2. 登录、注册与通用操作

### 2.1 登录



1. 打开系统地址，进入统一登录页（`login.html`）。

2. **选择登录身份**：

* 平台管理员：选「平台管理员」，租户编码自动锁定为 `platform`；

* 租户端（管理员 / 教师 / 学生）：选「租户端」，填写所属**租户编码**（可由机构专属链接自动带入）。

1. 输入**账号**（邮箱或手机号）与**密码**。

2. 点击「登录系统」。验证通过后按角色自动跳转对应工作台：

* `platform_admin` → 平台管理端；

* `admin` → 租户管理端；

* `teacher` → 教师端；

* `student` → 学生端。

**登录失败常见提示**：



| 提示            | 原因                            | 处理                             |
| ------------- | ----------------------------- | ------------------------------ |
| 账号或密码错误，请重试   | 账号 / 密码不匹配                    | 核对后重新输入；忘记密码联系管理员重置            |
| 账号等待审核        | 状态为 `pending`（待审核）            | 联系机构管理员在用户管理中审核通过              |
| 账号状态异常        | 账号被停用 `inactive` 或冻结 `frozen` | 联系管理员处理                        |
| 401 未登录或登录已过期 | 登录凭证失效                        | 重新登录即可（系统会自动无感刷新 Access Token） |

### 2.2 注册

登录页点击「还没有账号？点击注册」打开注册弹窗。

**自助注册身份**：教师、学生（平台管理员与机构管理员不由自助注册产生）。



| 字段        | 填写要求                           |
| --------- | ------------------------------ |
| 注册身份      | 教师 / 学生                        |
| 账号        | 字母 / 数字或邮箱、手机号，系统实时查重，已存在会提示更换 |
| 姓名        | 真实姓名，必填                        |
| 密码 / 确认密码 | 两次输入必须一致                       |
| 租户编码      | 所属机构编码；由专属推广链接进入时自动带入          |
| 协议勾选      | 须先阅读并勾选同意用户协议与隐私政策，方可提交        |

提交后账号状态默认为 **待审核（pending）**，需管理员审核通过（active）后才能登录使用。

**免费体验注册（自助建租户）**：通过好友推广链接进入时，可填写机构名称、管理员账号、姓名、联系电话、所属行业并设置密码，注册后即成为新机构（新租户）的管理员，享受限时免费体验；所属行业决定界面术语体系，注册后仍可在「租户信息」中修改。

### 2.3 顶部通用操作（各端一致）



| 操作   | 说明                                     |
| ---- | -------------------------------------- |
| 退出登录 | 点击右上角「退出」，清除本地登录态与服务端刷新凭证，返回登录页        |
| 修改密码 | 头部操作区「修改密码」：输入旧密码、新密码、确认新密码；修改成功后需重新登录 |
| 刷新   | 内容区标题栏「刷新」按钮，按当前条件重新加载列表与统计            |
| 语言切换 | 头部语言下拉可切换界面语言（中 / 英 / 法等），选择保存在本地      |
| 消息红点 | 菜单「消息中心」旁的未读角标，显示未读消息数量                |

### 2.4 通用界面约定



* **列表筛选**：列表页顶部支持按关键词、状态、时间等条件筛选，「搜索」提交条件，「重置」清空条件。

* **分页**：列表底部提供页码、上一页 / 下一页与总条数。

* **弹窗**：新增 / 编辑为居中表单弹窗，可点击右上角 ×、取消按钮或遮罩空白区关闭；删除、取消预约等危险操作需二次确认。

* **提示**：操作失败显示底部错误横幅（数秒后自动消失）；成功以页面提示或 toast 反馈。

* **时区**：排期时间按所选时区录入，跨地域查看时自动换算为对方本地时区显示；后端统一以 UTC 存储。

## 3. 平台管理员操作手册

> 入口：
>
> `platform_admin.html?tCode=platform`
>
> ；仅 
>
> `platform_admin`
>
>  角色可进入。平台端负责 "管租户、管套餐、管全局配置、看跨租户数据"，不直接处理机构内课程与预约业务。

### 3.1 平台总览（overview）

进入后展示全平台汇总面板：租户规模、用户总量、课程 / 排期 / 预约 / 课时等关键指标的跨租户统计与趋势概览。点击右上角「刷新」重新拉取数据。

### 3.2 租户管理（tenant）

管理平台上所有机构（租户）账号。

**列表信息**：机构名称、租户编码、所属行业、状态、套餐、到期时间、资源额度使用情况。

**操作**：



| 操作           | 步骤与说明                                                    |
| ------------ | -------------------------------------------------------- |
| 新增租户         | 点击「新增租户」，填写机构名称、租户编码、所属行业、初始状态、到期时间等，保存后生成租户             |
| 编辑租户         | 点击该行「编辑」，修改机构资料、状态、到期时间                                  |
| 分配套餐         | 点击「分配套餐」，从可用套餐模板中为该租户指定套餐；已有套餐的租户会置灰标注「已有套餐」，如需更换走「变更套餐」 |
| 启用 / 禁用 / 删除 | 状态切换用于控制租户是否可登录使用；删除为二次确认后的回收操作，谨慎执行                     |

### 3.3 用户管理（user）

跨租户查看与管理平台内用户账号，支持按角色（平台管理员 / 管理员 / 教师 / 学生）、状态、姓名、账号等条件检索；可查看账号归属租户、调整账号状态、重置密码。

### 3.4 套餐管理（package）

分两个子区：

**套餐模板**：平台统一定义可售卖的套餐规格。



| 操作        | 说明                                                          |
| --------- | ----------------------------------------------------------- |
| 新增 / 编辑模板 | 模板名称、状态，以及各类资源额度：课程数、排期数、注册用户总数、教师数、学生数、教师信息发布数（额度填 0 表示不限） |
| 启用 / 停用   | 控制模板是否可被分配给租户                                               |
| 删除模板      | 二次确认后删除                                                     |

**租户套餐**：查看每个租户当前生效的套餐实例与各项额度余量，可新增 / 编辑 / 删除租户套餐；也可从模板卡片式选择 "目标租户 + 套餐模板" 一键指定。

### 3.5 运营统计（statistics）

跨租户的业务统计面板：用户、课程、预约、课时等指标的月度对比与总量概览，用于掌握平台整体运营情况。

### 3.6 消息中心与消息管理



* **消息中心（messages）**：平台管理员本人的收件箱，查看系统通知与推送消息，点击可查看详情。

* **消息管理（msg\_manage）**：向平台范围内或指定对象撰写、发送通知；发送时消息分类从「消息分类管理」中选择。

### 3.7 系统配置



| 菜单                      | 功能                                  |
| ----------------------- | ----------------------------------- |
| 消息分类管理（msg\_category）   | 维护消息分类字典，供消息发送时下拉选用                 |
| 敏感词管理（sensitive\_words） | 维护平台敏感词库；用户提交的文本命中敏感词时按规则拦截或提示      |
| 系统设置（config）            | 全局参数配置；含行业字典、行业术语、系统参数等子页，支持分页检索与编辑 |

### 3.8 系统维护



| 菜单                   | 功能                                                          |
| -------------------- | ----------------------------------------------------------- |
| 系统日志（sys\_log）       | 跳转独立日志浏览器 `logBrowser.html`，查看后台运行日志；带返回参数可回到平台端            |
| 审计日志（audit\_log）     | 跳转 `auditLog.html`，查看关键操作的审计留痕（操作人、动作、对象、时间）                |
| 后台信息（backend\_info）  | 展示主业务 API、消息中心等服务的运行信息（程序名、版本、服务器时间、时区、已运行时长、连接诊断），用于确认服务存活 |
| 推广统计（promo\_stats）   | 全平台推广漏斗、推广者排行、最近转化明细                                        |
| 我的推广（my\_promo）      | 跳转 `promo.html`，查看本人推广码与个人业绩                                |
| 数据维护（data\_maintain） | 平台级对象的回收站清理：租户、平台用户、租户套餐等（与租户端业务数据维护不同）                     |

## 4. 租户管理员操作手册

> 入口：
>
> `admin.html?tCode=<租户编码>`
>
> ；角色 
>
> `admin`
>
> 。本端管理
>
> **本机构内**
>
> 的全部教学业务与账号。

### 4.1 数据总览（overview）

机构运营统计面板，展示：



* 本月月初 / 月末教师数量对比；

* 本月月初 / 月末学生数量对比；

* 本月月初 / 月末课程数量对比；

* 本月与上月预约数量对比；

* 本月与上月课时数量对比；

* 未来 7 日内课时总数。

点击「刷新」获取最新数据。

### 4.2 用户管理

#### 4.2.1 教师管理

列表展示：姓名、账号、邮箱、电话、教授语言、资质（缩略图）、状态标签。



| 操作   | 说明                                             |
| ---- | ---------------------------------------------- |
| 审核通过 | 待审核（pending）→ 正常（active），通过后教师方可登录开课           |
| 冻结   | 改为 frozen，该账号无法登录                              |
| 停用   | 改为 inactive，账号不可用                              |
| 重置密码 | 将密码重置为系统默认初始密码，教师首次登录后应自行修改                    |
| 查看资料 | 点击教师可进入其职业信息页（`teacherInfo.html`）查看简介、证书、可预约时段 |

#### 4.2.2 学生管理

列表展示：姓名、账号、邮箱、电话、学习目标、语言水平、状态标签。操作与教师管理一致：审核通过、冻结、停用、重置密码。

#### 4.2.3 管理员管理

管理本租户内 `role=admin` 的子管理员账号：新增、状态调整、重置密码。

### 4.3 课程模板管理（course\_template）

课程模板是教师创建课程的基础规格（语言 + 难度 + 价格 + 时长 + 形式）。

**新增模板**：点击「新增模板」，填写：



| 字段   | 规则                                    |
| ---- | ------------------------------------- |
| 语言类型 | 英语 / 日语 / 韩语 / 法语 / 德语 / 西班牙语等（按行业字典） |
| 难度等级 | 入门 / 进阶 / 中级 / 高级                     |
| 课时费  | 金额，≥ 0                                |
| 时长   | 分钟数，≥ 15 且为 15 的倍数                    |
| 授课形式 | 一对一 / 小班课 / 大班课                       |
| 课程描述 | 10–500 字                              |
| 状态   | 启用 active / 停用 inactive               |

**唯一性约束**：同一语言 + 同一难度不可重复建模板。

**其他操作**：编辑、删除（二次确认，关联课程按级联规则处理）、状态切换（启用 / 停用 / 冻结）。

### 4.4 课程列表（course\_list）

查看本机构全部教师课程：课程名称、关联模板、授课教师、课程状态、创建时间。



* 按课程名 / 教师名筛选；

* 修改课程状态（发布 / 回收）；

* 按模板批量修改课程状态；

* 删除单个课程，或按模板批量删除关联课程。

> 教师新建的课程默认为待审核（pending），管理员在此审核发布后学生方可预订。

### 4.5 课程排期（schedule）

查看与维护本机构所有课程的排期。

**新增 / 编辑排期**：



| 字段        | 说明                              |
| --------- | ------------------------------- |
| 所属课程      | 下拉选择已有课程                        |
| 排期名称      | 自定义名称                           |
| 时区        | 如 Asia/Shanghai、America/Toronto |
| 开始 / 结束时间 | 单次课时间范围                         |
| 起始日期      | 重复排期的开始日期                       |
| 重复类型      | 不重复（单次）/ 每天 / 每周 / 每月           |
| 重复间隔      | 如每 2 周一次填 2                     |
| 重复日       | 周重复选周一至周日（1–7）；月重复选日期号（1–31）    |
| 可用席位      | 同时可预约学生数，默认 1                   |

**保存前**可点击「预览 / 检测冲突」：系统生成课时预览列表，并检查与同一教师其他排期是否时间重叠；确认无误后保存入库，按重复规则展开生成具体课时。

**其他操作**：修改排期、增减可用席位、启停排期、查看排期展开后的课时列表、删除单个排期、删除某课程下全部排期；候补名单在排期内查看与处理。

### 4.6 预订审核（booking\_audit）

查看本机构全部预约记录：序号、课程名称、排期名称、学生、教师、上课时间、预约状态。



* 按学生 / 教师 / 状态（待确认 / 候补 / 已确认 / 已拒绝等）筛选；

* 查看预约详情（含展开后的每个课时及状态）；

* 查看预约备注。

**按状态可执行的操作**：



| 预约状态                             | 可执行操作                                   |
| -------------------------------- | --------------------------------------- |
| booking（预订待确认）                   | 「确认」转为 booked（已确认占座）；「拒绝」置为 rej-booking |
| waiting（候补）                      | 「查询递补」跳转该排期候补队列处理；「拒绝候补」置为已取消           |
| cancelling（取消待确认）                | 「确认」取消；「撤回」退回待确认；「拒绝」取消申请               |
| booked（已确认）                      | 「撤回」退回待确认；「取消」发起取消流程                    |
| rej-booking /rej-cancelling（已拒绝） | 「撤回」恢复到上一状态                             |
| cancelled（已取消）                   | 「撤回」恢复；「取消」重新申请；记录可「删除」                 |
| 非占座状态                            | 可「查询递补」进入排期候补队列，将候补学生递补为正式预约            |

### 4.7 上课通知（lesson\_notice）

检视近 7 日待上课课时：课程名称、学生、教师、上课时间（精确到分钟）、课时状态。



| 操作     | 说明                   |
| ------ | -------------------- |
| 发送通知 1 | 课时状态置为 noted1（第一次提醒） |
| 发送通知 2 | 课时状态置为 noted2（第二次提醒） |
| 标记完成   | 课时状态置为 completed     |

> 提醒发送的时间点由「通知规则」配置；此处为人工检视与补发入口。

### 4.8 消息中心



* **消息中心（messages）**：本管理员收件箱，查看机构内通知与提醒。

* **消息管理（msg\_manage）**：撰写并向教师 / 学生 / 指定对象发送通知，选择消息分类与接收范围。

### 4.9 系统配置

### 4.10 系统维护

## 6. 学生操作手册

> 入口：
>
> `student.html`
>
> ；角色 
>
> `student`
>
> 。学生完成注册并经管理员审核通过后，可浏览课程、预约 / 候补、管理本人预订。

### 6.1 今日课程（today\_course）

查看本人近 7 日上课安排：课程名称、教师姓名、上课日期时间、课时状态（待上课 / 已通知 / 已完成 / 已取消）。建议上课前再次打开本页确认通知；状态异常时点击「刷新」重新加载。

### 6.2 课程预订（booking）

**预约流程**：



1. **浏览课程卡片**：卡片展示课程名称、教师、语言、难度、课时费、时长、授课形式等标签。

2. **筛选检索**（可选）：按语言类型、难度筛选，或按关键词搜索课程名 / 教师名。

3. **查看排期**：点击「查看排期」展开该课程下各教师排期，显示上课时间、重复规则、剩余席位、时区；课程尚未发布排期时显示「待排期，可联系管理员」。

4. **选择排期并预约**：

* 有余位时点击「立即预约」，弹出二次确认，确认后提交；

* 名额已满时「立即预约」不可用，可点击「候补预订」排队；席位释放后按候补顺序处理。

1. **预约成功后系统自动处理**：扣减可用席位 → 生成预约记录（booked）→ 按排期规则生成全部课时（active）。

2. 到「我的预订」查看已预约课程。

**预约限制与提示**：



* 席位为 0 时预约按钮禁用，仅可候补；

* 同一学生对同一排期不可重复预约 / 候补；

* 候补记录不占用席位，待名额释放并经确认后转为正式预约；

* 排期时间按学生本地时区显示。

### 6.3 我的预订（my\_booking）

查看本人全部预约历史：预约 ID、课程名称、教师姓名、预约时间、预约状态；展开可见对应课时明细（每节课日期、时间、课时状态）。

**预约状态说明**：



| 状态                   | 界面文案    | 含义                   |
| -------------------- | ------- | -------------------- |
| booking              | 已预订，待确认 | 学生已提交申请，等待教师 / 管理员确认 |
| booked               | 预订成功    | 正式占座，等待上课            |
| waiting              | 候补      | 已排队等待名额释放（不占席位）      |
| cancelling           | 取消待确认   | 学生发起取消，待处理           |
| cancelled / canceled | 已取消     | 预约已取消，席位归还           |
| completed            | 已完成     | 全部课时已上完              |
| overtime             | 已过时     | 预约已过期                |

**操作**：



| 操作   | 条件                              | 说明                           |
| ---- | ------------------------------- | ---------------------------- |
| 撤销   | 状态为 booking（待确认）                | 撤回本次预订申请                     |
| 撤销候补 | 状态为 waiting                     | 退出候补队列                       |
| 取消预订 | 状态为 booked（预订成功）                | 发起取消申请（cancelling），处理完成后席位归还 |
| 撤销取消 | 状态为 cancelling（取消待确认）           | 撤回取消申请，恢复为 booked            |
| 重新申请 | 状态为 cancelled                   | 对已取消的排期再次提交预订申请              |
| 预订详情 | 非 booking /waiting/cancelled 状态 | 展开完整课时列表与每节课状态；候补尚无课时明细      |
| 评价课程 | 课程已完成                           | 对已完成课程进行星级与文字评价（以当前版本开放情况为准） |

> 候补转正由教师 / 管理员在预订列表确认，学生侧不直接确认，以避免绕过名额校验。

### 6.4 消息中心（messages）

接收上课提醒、预约状态变更、候补转正、机构通知等；未读角标提示数量，点击查看详情。

### 6.5 浏览师资（teacher\_showcase）

### 6.6 个人中心（profile）



* 查看本人账号信息：姓名、账号、所属机构、手机号、邮箱、学习目标、语言水平；

## 7. 状态与规则速查

### 7.1 账号状态（user.status）



| 状态       | 含义  | 能否登录     |
| -------- | --- | -------- |
| pending  | 待审核 | 否，提示等待审核 |
| active   | 正常  | 是        |
| inactive | 停用  | 否，状态异常   |
| frozen   | 冻结  | 否，状态异常   |

### 7.2 课程与排期状态



| 对象   | 状态                         | 含义                  |
| ---- | -------------------------- | ------------------- |
| 课程模板 | active / inactive / frozen | 启用 / 停用 / 冻结        |
| 课程   | pending / 已发布 / 未发布        | 待管理员审核 / 对外可见 / 已回收 |
| 排期   | active 等                   | 启用中 / 停用等           |

### 7.3 预约状态（booking.status）



| 状态                   | 含义                  |
| -------------------- | ------------------- |
| booking              | 已预订，待确认（申请已提交，等待确认） |
| booked               | 预订成功（正式占座）          |
| waiting              | 候补排队（不占席位）          |
| cancelling           | 取消申请待确认             |
| cancelled / canceled | 已取消，席位归还            |
| completed            | 已完成                 |
| overtime             | 已过时                 |

### 7.4 课时状态（appointment.status）



| 状态                          | 含义               |
| --------------------------- | ---------------- |
| active                      | 生效中，待上课          |
| noted1 / noted2             | 已发送第 1 / 2 次上课通知 |
| completed                   | 已完成              |
| cancelled                   | 已取消              |
| s-cancelling / t-cancelling | 学生 / 教师发起取消中     |

### 7.5 退改规则档位



* 提前 ≥ 免责时间点：免责取消，全额退费；

* 部分退费线 ≤ 提前 < 免责时间点：按部分退费比例退费；

* 提前 < 部分退费线：不退费；

* 生效顺序：课程专属规则 > 租户默认规则 > 系统内置默认。

### 7.6 数据额度（套餐）

租户套餐可限制：课程数、排期数、注册用户总数、教师数、学生数、教师信息发布数；额度填 0 表示不限。当前用量与余量在租户管理员「租户信息」页查看。

## 8. 常见问题（FAQ）



| 问题现象           | 可能原因                       | 处理方法                                |
| -------------- | -------------------------- | ----------------------------------- |
| 注册后无法登录        | 账号仍为待审核 pending            | 联系机构管理员在「教师 / 学生管理」中审核通过            |
| 登录后立即跳回登录页     | 登录凭证失效或被清除                 | 重新登录；不要手动清除浏览器本地存储                  |
| 新建课程 / 排期学生看不到 | 课程待审核或未发布；排期未启用            | 联系管理员审核发布，或在「我的课程」中调整状态             |
| 预约提示 "已无席位"    | 排期可用席位为 0                  | 选择其他排期，或点击「候补预订」排队                  |
| 候补为何还没转正       | 名额尚未释放，或需管理员 / 教师确认        | 在「我的预订」关注状态变更，留意消息中心通知              |
| 取消按钮不可用        | 课程已完成 / 已取消 / 已过时，或已过可取消时限 | 联系管理员或教师后台处理                        |
| 页面时间与本地不符      | 排期时区选择有误                   | 核对排期创建时所选时区；跨时区由系统自动换算              |
| 接口返回 401 / 无权限 | 登录过期或角色不足                  | 重新登录；确认当前账号具备对应角色权限                 |
| 消息收不到          | 浏览器通知 / SSE 连接异常           | 刷新页面；检查消息中心是否有未读；联系管理员检查消息规则        |
| 教师资料学生看不到      | 资料未发布，或发布版本被归档             | 在 `teacherInfo.html` 发布模式中重新发布      |
| 额度不足无法新建       | 套餐对应额度已用尽                  | 联系平台管理员调整套餐或额度                      |
| 页面打开空白 / 404   | 后端服务未启动或静态资源未发布            | 确认 API（8081）、消息服务（8090）与前端站点运行正常后刷新 |
