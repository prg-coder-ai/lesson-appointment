# 电子课堂系统 · 操作说明

> 适用版本：2026-11-18（按当前界面与默认配置核对）
> 面向对象：授课教师、上课学员、机构管理员、平台管理员
> 本说明只写界面上真实存在的操作；按钮文字与提示文案取自当前代码。
> 配套文档：《电子课堂使用手册-20261118.md》（更完整的场景版）、`doc-develop/08-电子课堂/电子课堂-系统维护说明.md`（部署与故障处置）。

---

## 一、角色与能做什么

系统按角色区分能力，权限由服务端判定；前端只按角色显示按钮。

| 角色 | 标识 | 课堂页底部可见按钮 | 核心能力 |
|---|---|---|---|
| 学员 | `student` | 麦克风、摄像头、白板、讲稿、举手、上传作业、录制横幅 + 离开 | 听讲、举手、应答点名、聊天、上传作业、看讲稿、查看自己的出勤 |
| 教师 | `teacher` | 麦克风、摄像头、白板、讲稿、点名、全员静音、录制模式 + 录制、保存板书、作业点评、**进行中 / 暂停 / 下课** | 开课/暂停/下课、点名、白板与授权、讲稿上传翻页、两种录制、作业点评、补签 |
| 机构管理员 | `admin` | 白板、讲稿、全员静音、录制模式 + 录制、**巡课**、离开 | 巡课与强制结束、全员静音、录制；**没有**麦克风/摄像头、点名、板书保存、状态按钮 |
| 平台管理员 | `platform_admin` | 白板、讲稿、离开 | 跨机构查看；在课堂页能力最少 |

**前置条件（不满足则进不去课堂）**：

1. 机构已开通课堂功能，否则提示「本机构未开通在线课堂」。
2. 你的账号在该课堂成员名单内（由报名/排期生成），非成员即使有链接也进不去。
3. 课堂状态不是 `CANCELLED`；`CLOSED` 的课只能看回放，不能进入。

> ⚠️ **当前默认是显式状态管理**：`classroom.state-manual-only=true`、`classroom.auto-start=false`，到点了也**不会自动开课**；自动下课配置虽有，但在该模式下不生效。时间只产生提醒，开课/下课由教师手工点。

## 二、进入课堂

### 2.1 入口

- 常用路径：「我的课堂」→ 对应课次 →「课程准备」（教师）/「课前准备」（学员）→「进入课堂」。
- 学员临时课堂：`student.html` →「加入课堂」→ 粘贴老师发的**链接**或直接输入**课堂号** →「查找课堂」→「进入课堂」。
  - 临时课堂（管理员应急建的）没有排期、没有预约记录，**不会出现在「我的课堂」列表里**，只能用这个入口或点老师消息里的「进入课堂」按钮。
  - 提示「你不在本课堂名单内」时不要反复重试：让管理员在运营台「给指定课堂加学员」里把你的账号加进去，再查找一次即可。
- 管理员：`admin.html` →「预订审核」或「上课通知」→ 对应行的「进入课堂」。
- 直接访问：`https://<你的域名>/classroom.html?scheduleId=<课次ID>`。
  - `scheduleId` 是**课次**标识，不是课程 ID；不带参数会被退回首页。
  - 多课次时，第 1 课次用裸 ID，第 2 课次起为 `<课次ID>~N`（N 为课次序号）。页面显示的是「课程名 · 第N课次」，不会显示长 ID。
  - 未登录时点链接会先到登录页，**登录成功后自动回到这间课堂**，不需要再点一次。
- 同一课次再次打开即为重连，会恢复禁言态、举手态、白板笔迹、讲稿页码与滚动位置。

### 2.2 进房后会自动发生什么

1. 校验身份与课堂归属 → 写成员记录、开始在线计时。
2. 建立信令、白板、心跳三类长连接。
3. 回放服务端当前状态：谁被禁言、谁举手、谁被授权画白板、讲稿第几页、已有笔迹。
4. 顶部状态灯变绿表示「已连接」；长时间「连接中…」见第八节。

### 2.3 页面构成

| 区域 | 位置 | 说明 |
|---|---|---|
| 状态灯 | 顶栏 | 灰=连接中，绿=已连接，红=已断开 |
| 回放 | 顶栏右侧 | 打开本节课的回放页（新窗口） |
| 禁言横幅 | 顶部（红色） | 全员静音时出现 |
| 录制横幅 | 横幅下方 | 红点闪烁；教师端同时显示已录时长 |
| 成员名单 | 左侧 | 在线人数、角色、举手/关摄像头/白板授权标记；下方有「我的出勤」 |
| 视频 / 白板 / 讲稿 | 中间 | 三个独立浮层面板 |
| 聊天 | 右侧 | 消息列表 + 输入框 |
| 控制栏 | 底部 | 按角色显示，见第一节 |

### 2.4 面板拖动、缩放与视频焦点（通用）

| 想做什么 | 怎么操作 |
|---|---|
| 移动面板 | 按住面板**标题栏**拖动（视频标题栏 / 白板工具栏 / 讲稿标题栏） |
| 缩放面板 | 拖面板**右下角**缩放手柄 |
| 复位 | 点标题栏 ⟳「恢复默认位置与大小」，或**双击标题栏** |
| 置顶 | 点面板任意位置 |
| 视频焦点放大 | 画面 ≥2 个时点某个画面放大，其余缩到右侧；再点一次 / 点「关闭放大」/ 按 `Esc` 退出 |

布局存在本机浏览器，换电脑或清缓存会重置；焦点放大只是本地观看态，刷新即恢复。

## 三、学员操作

### 3.1 麦克风 / 摄像头

- **进入课堂时麦克风与摄像头默认关闭**，底部两个图标都是灰的，需要自己点开才有声音和画面（教师、学员一致）。这样避免一进教室就把画面声音推给全班。
- 点底部「麦克风」「摄像头」切换；首次进入需允许浏览器权限。
- 被全员静音时提示「全员禁言中，无法开启麦克风」，按钮由服务端强控，教师解除后恢复。
- 学员想发言必须先举手并等教师批准：直接点麦克风会提示「请先举手，等待老师批准后发言」，麦克风不会打开。
- 学员默认不推送视频（`classroom.rtc.student-publish-video` 默认 `false`），点「摄像头」只对自己生效；需要互看由机构改配置后重启服务，教师端没有「开启学生视频」按钮。
- 刷新页面会回到默认关闭态；网络抖动导致的媒体重连不会改变你当前的开关。

### 3.2 举手 / 发言（三态）

按钮会根据状态自动切换文字与颜色：

| 态 | 按钮显示 | 含义 |
|---|---|---|
| 未举手 | 「举手」常态 | 点一下申请发言 |
| 待批准 | 「等待批准」**黄色** | 已申请，等教师在名单里点「批准开麦」；此时再点可取消 |
| 发言中 | 「发言中」**红色** | 教师已批准，麦克风自动打开，可以说话 |

- 教师批准后你会收到提示「教师已允许你发言，麦克风已开启」，麦克风图标同时点亮。
- 结束发言有两种方式，效果相同：点「发言中」按钮，或直接关麦克风。两者都会**自动放下手、关闭麦克风、撤销这次批准**，教师端按钮回到「批准开麦」。
- **教师也可以收回**：教师点名单里绿色的「已批准」即收回你的发言权，你会被关麦、举手一并取消（回到「举手」常态，不是「等待批准」）。想再发言需要重新举手、重新获批。
- 教师开启全员静音时，所有发言中的学员都会被打回「等待批准」（举手保留），解除静音后**不会自动恢复发言**，需教师重新批准。

> 批准状态是服务端权威态：举手期间有效，放下手即撤销；中途刷新页面会按服务端状态恢复按钮与麦克风。
>
> **录制提醒**：录制取的是本机麦克风与摄像头轨道，如果录制时麦克风和摄像头都是关的，录出来的画面是黑的、也没有声音。录课前请先打开这两项。

### 3.3 应答点名

被点到的学员弹出「老师点名了你！」，点「我已到」或「稍后」。「稍后」关闭后 2 分钟内不作答会被判超时；其他人无感。

### 3.4 聊天

- 输入后按 **Enter** 或点「发送」；消息由服务端广播后才显示。
- 全员静音时会被拒绝，提示「全员禁言中，消息未发送」。
- **聊天消息不落库**，管理员无法调阅历史聊天内容，请勿发送需要留痕的信息。

### 3.5 上传作业

点「上传作业」，可选文字 / 语音 / 图片 / 文件，单个文件 ≤100MB；上传中不要关闭页面，中断后需重新上传。教师点评后可在作业列表看到评语与分数。

### 3.6 查看讲稿

教师翻页与滚动会自动同步给你；中途进入或刷新会定位到当前页。学员端只读，没有上传和翻页按钮。

### 3.7 查看自己的出勤

点左侧名单下方「我的出勤」，列表四列：课程名/课次、签到时间、状态、有效时长（分钟）。
状态取值：**出勤 / 迟到 / 缺席 / 离开 / 重连**。有效时长按在线区间累计，间隙 ≤60 秒会合并计入；超过 60 秒的间隙不计入。

### 3.8 离开课堂

点底部「离开」，确认「确定要离开课堂吗？」。离开后停止计时；短时网络闪断有保护，超过保护窗口的间隙不计入课时。

## 四、教师操作

### 4.1 开课、暂停与下课（上课前务必看清）

| 按钮 | 行为 |
|---|---|
| **进行中** | 手动开课/恢复：`PAUSED` → 恢复；`LIVE` → 提示「课堂已在进行中，无需重复开课」；`CLOSED` → 提示「课堂已结束/已取消，无法重新开课」。 |
| **暂停** | 确认「确定暂停课堂吗？暂停期间教师端和学生端都不能发送音视频、白板与聊天。」暂停期间**师生全员**禁发。 |
| **下课** | 确认「确定要结束本次课堂吗？」若**尚未到计划上课时间**，不会结束，改为暂停并提示「尚未到上课时间，课堂已暂停（稍后可点「进行中」恢复）」；已到/超过计划时间才真正结束。 |

下课是不可逆收尾：闭合出勤区间、归一出勤、全员离线、回流课时。**`CLOSED` 是终态，不能重新开课**；只是中途停一下请用「暂停」而不是「下课」。

### 4.2 全员静音

点「全员静音」切换。开启后所有学员被强制静音、顶部出现红色横幅，新进学员也立即静音；再次点击解除。

**静音会收回所有发言权**：已经在发言的学员会被关麦、按钮退回「等待批准」（举手保留），解除静音后**不会自动恢复发言**，需要你重新点「批准开麦」。这是有意的——静音期间你并不知道谁在说话，恢复后自动放开容易失控。

### 4.2.1 你自己的麦克风与摄像头

教师进课堂时**麦克风与摄像头同样是默认关闭的**，需要点开才有声音画面。上课前建议先打开这两项再点「进行中」，否则学生进来看不到你，录制也会是黑屏无声。

### 4.3 点名

点「点名」→ 弹窗中从下拉框选学员（留空=随机抽在线学员）→ 点「发起点名」。弹窗实时显示「已应答 / 超时」；关闭弹窗不影响已发起的点名。频率限制为每分钟 10 次。

### 4.4 白板

- 工具栏：画笔、橡皮、矩形、圆、正方形、文字、颜色、粗细、字体、字号、撤回（`Ctrl+Z`）、清空、复位 ⟳；文字输入用 `Ctrl+Enter` 确认。
- 白板**默认教师可写、学员只读**；学员要写字，在右侧参与者列表点该学员行的「授权白板」，收回点「收回白板」。
- 点「保存板书」立即落盘；学员刷新或中途进入会看到已有笔迹。
- **没有「移出成员」按钮**，后端虽有 kick 能力但界面不提供。

### 4.5 讲稿

讲稿栏有「资料选择…」下拉、「上传讲稿」「上一页 / 下一页」。支持 PDF / png / jpg / jpeg / webp / ppt / pptx，≤100MB。翻页与滚动实时同步全班；PDF 在浏览器内渲染并缓存，翻页不重新下载整份文件。PPT/PPTX 无法内联预览，提示「该格式（PPT）不支持内联预览，点此下载」——建议课前转 PDF。

### 4.6 录制

1. 先在「录制模式」下拉选择：
   - **人像录制**（默认）：录教师本机摄像头 + 麦克风，画面只有教师。
   - **教学区域**：屏幕/窗口共享采集，讲稿、白板、PPT 都进画面；需 Chrome/Edge + HTTPS，共享时勾选系统音频，并建议同时开麦克风。
2. 点「录制」开始，全体学员看到录制横幅；再次点击停止并上传，下课时若仍在录制会自动收尾。
3. 录制文件约 5MB 分片上传，请保持页面开启直到上传完成；保留期默认 **90 天**。
4. **2026-11-18 起新录制**在收尾时自动补时长与跳转索引，回放可显示总时长并拖到中间任意秒；**旧录制**仍可能显示 ∞、拖不动，需离线回填。
5. 云录制模式在本仓库没有内置厂商实现，配置后也会降级为本地录制。

### 4.7 作业点评

点「作业点评」，列表显示本堂课所有提交。可查看文字/试听语音/预览图片/下载文件，填写评语与分数（0~100）后学员可见；已批阅可修改。

### 4.8 名单操作

学员行内的按钮：

| 按钮 | 作用 |
|---|---|
| 批准开麦 | 学员举手后按钮**黄色**；点一下批准，该学员麦克风自动打开、图标点亮，按钮转**绿色「已批准」** |
| 已批准（绿色） | **再点即收回发言权**：学员被关麦、举手一并取消（该行回到无举手状态，按钮整体消失），需学员重新举手再批准。鼠标悬停时按钮变红作提示 |
| 授权白板 / 收回白板 | 允许或取消该学员在白板书写 |
| 补签 | 手动修正出勤状态，需填写原因并留痕（用于设备故障等场景） |

> 收回是"一步到底"：不会退回"待批准"，而是回到完全未举手的默认态，避免老师以为还挂着一次待批申请。

### 4.9 管理员与平台管理员差异

- 机构管理员课堂页有「巡课」浮层，内含「强制结束」；底部红色按钮是「离开」，**不能在课堂页点下课**。
- 平台管理员课堂页只有「白板 / 讲稿 / 离开」。
- 强制结束后行为等同下课（结算出勤 → 回流课时 → 停录制），**不可恢复**，操作前确认课次。

## 五、课堂运营台（管理员 / 平台管理员）

入口：`admin.html` →「课堂监控」菜单，跳转 `classroom-ops.html`；也可直接访问该地址。未登录会拦，非管理员返回 403。

| 标签页 | 用途 |
|---|---|
| 实时监控（默认） | 活跃课堂、在线/名单人数、卡在 LIVE 等告警、部署健康；三个应急面板也在这一页（见下表） |
| 学情报表 | 按课堂/按学生查出勤与互动，可导出 CSV |
| 对账差异 | 课时回流异常，按待处理/已解决/已忽略筛选，「立即对账」手动跑 |
| 内容审核 | 学员作品处置为主；**聊天内容不落库，无法调阅历史聊天** |
| 契约联调 | 查事件流水、「重放」、「重新同步」；重放有幂等保护，不会重复扣课时 |

「实时监控」页的三个应急面板（课前 1 分钟就能把课上起来）：

| 面板 | 用法 | 注意 |
|---|---|---|
| 临时建课（应急） | 填课程名、教师 userId、起止时间、学生 userId → 创建 → 直接把「学生链接」发给学生 | 不结算课时、不进学情报表、不进学生「我的课堂」；建完是「待开课」，需教师点「进行中」（也可用带 `role=teacher` 的链接由管理员代开课） |
| 给指定课堂加学员 | 填课堂号 + 学生 userId（逗号/换行分隔）→ 加入 | 已在名单的人会跳过；加入后对方刷新即能进 |
| 发上课通知 | 填课堂号（或点课堂列表该行的「发通知」）→ 标题/正文留空即自动生成 → 发送 | 只发给名单里 `role=student` 且未被移出的人；消息里会带一个**可点的「进入课堂」按钮** |

> 强制结束课堂：活跃课堂行的「结束」按钮，或管理员进入课堂后的「巡课」浮层。结束后 CLOSED 不可重开。

## 六、回放

### 6.1 进入方式

- 「我的课堂」已结束课次的「课程回看」，或课堂页顶栏「回放」。
- 直接访问 `https://<你的域名>/replay.html?scheduleId=<课次ID>`；不带参数时页面提供手工查询输入框，支持粘贴整条链接自动解析。

### 6.2 播放器

- 列表显示开始时间、状态徽标（可回放 / 录制中 / 录制失败）、时长与录制类型（人像录制 / 教学区域录制）。
- 原生控件之外还有：
  - 倍速按钮 `1x / 1.25x / 1.5x / 2x`（记忆上次选择，无 0.5x）；
  - 「从 mm:ss 继续播放」（超过 5 秒且未看完时出现）；
  - 快捷键：`空格` 播放/暂停、`←→` 快退/快进 5 秒、`↑↓` 音量 ±0.1；
  - 播完提示「本条已播完，已选中下一条（点击即可播放）」。
- 签名地址有效期 **2 小时**；过期刷新页面重新获取。旧录制没有时长/索引，进度条仍可能 ∞。

## 七、课堂状态

| 状态 | 界面文字 | 含义 |
|---|---|---|
| SCHEDULED | 待开始 / 未开始 | 排期已生成 |

## 八、常见问题

| 现象 | 原因与处置 |
|---|---|
| 到点没自动开课 | 默认显式管理（`state-manual-only=true`、`auto-start=false`），教师点「进行中」 |
| 点「下课」没反应，只提示「尚未到上课时间」 | 设计行为：自动转暂停，稍后点「进行中」恢复 |
| 想重新开课但提示无法开课 | CLOSED 是终态，已结算；中途停一下应点「暂停」 |
| 一直「连接中…」 | WebSocket 被拦或 8092 不可达；换网络、查 `/ws/classrooms/` 反代与服务存活 |
| 状态条变成「连接中断，正在重连…」 | 网络抖动，页面会自动重连（间隔 0.8s 起逐次翻倍，最长 15s）；恢复后提示「已重新连接课堂」，板书与举手/授权状态自动补回 |
| 断线重连后板书没了 / 出现重影 | 正常情况会自动补全且不重影；若确实为空，刷新页面即可（服务端保存了完整板书） |
| 提示无权进入 | 不在成员名单 / 已取消 / 机构未开通 |
| 学生说「我的课堂里没有这节课」 | 临时课堂没有排期与预约，列表里本来就没有。让他在「加入课堂」粘贴链接或输入课堂号；或由管理员在运营台「发上课通知」群发带按钮的消息 |
| 「加入课堂」提示「你不在本课堂名单内」 | 名单里没有这个账号：管理员在运营台「给指定课堂加学员」加入此人，学生刷新后重试 |
| 麦克风按钮点不动 | 全员静音服务端强控，请教师解除 |
| 点麦克风提示「请先举手，等待老师批准后发言」 | 学员发言需先举手并由教师批准；或举手后教师尚未处理 |
| 按钮从「发言中」变回「举手」 | 教师收回了发言权，或开了全员静音；重新举手即可 |
| 进课堂后没有我的画面和声音 | 麦克风/摄像头默认关闭，点底部两个图标打开 |
| 学生画不上白板 | 默认只读，请教师在名单里「授权白板」 |
| 学生端提示「课堂已暂停…」 | 教师暂停了，等其点「进行中」 |
| 看不到别人的画面 | 对方未开摄像头；或 mesh 模式已满 6 路上行——**后加入的人**转为「只收不发」（他看得到别人，别人看不到他），有人退出后自动恢复 |
| 点名没弹窗 | 未点到你或弹窗被关；教师可重新发起 |
| 作业上传卡住 | 文件超 100MB 或网络抖动，换文件重试 |
| 教学区域录制没有系统声 | 勾选共享标签页音频，并同时开麦克风 |
| 录制结束没有文件 | 停止后立即关页面导致上传中断；保持页面开启至进度走完 |
| 回放拖不动 / 显示 ∞ | 旧录制无时长与索引；新录制已自动补齐 |
| 面板找不到 / 画面叠一起 | 双击标题栏或点 ⟳ 复位；点面板任意位置置顶 |

## 九、培训用 3 分钟速览

**教师课前**：提前进入 → 确认状态灯绿 → 上传讲稿并翻到第一页 → 选录制模式（通常「人像录制」）→ 点「录制」→ 点「进行中」开课。

**教师课上**：讲重点前「全员静音」，提问时解除；需要互动点「点名」（留空=随机）；需要学生上台写就在名单里「授权白板」；讲稿翻页学生自动跟随。

**教师下课**：先停「录制」等上传完成 → 点「下课」并确认「确定要结束本次课堂吗？」→ 到「作业点评」批阅。

**学员课前**：允许浏览器权限 → 确认状态灯绿 → 需要发言先「举手」，不要直接开麦。
