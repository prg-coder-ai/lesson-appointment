- **体验坑**：前端 CLOSED 下"进行中"按钮没禁用（controls.js:84 只切 active），点了抛 409；且 `enter` 接口无状态校验，CLOSED/CANCELLED 仍可 join+checkIn 开区间写脏数据。
- **时间维度**：3 个 SQL 硬窗口（就绪 start_time<=NOW+10min；开课 start<=NOW 且 end>=NOW；下课 end<=NOW-5min）；手动模式下时间对状态全失效；过期 SCHEDULED 无自动终态（listStaleLive 只覆盖 LIVE 超时）。
- **方案（分场景，不一刀切）**：P0 修体验坑（隐藏/禁用按钮+明确提示、enter 加状态前置、运营台暴露两类僵尸课）；P1 撤销下课（CLOSED 5min 内 undo-end，回滚收尾）；P2 续课（session_seq 分段出勤但只扣一次，与 consumption_version 对齐）；P3 时间软约束（偏离计划时间弹确认、过期课标"未开课"）。核心原则：一课次只扣一次费（biz_key 已支持），终态不可变+审计。
