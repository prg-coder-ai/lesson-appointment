## 小程序目录重构：role 平铺 → 独立 package-* 分包（2026-09-16 晚）
- 目标结构：主包 pages 仅 login/mine/demo；三首页+深页分别迁入 package-student/teacher/admin/message 四个独立分包根，每个页面再套一层同名子目录（如 package-student/home/home.{js,json,wxml,wxss}）。
- 关键结论：原 `pages/<role>/<page>` 扁平时到根为 `../../`（2层）；改 `package-<role>/<page>/<page>` 后去掉 pages/ 一层又加页面目录一层，净层数不变（仍 `../../core`、`../../shared`、`../../components`），import 无需改层。
- 绝对跳转 URL 单一真相源在 shared/constants.js（homePageForRole + TAB_ITEMS），用映射表把 `/pages/<role>/<page>` 全量替换为 `/package-<role>/<page>/<page>`；各页面 navigateTo 一并替换。
- app.json：pages=[login/mine/demo]；subPackages（官方字段名）root=package-*，pages 用 home/home 等嵌套路径；preloadRule 改为主包页预载分包（login 预载全部、mine 预载 message、demo 预载 student）。

## 目录重构后「主页面空白」排查（续 Message 3）
- 现象：编译通过，但主页面空白。
- 全量静态核查（均通过）：app.json 主包+分包结构正确；仓库内**无残留**旧 `/pages/<role>/...` 路径（Grep No matches）；从 home.js 出发的整条 import 链（auth/term/message/constants → request/storage/terms/apiPaths）→ role-tabbar → constants 全部无模块级 throw；launch 页 login 与首页 home 的 WXML 无缺失数据绑定；project.config.json es6:true、无 miniprogramRoot 越界。
- 结论：**空白非代码/配置错误，而是微信开发者工具在大批量文件移动后的编译缓存脏数据**（与 Message 1 旧 app.json 报错同源——工具侧加载的是旧产物）。
- 修复（用户侧）：开发者工具「工具 → 清除缓存 → 全部清除」后重新编译；仍空白则开调试器 Console 看是否有 JS 报错（模块加载失败导致 Page() 未注册），贴报错文本再精确定位。
- 入口链：login.onLoad 无登录态正常渲染登录表单（非空白）；有登录态 goHome()→reLaunch 到 /package-<role>/home/home；home.onLoad 无登录态 reLaunch 回 login——任意分支都不会整页空白，进一步佐证是缓存问题。
