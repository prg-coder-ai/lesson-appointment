- 修复师资卡"查看详情"报错「请在 URL 上附加 ?id=xxxx…」：
  * 根因：teacherCardCarousel.js 已登录分支用 `base + '?id=' + pid` 拼接，但 `window.pageUrl()`（api.js:709）返回的 base 已带 `?tCode=租户编码`，于是得到 `...?tCode=XXX?id=PID`（两个 ?），详情页 getQueryParam('id') 解析失败 → 缺参数报错。未登录分支本就正确用了 `&` 续接。
  * 修复：已登录分支改为 `base + (base.indexOf('?') >= 0 ? '&' : '?') + 'id=' + pid`，与未登录分支一致。
  * 验证：node build.js 重建 + cp 同步；dist 中保留 `r.indexOf("?")` 条件拼接。
