# 2026-10-18 工作日志

## 租户端添加教师/学生：角色只读框显示 XML 代码（00:10 修复）

- **现象**：租户管理端（admin-user.js）点「添加教师/学生」，弹窗卡片里「角色」下的只读 `<input>` 显示一串 XML/标签代码。
- **根因**：`openAddUserModal` 里角色名用的是 HTML 片段
  `roleName = '<span data-term="teacher">教师</span>'`，同一变量同时喂给两处：
  ① 标题 `innerHTML`（span 能正常渲染，无害）；
  ② **`<input value="${roleName}" readonly>`** —— `value` 是属性上下文，span 里的内层双引号会提前截断属性，
  浏览器把 `<span data-term=` 当值、`teacher` 当新属性 → 只读框渲染出标签源码。
- **附带发现**：弹窗由 `createUserModal` 挂到 `document.body`，而 `applyTerms` 只在列表处调用（`renderTeacherCards` 内），
  **覆盖不到弹窗** → 标题里 `data-term` span 其实从未被本地化，只是锚点词"教师/学生"恰好正确才没暴露。
  若只修输入框而保留标题用 span，会出现"输入框显示行业词、标题显示锚点词"的各说各话。
- **修法**（`frontend/js/admin-user.js`）：
  - 添加/编辑弹窗统一用**纯文本**角色词：`(typeof termText === 'function') ? termText('teacher') : '教师'`（与全站既定用法一致，如 student-bookingBrowserCards.js:350）。`termText()` 与 `applyTerms` 同源同优先级（getTerms()→education 锚点→key 兜底），动态文案本来就该走它（termsFunction.js 注释亦如此约定）。
  - 输入框改 `value="${escapeAttr(roleText)}" readonly`（转义兜底）。
  - 两个标题改 `textContent`（既然已是纯文本，不再用 innerHTML）。
- **验证**：`node --check` 语法通过；全站 grep 无残留 `value="...<span`；`node frontend/build.js` 重建 dist 后确认产物含 `termText("teacher"/"student")` 各 2 处、角色框为 `value="${escapeAttr(n)}" readonly`。
- 注：编辑弹窗本身**没有**角色字段（只有标题），用户口头说的"编辑卡片"实为添加弹窗的表单卡片。

## 经验（可复用）

- **一个变量别同时喂 innerHTML 和 HTML 属性**：`value="..."` / `onclick="..."` 是属性上下文，内容里的双引号会截断属性。属性上下文必须用纯文本 + `escapeAttr`/`escAttr` 转义；需要行业词时用 `termText()` 取纯文本，不要拼 `<span data-term>`。
- **动态生成的弹窗要单独调 applyTerms**：挂在 `document.body` 上的弹窗不会被列表容器的 `applyTerms(container)` 覆盖，除非显式对弹窗调用；否则改用 `termText()` 取词更稳。
