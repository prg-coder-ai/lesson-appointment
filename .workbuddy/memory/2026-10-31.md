### 关键前提（差点踩空）
`window.ApiPaths` **只由 `frontend/js/shared-domain-bridge.js` 提供**（该文件 2004 行 `window.ApiPaths = {...}`），而 `classroom.html` / `classroom-ops.html` **从来没引过它**。
原来 `classroom-main.js:60` 的 `var EP = (window.ApiPaths && ...) || {}` 因此恒为空对象，`_ensureConfig` 里 `if (!EP.ECLASSROOM_CONFIG) { cb(); return; }` 一直静默跳过课堂开关检查 —— 这是个既有隐形 bug，本次随引入 bridge 一并修好。
若只改 EP 引用不引 bridge，22 处会全部拼成 `undefined`。

### 改动（9 个文件）
1. `shared/apiPaths.js`：新增 **22 个**课堂端点常量（`CLASSROOM_SUBMISSION_FILE` / `CLASSROOM_MATERIAL_FILE` / `CLASSROOM_RECORDING` / `UPLOAD_{INIT,PART,COMPLETE}` / `CLASSROOM_ADMIN_{MONITOR×3, REPORT_LEARNING, EXPORT, RECONCILE×3, AUDIT×5, CONTRACT×3}`）。拼接型一律箭头函数 + `encodeURIComponent`。
2. 四个前端 IIFE 顶部各加 `var EP = (window.ApiPaths && window.ApiPaths.ENDPOINTS) || {};`；`classroom-main.js#_ensureConfig` 内原有的同名局部 `var EP` 已删除（避免遮蔽）。
3. 22 处硬编码逐处替换（main 1、material 1、record 4、ops 16）。
4. `classroom.html` / `classroom-ops.html`：在 `js/public/api.js` 之后插入 `<script src="js/shared-domain-bridge.js">`（必须早于 `js/classroom/*.js`，因为它们在 IIFE 执行时就读 EP）。
5. `miniprogram/shared/apiPaths.js` 镜像同步 + `frontend/js/shared-domain-bridge.js` 重新生成 + `frontend/dist` 重建。

### 值得记住的坑
- **两个 html 是 CRLF**（189/235 行全 CRLF），`.js` 是 LF —— 用 python 按 `newline=''` 读写，插入时手写 `\r\n`，别用 Edit 硬塞 `\n` 造成混合换行。
- `gen-shared-bridge.mjs` 的输入**包含 `shared/apiPaths.js`**（第 79-80 行），所以改端点常量必须重跑生成器，否则源码绿、运行时 undefined。
- terser 不会 mangle 对象属性，`EP.CLASSROOM_ADMIN_*` 在 dist 里原样保留（可 grep 核验）；但**函数名会被压缩**，核验只能 grep 字符串字面量。
- `check-global-collide` 的 `GENERATED` 白名单含 `js/shared-domain-bridge.js`，所以引入 bridge 不会触发全局碰撞红——但这意味着**它也不会替你检查 bridge 与页面脚本的全局冲突**，需人工确认（本次：bridge 挂 `Window.*Domain/Adapter/ApiPaths`，课堂脚本挂 `Window.Classroom*`，无重叠）。
