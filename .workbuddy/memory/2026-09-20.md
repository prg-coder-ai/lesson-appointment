- `UserMapper.getByWxOpenid` / `updateWxOpenid`（自定义 SQL 用 wx_openid 列）整段块注释。
- `UserService.wechatLogin` / `bindWechat` 整方法块注释。
- `authController` 的 `/wechat-login`、`/bind-wechat` 端点整段块注释（SecurityConfig/WebMvcConfig/JwtAuthenticationFilter 白名单里的 `/wechat-login` 放行条目保留无害）。

**验证**：`saas-api-build-smoke compile` = BUILD SUCCESS（EXIT=0，仅既有 WARNING）；grep 确认 `wx_openid`/`getByWxOpenid`/`wechatLogin`/`bindWechat` 仅出现在注释或带 `exist=false` 的字段声明内，无执行 SQL 引用。
