## student-bookingCards.js + ScheduleGenerator.java · 修复 generateScheduleListFromServer 服务器超时（2026-09-23）
- 现象：学生端"预览排期"未预定分支调 generateScheduleListFromServer → 本地 api /schedule/generate 服务器超时。
- 根因（已闭环）：DB course_schedule.repeat_type 存**数字枚举** 0=不重复/1=每天/2=每周/3=每月（700 行里 697 行是 0、3 行是 2）；前端 scheduleObject.repeatType 直接透传数字给 ScheduleGenerateDTO(String)。后端 ScheduleGenerator.generateUserZoneSchedule 的 switch 只认 none/day/week/month 字符串 → 数字全命中 default：主循环不添加 + nextDate default 返回 current（不推进）→ **while 死循环 → 服务器超时**。后端 CreateDtoToGenerateDto(412-421) 的数字→字符串映射只给"创建排期"用，/schedule/generate 直收透传未映射。
- 前端修复（立即止血，旧 jar 即生效）：previewSchedule 构造 form 时 normalizeRepeatType(数字→字符串) + parseRepeatDays(字符串"1,3,5"→[1,3,5])。dist 已含，node 单测 0→none/2→week、parseDays 通过。
- 后端修复（根治隐患，防任何非标准 type 卡死服务器）：ScheduleGenerator 新增 normalizeRepeatType（数字 0-3 兼容 + 未知兜底 none）；nextDate default 由 return current 改为 return current.plusDays(1) 兜底推进。api 模块 launcher compile BUILD SUCCESS。
- 部署：前端 Ctrl+F5 强刷即可（旧 jar 收字符串已不超时）；后端修复需重建 api jar 并重启 8081 才生效（择机做，非当前阻塞）。
