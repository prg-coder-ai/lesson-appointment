## Web 前端手动测试发现并修复 STORE.getItem bug
- 现象：手动测试 Web 时 `api.js:172` 报 `Uncaught TypeError: STORE.getItem is not a function`（getCurrentUserInfo → guardEntryPage → window.onload，admin.html?tCode=...）。
- 根因：P2 接线把 `api.js`/`auth.js` 的 `STORE` 指向 `window.StorageAdapter.storage`，但共享 `storage` 适配器仅暴露 `get/set/remove/clear`，而历史代码与浏览器 `localStorage` 用 `getItem/setItem/removeItem`；接口名对不上 → 桥接加载即崩。
- 修复：两文件顶部加 `_storageBackend` + `STORE` 垫片，把底层 backend 归一成同时支持两套接口的对象（桥接加载→走 `StorageAdapter.storage.get`；桥接缺失→回退原生 `localStorage`）。调用代码 `STORE.getItem/setItem/removeItem` 零改动。
- 验证：`vm` 沙箱加载 `api.js` 真实源码，模拟桥接加载/缺失两场景，`STORE.getItem` 均为 function 且分别走通 `ADAPTER:`/`LS:` 源；`node --check` 两文件通过；`node build.js` 重建 dist；回归 shared-domain 122 / bridge 冒烟 / remaining-sites 42 / 漂移守卫 EXIT=0 全绿。
- 已知漏点：`utility_request.js` 仍直接调原生 `localStorage.getItem/setItem/removeItem`（同源不报错），未走 STORE 垫片，属待收敛项（18 处，需回归验证）。
- 技能 `shared-adapter-wire` 已补充「Web 接入 storage 必须做接口归一」警示，避免重蹈。

## Web 前端手动测试发现并修复 login.html 整段崩溃（IIFE 重名 const）
- 现象：dev :8080 手动测 `login.html?tCode=TENANT_A` 报两个错：① `Uncaught ReferenceError: applyLoginTenantRule is not defined`（select onchange，login.html:174）；② `Uncaught SyntaxError: Identifier 'PLATFORM_TENANT_CODE' has already been declared`（login.html:268/685）。
- 根因（同一根因连锁）：桥接生成器把 `shared/constants.js` 全量内联进全局桥接脚本（`head` 第 146 行 `<script src="js/shared-domain-bridge.js">`），其中 `const PLATFORM_TENANT_CODE='platform';` 落在页面全局词法环境；`login.html` body 内联 `<script>`（268 行起）第 685 行又声明同名 `const`。classic `<script>` 顶层 `const` 跨脚本块共享全局词法环境，重名即抛 `already been declared`，导致 login.html 这段内联脚本**整块解析失败**——769 行的 `applyLoginTenantRule`（及同块所有函数）从未定义，触发错①。
- 修复（治本）：把桥接整段用 IIFE 包裹（`gen-shared-bridge.js` 末尾 `'(function(){\n'+constSrc+domainSrc+adapterSrc+body+'\n})();\n'`）。constants/domain/adapters 的顶层声明留在 IIFE 作用域不泄漏全局，仍只经 `window.*Domain`/`window.*Adapter` 暴露。domain 函数闭包捕获 constants，照常工作。`login.html` 自身的 `const PLATFORM_TENANT_CODE` 不再冲突。
- 验证（对照确凿）：vm 模拟浏览器「全局词法环境共享」语义，把桥接+login内联拼成单一全局脚本——`BEFORE`（剥 IIFE）精确 CRASH `SyntaxError: Identifier 'PLATFORM_TENANT_CODE' has already been declared`；`FIXED`（IIFE）PASS（`window.TermDomain` 暴露、`applyLoginTenantRule` 已定义、login 内联的 `PLATFORM_TENANT_CODE` 仍可见=platform）。
- 重建 dist（`node build.js`，含 `CODEBUDDY_SAFE_DELETE_ENABLED=0`）通过；回归 shared-domain 122 / bridge 冒烟 / remaining-sites 42 / 漂移守卫 EXIT=0 全绿。
- 注意：dev 代理直出 `frontend/` 源码，改 `frontend/js/shared-domain-bridge.js` 即生效（无需等 dist）；两端已同步重建。
- 技能 `shared-adapter-wire` step 3 已加「桥接必须 IIFE 包裹」铁律，避免重蹈。
