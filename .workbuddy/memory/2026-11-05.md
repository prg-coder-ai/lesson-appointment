## ★登录页选项条拥挤的真正根因（14:56，纠正前两轮误判）
- 前两轮按「块级 view 撑满父容器」判断是错的：miniprogram/app.wxss:22 有全局 `.field { display:flex; align-items:center; padding:20rpx 24rpx }`，login.wxss 只覆盖 margin-bottom，故每个 field 是 flex 行。`.role-seg` 作为 flex 项，width:auto = 内容宽，被三个 flex:1 1 0 子项压到最窄（截图里明显比输入框窄）；去负 margin / 去文本空白都没触及根因。

- 教训：改页面级 WXSS 前必须先看 app.wxss 的全局同名类（.field/.card），页面样式只覆盖显式声明的属性，未声明的 display:flex / padding 仍生效。
