关键决策：
1. 1002 **不进** ResultHttpStatusAdvice 映射表（那张表刻意只映射 400/404/409/500）→ 天然 HTTP 200 + body.code，与 1001 静默降级同姿态；两端拦截器都按 body.code 分支，不需改 axios/wx 拦截器。
2. 超限只升级不拒绝（返回 1002 + "操作过于频繁"），绝不用 403（两端都把 403 当权限不足，历史踩过 403 触发刷新无限循环）。
3. 阈值刻意宽松：NAT 出口（一间教室共用公网 IP）是真实的，IP 设个位数第一个封的是客户；真正能收紧的是 account 维度。
4. 降级放行是硬约束：表没建/配置缺失也不能拖死登录（DDL 与代码分开部署，顺序不确定）。
5. DDL 里**不能写 CREATE TABLE IF NOT EXISTS**——check-ddl-align 的解析正则是 `^CREATE TABLE \`xxx\``，带 IF NOT EXISTS 会导致基线里"表不存在"假红（已踩，改掉后 51 表通过）。
