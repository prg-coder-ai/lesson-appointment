## 20:25【修复】创建临时课堂 403 —— 分流清单漏了「无子路径」的端点

**现象**：运营台点「创建临时课堂」→ `POST :8080/api/v1/admin/classrooms` 403「无权限访问该资源」。

**根因**（三端口对照验证）：
- `dev-proxy.js` / nginx 的课堂前缀是 `'/api/v1/admin/classrooms/'`（带尾斜杠），匹配用 `startsWith`
- 创建接口路径恰好是 `/api/v1/admin/classrooms`（**没有子段**）→ 永远命中不了
- 请求被兜底送到 8081 booking → 主服务无此映射，`SecurityConfig.anyRequest().denyAll()` → 403
- 带 token 才是 403、不带是 401（实测 8092→401 路由存在 / 8081→401 / 8080 连不上是 https 端口）

**修法**：
- `dev-proxy.js`：`urlPath === p.replace(/\/$/,'') || urlPath.startsWith(p)`
- `deploy/nginx/booking.conf` / `booking-ip.conf`：加 `location = /api/v1/admin/classrooms`（前缀 location 语法上匹配不到无子段路径）
- 文档：`电子课堂-系统维护说明` 补第 3 条写法约束；`前端部署与维护手册` 的 nginx 片段补精确块

**防回归**：新增 `tools/check-proxy-routes.mjs`（`npm run check:proxy`，已进 pre-commit，逃生 `SKIP_PROXY=1`）
- ① 从 `shared/apiPaths.js` 抽 23 个 `CLASSROOM_*` 端点，断言都能被判到课堂服务
- ② nginx 两 conf 的课堂 location 与 dev 清单一一对应（**清单从 dev-proxy.js 源码读，不复制第二份**）
- ③ 逐个端点在 nginx 里可匹配（无子段必须靠 `location =`）
- 双向变异证真会红（回退匹配逻辑 / 改坏精确块各报一次），已还原

**教训**：反向代理坑第 3 类（第 1 类是漏前缀→404，第 2 类是变量 proxy_pass 缺 resolver→502）：
**一个端点如果整个路径就等于前缀本身，前缀规则永远匹配不到它**。加端点时先问「它有子段吗」。
