## 小程序教师端「今日课程」对齐 Web 前端显示（序号/课程名称/学生列表/预约时间）
- **需求**：教师端「今日课程」采用 frontend 的显示内容——序号、课程名称、学生列表、预约时间等（不动 api）。
- **前端权威实现**（`frontend/js/public/appointmentNotes.js` + `admin-AppointmentNotes.js` teacher 分支）：
  - 数据源：POST `/course/appointment/statistical/listByDaysByPage` **循环翻页取全量**（pageSize=200），因为服务端逐条分页会把同一排期拆到不同页，聚合行数与分页总数对不上。
  - 依赖链：`appointment → booking(studentId/teacherId/scheduleId) → schedule(courseId/timeZone) → course(courseName)`，学生/教师姓名经 `GET /user/name/{id}` 解析，全程 Promise 缓存（booking/schedule/course/user 四个 Map）。
  - 分组：同一 `scheduleId + 上课日期` 聚合成一行（`formAppointmentGroupTr`）；行内容=序号 / 课程名称+classIndex / 学生列表（`、拼接 +（共 N 人）`）/ 教师 / 预约时间+时区 / 状态聚合 / 操作「申请改期⇄取消改期」（`teacherRescheduleTodayGroup` → 批量 `PUT /course/appointment/updateStatusById` body `{id,status}`，t-cancelling / active）。
- **小程序改造**（`miniprogram/package-teacher/appointment/`）：
  - `appointment.js` 重写：fetchAllRows（分页循环 + **兜底**退回 GET `listByDays`）/ enrich（memo 缓存 promise，4 类依赖并行）/ group（排期+日期分组、学生名去重、状态聚合与色调、pending 判定）/ load（服务端 status+courseName 过滤 + 客户端兜底二次过滤、聚合后编序号 1..N）。
  - 状态文案改用共享领域层 `shared/domain/appointmentState.js` 的 `appointmentStatusText(status,{teacherLabel})`（teacherLabel 取 `core/term.js` 的行业词），消除第二套 switch。
  - `onReschedule`：`wx.showModal` 二次确认后逐条 PUT，整组改期/取消改期（对齐前端）。
  - `.wxml`：序号徽标 + 课程名 + 状态徽标 / 课次 / 学生 / 教师 / 时间(+时区) / 操作条（查看排期、申请改期）；新增课程名搜索框（对齐前端 `course-name-input`）。
  - `.wxss`：补齐 search-row / count-bar / it-head / it-index / it-row / it-label / it-val / it-actions / act 等类。
