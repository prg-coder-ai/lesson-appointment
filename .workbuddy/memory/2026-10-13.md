**恢复做法（可复用 SOP）**：
1. `git reflog` 找被丢弃的提交链；`git merge-base HEAD <目标>` 确认分叉点

3. **先建备份分支**：`git branch backup/before-restore-20261013`（指向恢复前 HEAD）
4. `git merge -X ours 87e2adea -m "..."` —— `-X ours` 只让**冲突 hunk** 取当前侧，非冲突改动照常应用；本次 57 文件全部干净落回
5. 验证：编译 + 全量守卫 + 镜像同步 + 编码完整性

```js

```
把后端 briefs 的返回**按字段白名单重建**，后端新增的 `orgName` 在这一层被丢弃 → 前端 `b.orgName` 恒 undefined → 不渲染，**且无任何报错**。

`renderRecipients` 侧天然安全：`b.name` 缺失回退 userId、`b.account`/`b.orgName` 缺失则不渲染该节。
