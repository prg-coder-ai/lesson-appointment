## saas 分支 mvn package 报错定位（2026-09-07 ~20:25）
- 现象：切到 saas 分支后 `mvn package` 报 BUILD FAILURE；但 `mvn compile` 正常（BUILD SUCCESS，"Nothing to compile"）。
- 真正失败点：`spring-boot:repackage` 阶段 `Unable to rename '...booking_api-1.0.0.jar' to '...booking_api-1.0.0.jar.original'`。
- 根因：之前跑着的后端 `java -jar booking_api-1.0.0.jar`（PID 26644，监听 8081）**占用锁住了该 jar 文件**，repackage 无法改名。另一 java PID 14892 是 VS Code 的 redhat.java JDT 语言服务器，与构建无关、不可杀。
- 修复：停掉占用 jar 的后端进程（taskkill /PID 26644 /F），重跑 `mvn package -DskipTests` → BUILD SUCCESS（产出 42MB 可执行 jar）。
- 规律：**构建前必须先停掉正在运行的 jar 实例**（任何 `java -jar` 都会锁 target 下的 jar，导致 repackage 改名失败）。api 与 message-service 同理。
