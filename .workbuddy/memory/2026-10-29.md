## P0-D：课堂生命周期七个定时扫描器（提交 0fcb7b55）

### 根因
此前课堂开/下课、掉线判定、点名超时、过期清理**完全靠人工**调 `/start`、`/end`，无任何无人值守自愈。
七个扫描器在 P0-D 清单里是"功能完全不存在"，不是"不完善"。

### 实现（全部在 classroom-service）
- 新增 `scheduler/ClassroomScheduler.java`：七个 `@Scheduled` 方法。
  1. 就绪提醒（30s）：`listReadyToRemind` → `markReady`(SCHEDULED→READY) → 推 `READY_REMINDER` 告警。
  2. 自动开课（30s）：`listDueToStart` → `startClass`；全局 `classroom.auto-start` + 单课 `auto_start=false` 双闸。
  3. 自动下课（30s）：`listOverdueLive(grace)` → `endClass`（复用收尾 closeAfterEnd，与人工同口径）。
  4. 学生掉线判定（20s）：LIVE 课堂 `listOnline` → Redis key 消失 → `leave(...,"timeout")`。
  5. 点名超时（30s）：`listExpiredPending` → `updateById` 置 `TIMEOUT`。
  6. 教师掉线结课（40s）：教师 `OFFLINE` 且 `leave_time` 超 `teacher-drop-grace-seconds(120)` → `endClass`。
  7. 过期清理（每日 03:30）：6 张历史表按保留天数物理删除。
- **关键设计**：状态流转一律复用 `ClassroomService.markReady/startClass/endClass`（与人工同口径）；
  每个扫描器自包含 try/catch（单条失败不污染整轮）；掉线判定以 **Redis 在线 key 为唯一真相源**。
- `OnlineStateManager.refresh` 的 TTL 由硬编码 30s 改为可配 `@Value("${classroom.offline-timeout-seconds:60}")`。
- `ClassroomService.markReady` 由 `void` 改为返回 `boolean`（翻成功才发提醒）。
- Mapper 新增选行/清理方法（均复用既有列，**无新表新字段**，故 check:ddl-align 不受影响）。
- `application.properties` 合并去重课堂参数；调度线程池 2→8。
