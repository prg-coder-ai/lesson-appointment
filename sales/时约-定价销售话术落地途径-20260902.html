使用说明：本方案把用户按"规模 + 数据敏感度"切成三层，每层配独立定价、销售模式、话术与渠道。价格与话术均为建议初稿，上线前请卞现做最终报价拍板、赵写过合规与语气。涉及心理/法律行业，一律落到"辅助管理 + 数据本地"，不写"帮你获客/合规"。
①

用户规模分层（先分清楚"卖给谁"）

A 层 · 个体 / 自由职业者
独立咨询师、私教、教培自由老师、律师个人工作室
  • 规模：1 人经营，0–2 名辅助
  • 决策：自己说了算，秒级决策
  • 痛点：排期乱、爽约、手动提醒累
  • 付费意愿：低，认"一杯咖啡钱"
  • 数据敏感度：一般（SaaS 够用）
B 层 · 小团队 / 小微机构
教培小机构、律所小团队、健身工作室、心理诊所
  • 规模：2–10 名服务者（教练/老师/咨询师）
  • 决策：负责人拍板，会问"团队怎么用"
  • 痛点：多人排班冲突、客户分组、续费
  • 付费意愿：中，认"按席位摊薄"
  • 数据敏感度：中（SaaS 团队版为主）
C 层 · 成长型 / 连锁 / 强隐私
连锁健身、多校区教培、律所分所、心理机构
  • 规模：多门店 / 多服务者 / 有 IT 或合规要求
  • 决策：采购/负责人/合伙人，长周期
  • 痛点：数据归属、合规、统一管控
  • 付费意愿：高，认"项目制 + 年服"
  • 数据敏感度：高（须私有/内网）

分层口径：人数决定套餐与销售强度，数据敏感度决定交付形态（SaaS vs 私有/内网）。A、B 走 SaaS 自助；C 走私有部署定制。

分规模销售策略

A 层 · PLG 自助转化（零人工）
小红书/搜索 → 落地页 → 免费注册 → 产品内自助激活 → 自然转付费
  • 模式：产品驱动增长，几乎不靠人。靠内容 + 产品体验 + 站内/邮件提醒。
  • 关键动作：注册后 5 分钟引导建好第一个预约页（首屏 onboarding）；试用末 3 天触发"升级省心"提醒。
  • 主指标：注册数、激活率（建页率）、付费转化率、ARPU。
  • 原则：不投流、不打电话，让《首页文案》的 CTA 自己收注册。
B 层 · 轻销售（创始人/客服 1v1）
内容/搜索 → 注册 → 团队功能试用 → 1v1 引导 demo → 转团队版
  • 模式：自助为主 + 信号触发的人工轻触达。识别"多服务者/多人排班"行为即主动联系。
  • 关键动作：试用中识别扩张信号 → 企业微信/邮件触达 → 15 分钟轻 demo/答疑 → 促团队版付费。
  • 主指标：试用→团队版转化率、席位扩张率、净收入留存（NRR）。
  • 原则：不打扰个体用户，只对人多的账号做轻引导。
C 层 · 高 touch BD（创始人/销售直谈）
定向 BD/转介绍/行业活动 → 需求沟通 → 安全合规方案 → POC → 报价签约 → 部署
  • 模式：项目制销售，长周期（1–3 月），重信任与合规。
  • 关键动作：创始人或专职 BD 直谈；讲数据安全/合规/定制；给同行业案例；出 POC 再报价。
  • 主指标：商机数、POC 转化率、客单价、交付周期、续约率。
  • 原则：不公开标价，按规模与定制程度单谈，合同 + 部署交付。

分层话术库（可直接改稿用）

A 层 · 个体（偏小红书/落地页/站内，短平快）

开场钩子
"排课靠表格、约时间靠微信来回、续费靠一个个私信——这三件事，系统能替你接了。"
痛点共鸣
"你不是没客，是被人约这件小事，天天占你脑子。学员在群里问'还有位吗'，你还得手动排。"
价值主张
"时约把你可服务的时间一次性设好，学员自己挑、系统自动提醒。你只管按时上线。免费就能建第一个预约页。"
异议·价格
"标准版一个月 29，大概是你一节体验课的零头。省下每周几小时排课，值不值你算。"
促单收口
"先免费建一节课试试，5 分钟就好。觉得顺手再开标准版，不顺手也不亏。"

B 层 · 小团队（偏 1v1 引导/demo，讲"团队怎么用"）

开场钩子
"你们几个教练/老师的排期，现在是群里对、还是表格对？冲突了谁兜底？"
痛点共鸣
"人多就更乱：A 教练的课和 B 老师的撞了，会员约完才发现满员，续费还靠你记。"
价值主张
"团队版把所有人排班放一页，会员自助约、系统按人提醒；你后台看谁快到期、该跟进续费。加一个老师就加一个席位，按人摊。"
异议·怕麻烦
"不用迁数据，先把现有排期录进去就能用。我 15 分钟带你过一遍，你感受下多人视图。"
促单收口
"团队版 99/月起、含 3 个席位，年付 999。先开 14 天全功能试用，顺手就让团队都搬上来。"

C 层 · 私有部署（偏 BD 直谈/方案，讲安全合规与定制）

开场钩子
"咱们数据留在自己服务器，还是放公共云？这一条，往往决定了能不能用。"
痛点共鸣
"咨询记录、案卷、会员资料——这类数据放第三方，合规和归属都讲不清。内网跑、数据不出本地，才是硬刚需。"
价值主张
"时约支持私有/内网部署：功能跟 SaaS 一样，数据留你自己的环境。多门店统一管控、员工按角色权限，升级和运维我们包年服。"
异议·部署难
"前置就两样：自有服务器 + 基础网络。我们出部署指引，交付时培训+工单。具体范围我们先做个 POC 再报价，不先开天价。"
促单收口
"先约一轮需求沟通，我出一份部署+报价方案给你评估。项目制合作，按规模和定制单谈，不公开标价。"

风险与边界

合规：卖工具不是提供服务，禁绝对化用语（最/第一）与效果保证（保证不爽约/保证涨客）。心理、法律一律写"辅助管理工具 + 数据本地"，不写"帮你获客/合规"。

定价不自相矛盾：体验版要真能长期免费（否则"免费试用"变噱头，伤信任）；标准版与团队版边界要清晰，别让个体误买团队版、别让团队功能出现在免费版。

私有部署不夸大：说清前置（服务器/网络），别让人以为点一下就行；报价按项目单谈，对外不挂统一标价，避免被拿来做比价锚点。

归因要落地：方案跑通前提是"能自助注册试用 + 有落地页做来源归因"，否则 A/B 层转化无法量化、C 层线索无法回流。
