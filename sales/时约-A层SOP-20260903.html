A 层（个体服务业者）可执行 SOP

对象：独立咨询师 / 私教 / 教培自由老师 / 律师个人工作室 ｜ 模式：PLG 自助转化（零人工）｜ 套餐：体验版 ¥0 / 标准版 ¥29 ｜ 2026-09-03
本 SOP 把 A 层整条漏斗（获客→注册→激活→转化→留存→复盘）拆成谁来做、做什么、按什么标准算完成、卡在哪个阈值要报警。所有角色沿用你的 persona 团队；若你单人兼顾，按"负责人"列对号入座即可。价格与文案为建议初稿，上线前由卞现拍板报价、赵写过合规语气。
①

SOP 总览

小红书/搜索 获客→ 落地页 注册→ 5分钟 建页激活→ 14天试用 转付费→ 留存/转介绍→ 周/月 归因复盘

让个体业者"刷到→免费注册→5 分钟建好预约页→自然开 ¥29 标准版"，全程零销售介入。

阶段 1 · 获客（小红书 + 搜索）

1.1 账号与认证（冷启动三步）
启号
  • 第一步（0 成本）：开免费个人专业号（黄标"博主"）先发，测痛点选题和标题；不挂外链，主页/私信引导。
  • 第二步（官网就绪）：做极简注册落地页（需 ICP 备案）→ 认证企业号（600 元/年）→ 后台加"外链卡片/留资组件" → 笔记内蓝色按钮直达注册。
  • 第三步（持续）：每周 3–4 篇稳定更，标题埋行业词吃搜索流；注册送试用，引导进私域沉淀。
认证归类提醒（避坑）
企业号认证按"软件/SaaS 服务商"主体走，别归到教育培训类目（否则要办学许可）。时约卖工具，不办学。

1.4 内容生产 Checklist（每篇发布前过）
赵写
  • 标题含至少 1 个行业搜索词，且戳具体痛点（不是"好用的工具"而是"排课不再靠 Excel"）。
  • 正文用"他们自己的话"写痛点，不堆功能。
  • 演示类配真实录屏/截图，非 mock。
  • 结尾带注册钩子（CTA）：免费建页 / 免费试用。
  • 不出现绝对化用语（最/第一）与效果保证（保证不爽约/保证涨客）。
  • 心理/法律落到"辅助管理 + 数据本地"，不写"帮你获客/合规"。
  • 企业号笔记挂官方外链卡片（个人号阶段用主页引导）。
合规红线（发布即死线的几条）
禁：最 / 第一 / 唯一 / 保证不爽约 / 保证涨客 / 帮你合规。违规 = 限流或删帖，单主创更耗不起。

阶段 2 · 注册承接（落地页 + 归因）

2.1 落地页必备元素 Checklist
启号
  • 首屏主 CTA"免费试用"在 fold 内，副 CTA"看适用场景"。
  • 不注册可看全部 demo（真实截图/录屏）。
  • 行业切换入口（教培/律师/心理/健身 4 卡）点开看场景。
  • 分行业三段式：痛点→解法→截图，语气与小红书笔记一致。
  • 部署方式区块（SaaS/私有/内网），打隐私牌。
  • FAQ 前置回答三大顾虑：要不要钱 / 数据安全 / 怎么部署。
  • 移动端优先、加载快（小红书 90% 手机流量）。
  • 企业号外链卡片跳站外（ICP 备案就绪）；个人号阶段不直跳。
2.2 邀请码 / UTM 归因规则
梗王
  • 每篇小红书笔记配专属邀请码，格式：XY-行业-序号（例：XY-XL-001 = 心理篇第 1 篇）。
  • 或 UTM：?utm_source=xhs&utm_campaign=psy001&utm_content=帖子标题。
  • 注册时记录来源字段 → 写入"注册来源归因表"。
  • 落地页同时承载搜索/微信来源，用不同 UTM 区分，避免全算成"小红书"。
归因表字段（最小可用）
日期 / 来源邀请码 / 行业 / 是否注册 / 是否建页 / 是否付费 / 备注
2.3 注册门槛（降低阻力）
产品
  • 不绑卡、不审核，注册即开通 14 天全功能试用（= 标准版全部功能）。
  • 注册成功直接进 onboarding，不弹付费墙。
  • 微信/手机号任一种登录即可，尽量一键。

阶段 3 · 激活（5 分钟建页）

3.1 Onboarding 建页流程（产品内引导脚本）
产品
  • Step1 选行业：教培/律师/心理/健身 → 套用对应模板（字段预填）。
  • Step2 填服务者：姓名 / 头衔 / 一句话介绍（例："国家二级心理咨询师"）。
  • Step3 设时段：批量设周模板（如每周二三五 14:00–18:00 可约），拖拽即可。
  • Step4 生成页：自动出预约页链接 + 二维码，预览"客户视角"。
  • Step5 发出去：一键复制链接 / 存二维码，提示"发微信或贴主页"。
首屏引导文案（onboarding 顶部）
"花 5 分钟，把你的可约时间变成一张别人能自己挑的页。下面 5 步，做完就能发链接了。"
3.2 激活判定与失败干预
产品/卞现
  • 激活成功 = 建好预约页 + 至少完成一次"发链接"动作（或产生 1 次被预约）。
  • 注册后 24h 未建页 → 推送"3 步建页"引导 + 30 秒录屏，不催促。
  • 建页后 7 天 0 被约 → 提示"把链接发到微信群/主页，系统才会替你接预约"。

4.3 价格锚定话术（对外统一口径）
卞现
  • 标准版 ¥29/月 ≈ "一节体验课的零头 / 两杯咖啡"，锚定到省下的时间成本。
  • 年付 ¥299 = 10 个月价，突出"省两个月"。
  • 体验版永久免费（1 页 1 人）作为诚实兜底，反而提升信任。

阶段 5 · 留存与防流失

5.1 体验版留存设计
卞现
  • 体验版"1 页 1 人"对部分纯个体真够用 → 不强行逼付费，靠"够用就不走"做口碑。
  • 体验版保留全部已建页与数据，绝不清空，这是信任底线。
5.2 沉默唤醒
产品
  • 注册 30 天未登录 → 1 封"你的预约页还在，有人约过吗"轻提醒。
  • 建页但 60 天 0 被约 → 提示"把链接发到微信群/主页"。
5.3 转介绍（A→B 的种子）
卞现
  • 推荐 1 人注册并完成建页 → 推荐人得 1 个月标准版免费。
  • 推荐码与注册邀请码同源，归因到"转介绍"渠道，单独统计。

阶段 6 · 归因与周/月复盘

6.1 周看板（每周一，15 分钟）
梗王
  • 主看：来自小红书的免费试用注册数（按邀请码拆分到行业）。
  • 次看：激活率、付费转化率、转介绍数。
  • 参考：小眼睛、赞藏评、主页访问、官网点击（不用于定成败）。
6.2 月复盘（每月初，30 分钟）
梗王/卞现
  • 算"内容 → 注册"转化率，淘汰零转化选题。
  • 回看"哪个行业场景注册最多" → 反哺下月笔记选题（心理篇爆就加心理篇）。
  • 激活率 <25% → 先修 onboarding，再谈内容。
  • 付费转化 <5% → 查价格锚定话术 / 价值传递是否到位。
红线预警规则
激活率 <25% 查 onboarding；付费转化 <5% 查价格/价值；注册数连续 2 周为 0 → 内容方向或外链组件出问题，立即排查。

⑩

风险与边界

合规：卖工具不是提供服务，禁绝对化用语与效果保证；心理/法律写"辅助管理 + 数据本地"，不写"帮你获客/合规"。

体验版要真免费：若"免费试用"变噱头（暗藏绑卡/限功能），伤的是单主创最贵的东西——信任。1 页 1 人必须真能用。

不自相矛盾：标准版与体验版边界清晰，别让个体误买团队版、别把团队功能漏进免费版。

归因要真实：方案跑通前提是"能自助注册试用 + 落地页做来源归因"，否则 A 层转化无法量化、内容投入成盲飞。
