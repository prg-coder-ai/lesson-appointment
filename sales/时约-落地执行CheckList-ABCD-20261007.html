A

A 层 · 个体服务业者（PLG 自助转化）

对象：独立咨询师/私教/教培自由老师/律师个人工作室 ｜ 套餐：体验版 ¥0 / 标准版 ¥29 ｜ 模式：零人工自助
激活率 ≥40% 付费转化 8–12% 激活红线 <25% 修 onboarding 付费红线 <5% 查价格
1 获客（小红书 + 搜索）
启号/郝选题/赵写/梗王
  • 开免费个人专业号测痛点选题与标题，不挂外链、主页引导。
  • 极简注册落地页就绪 + ICP 备案完成 → 认证企业号（600/年）→ 接外链卡片。
  • 每周 3–4 篇稳定更（痛点 50% / 演示 30% / 人设 15% / 答疑 5%），不追日更、不投薯条。
  • 每篇笔记配专属邀请码 XY-行业-序号（例 XY-XL-001），或 UTM 参数。
  • 标题埋行业搜索词（心理咨询预约 / 私教排期 / 教培约课 / 律师预约页）。
  • 发布前过合规：禁"最/第一/保证/帮你获客"，心理法律只写"辅助管理+数据本地"。
认证避坑
企业号按"软件/SaaS 服务商"主体走，别归教育培训类目（否则要办学许可）。时约卖工具，不办学。
2 注册承接（落地页 + 归因）
启号/梗王/产品
  • 首屏主 CTA"免费试用"在 fold 内，副 CTA"看适用场景"。
  • 不注册可看全部 demo（真实截图/录屏）；行业切换入口（4 卡）点开看场景。
  • FAQ 前置回答三大顾虑：要不要钱 / 数据安全 / 怎么部署。
  • 移动端优先、加载快（小红书 90% 手机流量）。
  • 注册即开通 14 天全功能试用，不绑卡、不审核、不弹付费墙。
  • 注册时记录来源字段 → 写入"注册来源归因表"（日期/邀请码/行业/是否注册/是否建页/是否付费）。
3 激活（5 分钟建页）
产品/卞现
  • onboarding 5 步上线：选行业 → 填服务者 → 设时段 → 生成页+二维码 → 一键发出去。
  • 激活成功判定 = 建好预约页 + 至少完成一次"发链接"或产生 1 次被预约。
  • 注册后 24h 未建页 → 推"3 步建页"+30 秒录屏，不催促。
  • 建页后 7 天 0 被约 → 提示"把链接发到微信群/主页，系统才替你接预约"。
4 转化（试用 → ¥29 标准版）
卞现
  • D0/D1/D3/D7/D12/D14 自动时间线提醒配置完成（欢迎/建页/价值/周报/升级/降级）。
  • 三套转化文案就位：D7 周报价值锚定 / D12 升级损失规避 / D14 降级不催不封。
  • 价格锚定口径统一：¥29≈"一节体验课零头/两杯咖啡"，年付 ¥299=省两个月。
5 留存
卞现/产品
  • 体验版真永久免费（1 页 1 人），保留全部已建页与数据，绝不清空。
  • 注册 30 天未登录 → 1 封"你的预约页还在"轻提醒。
  • 转介绍：推荐 1 人注册并建页 → 推荐人得 1 个月标准版免费，单独归因统计。
6 复盘
梗王/卞现
  • 周看板（周一 15min）：主看小红书免费试用注册数，次看激活/付费/转介绍。
  • 月复盘（月初 30min）：算内容→注册转化，淘汰零转化选题，回看爆款行业反哺下月。
  • 红线预警：激活率<25% 先修 onboarding；付费<5% 查价格/价值；注册连续 2 周为 0 立即排查。
B

B 层 · 小团队 / 小微机构（轻销售 1v1）

对象：教培小机构/律所小团队/健身工作室/心理诊所（2–10 服务者）｜ 套餐：团队版 ¥99 起 ｜ 模式：信号触发的 1v1 轻销售
信号→触达 ≥70% 团队转化 25–35% NRR ≥110% 漏检红线 >30% 查埋点
1 信号识别（PQL）
产品
  • 多人信号埋点上线：第 2 个服务者账号 / 多人排班 / 团队页查看 / 试用服务者≥2 / 来自 B 渠道。
  • 72h 内出现任一信号自动入"轻销售线索池"，不等人肉翻后台。
  • 轻量资格认定（Sales Coach 透镜）：真有多个服务者？谁拍板？决策快不快？→ 三项皆"是"才进 demo。
  • 信号打分：多信号叠加或转介绍 → 优先 24h 内触达；记录到线索池表。
红线
多人信号却 >30% 未触达 → 先修埋点/同步，再谈话术。
2 1v1 触达
销售/创始人
  • 渠道优先级：企业微信（已在私域）> 邮件 > 站内信；不打电话。
  • 信号后 24h 内首触；避开周末早、晚 9 点后。
  • 语气：同行聊痛点，不装销售、不群发感。
  • 触达话术就位（赵写把关）：开场钩子 / 价值主张 / 收口要承诺。
3 15 分钟轻 demo
销售
  • demo 五步脚本：导入排期 → 多人排班视图（冲突高亮）→ 客户分组+续费提醒 → 数据看板 → 生成团队页。
  • 异议处理话术就位：怕麻烦 / 觉得贵 / 我们人少（赵写过合规）。
4 转化（团队版付费）
卞现/产品
  • 报价口径：¥99/月起含 3 席，每加 1 席 +¥19/月；年付 8 折（¥999 起）。
  • 自然扩张：客户加人即加席，收入随客户成长（B 层最值钱设计）。
  • 套餐边界纪律：用"席位需求"区分个体与团队，不做捆绑强推。
5 扩张 / 续费（NRR）
产品/卞现
  • 后台监测服务者数接近上限 → 自动提示升舱，按差额平滑过渡不重新签约。
  • 到期前 14/7/3 天提醒（企微+邮件）；多服务者降舱说明"留着更省心"，不强行扣费。
  • 转介绍：B 层客户推荐同行 → 双方各得 1 月标准版。
6 复盘
梗王/卞现
  • 周看板（15min）：线索池数量/触达率/demo 数/团队转化；标红黄绿（红=超72h未触）。
  • 月复盘（30min）：席位扩张率、NRR、信号准确率；淘汰误报多的埋点。
  • 红线：信号→触达<70% 查流程；团队转化<20% 查话术/demo；Sales Coach 先纠信号再纠话术。
C

C 层 · 私有部署 / 大客户（高 touch BD）

对象：连锁健身/多校区教培/律所分所/心理机构 ｜ 套餐：私有/内网部署项目制 ｜ 模式：长周期 1–3 月 BD
商机→POC ≥40% POC→签约 ≥50% 客单价 ¥15k–30k 资格红线 无 Buyer 不进 POC
1 商机获取（BD）
销售/创始人
  • 渠道优先级：转介绍（最高）> 定向 BD（协会/沙龙/拜访）> 行业活动演讲。
  • 行业优先级：律所（合规刚需）> 心理机构（隐私刚需）> 连锁健身/教培（规模）。
  • 每条商机入"商机表"：渠道/行业/规模/联系人/阶段/风险；来源归因同 A/B。
红线
无联系人或无行业匹配的商机 不占用 BD 精力。
2 资格认定（MEDDPICC）
销售
  • 每次沟通后填 8 维诊断表：Metrics / Economic Buyer / Decision Criteria / Decision Process / Pain / Champion / Competition / Paper Process。
  • 发现式提问脚本就位：开场重构问题（数据归谁/合不合规），找 Economic Buyer 拉会。
资格门槛（卡红线）
缺 Economic Buyer 或完全没有预算信号 → 养着，不进 POC。资格不全是丢单风险，不是 CRM 卫生问题。
3 方案 + POC
赵写/销售+技术
  • 方案文档 5 要素：痛点原话 / 部署形态建议 / 安全合规要点 / 功能映射表 / 实施计划+报价区间。
  • POC 范围明确：功能边界、数据量、环境（内网/隔离）、时长（2–4 周）。
  • 双方共同写下书面成功标准（可量化，例"内网跑通+数据不出本地+3 角色权限正确"）。
红线
POC 没有书面成功标准 = 不做（否则验收必扯皮）。
4 报价与签约
卞现/法务
  • 报价单：一次性部署费（私有 ¥8k–30k / 内网 ¥15k+）+ 年服（¥3k–10k）+ 可选定制/培训。
  • 付款节奏：首款（部署启动）+ 尾款（验收后），降低买方决策压力。
  • 不公开统一标价，按项目单谈；强调 TCO（含运维年服）。
  • 合同条款：数据归属 / SLA / 保密 / 部署前置（服务器网络自备写清）。
谈判红线
不先开天价吓退；不承诺超出能力的功能（尤其合规表述）。
5 部署交付
产品/技术
  • 流程：环境确认 → 部署 → 数据初始化 → 培训（管理员+终端两场）→ 验收 → 运维移交。
  • 验收对照 POC 成功标准逐条核对，双方签字；留操作手册。
  • 验收即启动年服计时；到期前 60 天启动续约沟通；沉淀脱敏行业案例。
6 复盘（Sales Coach 工具）
单必成
  • Pipeline Review 每周：每商机问 6 句（变了什么/跟谁谈/业务理由/决策流程/最大风险/下一步带日期 owner）。
  • 挑战 happy ears：买方"很喜欢"不算信号，问"承诺了哪步具体动作"；超 30 天无进展强制决策。
  • 丢单无责复盘：归类 资格/执行/竞争 → 对应不同干预。
  • 预测纪律：分层 upside/commit/closed；commit 只认"买方做了什么"的证据。
D

D 层 · 系统售卖（卖软件系统本身）

对象：想拥有/运营同类系统的机构、代理商、行业组织者、SaaS 创业者 ｜ 维度：与 A/B/C 正交的第四轴 ｜ 模式：资产/授权/渠道权
授权收入占比 15–25% M1 周期 ≤5 周 年维护续约 ≥85% 顺序红线 先 M1/M4 后 M2/M6
阶段一 · 立基线（M1 私有化授权 + M4 代理经销）
卞现/赵写/法务/产品
  • 授权协议模板出炉（赵写+法务）：禁止反编译、禁止二次分发、审计权、维护范围。
  • 部署包标准化：多租户/私有模式 + 授权 Key + 安装运维手册（产品/技术）。
  • 招首批 2–3 个代理，分级政策就位：铜 6 折 / 银 5 折返 3% / 金 4 折返 5–8%+区域保护。
  • 目标：跑通 1 单 M1（¥15k–40k 授权 + 年维护 15–20%）+ 1 个代理首单。
阶段二 · 建渠道（M4 代理 + M5 联合运营）
卞现/销售
  • 代理分级运营：培训 + 统一物料 + 线索分发后台；冲突由卞现仲裁。
  • 谈 1–2 个联合运营（协会/平台）：低前置 + 流水分成 15–30% + 自动分账后台。
  • 目标：代理带来末端 SaaS 占新签 20%+。
阶段三 · 做深合作（M3 白标 / OEM）
卞现/赵写
  • 选 1 个强信任行业品牌方做白标试点：可换 Logo/域名/配色 + 代运维。
  • 白标年费 ¥20k–50k + 实例/坐席抽成 或 纯年费+末端分成 10–20%。
  • 合同写清：白标方自行承担行业合规责任、最低年费保底、品牌边界（不得冒用"时约"主品牌）。
阶段四 · 顶级个案（M2 源码买断 / M6 平台特许）
创始人/卞现/法务
  • 仅接高价值、强信任个案，创始人亲谈；M2/M6 特批须创始人+卞现双签。
  • M2 源码走 escrow 托管交割（条件满足才释放）；合同锁定不竞争/不诋毁。
  • M6 用 MEDDPICC 严格筛买家；锁定数据归属、品牌边界、版本更新、违约责任。
顺序铁律
先 M1/M4 跑顺"交付+合同+渠道"，再上 M3/M5，最后才碰 M2/M6。一上来卖源码/平台特许最易丢控制权。
定价纪律与法务护栏
卞现/法务
  • 授权价锚定"对应 SaaS 年费 × 3 年"为基准，再按模式加溢价。
  • 年维护费 15–20% 是底线收入，不为成交而豁免。
  • 渠道价隔离：代理进货价（4–6 折）不公开挂价；直营 SaaS 价不受渠道影响。
  • 授权客户不享订阅价：其末端用户走 SaaS 按正常零售价。
  • 数据责任随部署转移写清；"数据不出公共云"必须靠部署真做到；SLA 分级对应维护费。
!

跨层通用红线（任何一层都不得破）

  • 合规表述：心理/法律一律写"辅助管理工具 + 数据本地"，禁"帮你获客/合规"；禁绝对化用语（最/第一/唯一）与效果保证。
  • 体验版诚实："免费试用"不可变噱头（暗藏绑卡/限功能）；1 页 1 人必须真能用，信任是单主创最贵的资产。
  • 不自相矛盾：各套餐功能/价格边界清晰，不误导误买、不漏功能。
  • 归因真实：A/B/C 跑通前提是"能自助注册试用 + 落地页来源归因"，否则转化无法量化。
  • 不公开统一标价：C/D 层按项目/授权单谈，避免被拿来做比价锚点。
  • 控制权护栏：D 层 M2/M6 让渡过多 → 仅接高价值个案、双签拍板、留审计与违约条款。
拍板与把关
所有价格与话术为建议初稿：最终报价/折扣框架由 卞现 终审，合规语气由 赵写 把关，M2/M6 特批须 创始人+卞现双签。
