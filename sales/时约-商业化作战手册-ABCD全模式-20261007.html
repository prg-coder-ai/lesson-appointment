四层模型怎么摆（先看懂这个再往下）

一个系统，两条收益线
A/B/C 层｜卖"使用"（SaaS 订阅）
按用户规模收费：个体 ¥29/月 → 团队 ¥99 起 → 私有部署项目制。靠内容获客 + 自助/轻销售转化，是持续经常性收入。
D 轴｜卖"系统本身"（授权/白标/代理）
因为源码自有，能一次性或周期性变现系统、授权、品牌、渠道权。是前置资产型收入，且自带渠道杠杆。

D 轴在 A/B/C 的上游：代理商（M4）在当地卖 A/B 订阅、白标方（M3）圈行业用户——这些末端最终都落回 A/B/C 的 SaaS 收入，"源头扩渠道、末端吃订阅"。

A 层 个体/自由职业者
→ PLG 自助，¥0 体验 / ¥29 标准

B 层 小团队/小微机构
→ 轻销售 1v1，¥99 团队版起

C 层 成长型/连锁/强隐私
→ 高 touch BD，私有部署项目制

D 轴 系统买家（机构/代理/品牌方）
→ 授权/白标/代理/联合运营
①

分层模型（卖给谁 · 用什么交付形态）

A 层 · 个体
独立咨询师、私教、自由老师、律师个人工作室
  • 1 人经营，自己秒级决策
  • 痛点：排期乱、爽约、手动提醒累
  • 付费意愿低，认"一杯咖啡钱"
  • 交付：SaaS（数据敏感度一般）
B 层 · 小团队
教培小机构、律所小团队、健身工作室、心理诊所
  • 2–10 名服务者，负责人拍板
  • 痛点：多人排班冲突、客户分组、续费
  • 付费意愿中，认"按席位摊薄"
  • 交付：SaaS 团队版
C 层 · 大客户
连锁健身、多校区教培、律所分所、心理机构
  • 多门店/有 IT 或合规要求
  • 痛点：数据归属、合规、统一管控
  • 付费意愿高，认项目制 + 年服
  • 交付：私有/内网部署
D 轴 · 系统买家
想拥有/运营同类系统的机构、代理商、行业组织者、SaaS 创业者
  • 有客群或有控制欲、但自己造不起/不值得造
  • 买的是"系统 / 授权 / 品牌 / 渠道权"，非末端订阅
  • 交付：授权包 / 源码 / 白标 / 代理政策 / 联合运营 / 平台特许
  • 与 A/B/C 正交：既服务末端，也服务"卖系统的人"

定价纪律（防自我蚕食 · 四条锁死）
① 锚定基准：一次性授权费 = 对应 SaaS 年费 × 3 年，再按模式加溢价；② 年维护是底线收入：私有/白标/平台一律收 15–20%，不为成交免掉；③ 渠道价隔离：代理进货价只用于代理自售，不公开挂价，直营 ¥29 不受渠道影响；④ 授权客户不享订阅折扣，避免"一次买断养一池免费末端用户"。价格审批权集中：标准框架卞现定，M2/M6 特批须创始人+卞现双签。

话术精华（各层钩子 / 价值 / 异议，可直接改稿）

A 层 · 个体

开场钩子
"排课靠表格、约时间靠微信来回、续费靠一个个私信——这三件事，系统能替你接了。"
价值主张
"时约把你可服务的时间一次性设好，学员自己挑、系统自动提醒。免费就能建第一个预约页。"
异议·价格
"标准版一个月 29，大概一节体验课零头。省下每周几小时排课，值不值你算。"

B 层 · 小团队

开场钩子
"你们几个教练/老师的排期，现在群里对还是表格对？冲突了谁兜底？"
价值主张
"团队版把所有人排班放一页，会员自助约、系统按人提醒；你后台看谁快到期、该跟进续费。加一个老师就加一个席位，按人摊。"
异议·怕麻烦
"不用迁数据，先把现有排期录进去就能用。我 15 分钟带你过一遍多人视图。"

C 层 · 私有部署

开场钩子
"咱们数据留在自己服务器，还是放公共云？这一条往往决定了能不能用。"
价值主张
"时约支持私有/内网部署：功能跟 SaaS 一样，数据留你自己的环境。多门店统一管控、员工按角色权限，升级运维我们包年服。"
异议·部署难
"前置就两样：自有服务器 + 基础网络。我们出部署指引，交付时培训+工单。先做个 POC 再报价，不先开天价。"

D 轴 · 卖系统（异议变了）

核心转向
这层卖的是资产与权利，异议从"太贵"变成"源码给我吗 / 数据归谁 / 能改吗"——话术围绕控制与归属而非性价比。缺"经济买家"或"预算信号"→ 养着不报价。

风险与合规红线

合规（发布即死线）：禁绝对化用语（最/第一/唯一）与效果保证（保证不爽约/保证涨客）。心理、法律一律写"辅助管理工具 + 数据本地"，不写"帮你获客/合规"。违规 = 限流或删帖，单主创更耗不起。

定价不自相矛盾：体验版要真能长期免费（否则"免费"变噱头伤信任）；标准版与团队版边界清晰，别让个体误买团队版、别让团队功能出现在免费版。

私有部署不夸大：说清前置（服务器/网络），别让人以为点一下就行；报价按项目单谈，对外不挂统一标价，避免被拿来做比价锚点。

D 轴四防：① 自我蚕食（授权价低于 3 年订阅/代理公开低价）→ 用定价纪律锁死；② 源码泄露（M1 只交部署包、M2 走 escrow，交付包不含核心密钥）；③ 渠道冲突（招商签区域/行业保护，冲突卞现仲裁）；④ 售后无底洞（维护费对应明确 SLA，超范围人天计费）。

控制权失控：M2/M6 让渡过多 → 仅接高价值个案、双签拍板、留审计与违约责任。心理/法律场景下"数据不出公共云"必须靠部署真做到，不口头承诺。
